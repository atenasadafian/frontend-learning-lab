# انواع سلکتورها (CSS Selectors)

با استفاده از CSS می‌توانیم ویژگی‌های ظاهری عناصر HTML را تغییر دهیم؛ برای مثال:

- تغییر رنگ متن
- تغییر اندازه فونت
- تغییر رنگ پس‌زمینه
- ایجاد فاصله بین عناصر
- تغییر حاشیه (Border)
- تنظیم ابعاد عناصر
- تغییر نحوه نمایش عناصر

برای اعمال استایل روی عناصر HTML، باید بتوانیم آن‌ها را انتخاب کنیم.

این کار با استفاده از مفهومی به نام **Selector (سلکتور)** انجام می‌شود.

## سلکتور چیست؟

سلکتور (Selector) بخشی از یک قانون CSS است که مشخص می‌کند استایل‌ها روی کدام عنصر یا عناصر HTML اعمال شوند.

ساختار کلی یک قانون CSS به شکل زیر است:

```css
selector {
    property: value;
}
```

اجزای این ساختار:

| بخش | توضیحات |
|---|---|
| Selector | مشخص می‌کند کدام عنصر انتخاب شود. |
| Property | ویژگی ظاهری موردنظر را مشخص می‌کند. |
| Value | مقدار ویژگی را تعیین می‌کند. |
| `{ }` | محدوده دستورات CSS را مشخص می‌کند. |

مثال:

```css
p {
    color: red;
    font-size: 18px;
}
```

در این مثال:

- `p` سلکتور است.
- `color` ویژگی رنگ متن است.
- `red` مقدار ویژگی رنگ است.
- `font-size` ویژگی اندازه فونت است.
- `18px` مقدار اندازه فونت است.

نتیجه: تمام تگ‌های `p` در صفحه، متن قرمزرنگ و اندازه فونت ۱۸ پیکسل خواهند داشت.

---

## سلکتور تگی (Tag Selector)

سلکتور تگی یکی از ساده‌ترین انواع سلکتورهای CSS است.

در این روش، نام تگ HTML را مستقیماً به‌عنوان سلکتور می‌نویسیم.

با این کار تمام عناصر موجود در صفحه که دارای آن نام تگ هستند انتخاب می‌شوند.

### ساختار

```css
tagName {
    property: value;
}
```

### مثال اول: انتخاب تمام پاراگراف‌ها

HTML:

```html
<p>این اولین پاراگراف است.</p>

<p>این دومین پاراگراف است.</p>

<p>این سومین پاراگراف است.</p>

<h1>عنوان صفحه</h1>
```

CSS:

```css
p {
    color: blue;
    font-size: 20px;
}
```

**نتیجه:**

تمام پاراگراف‌ها آبی می‌شوند و اندازه فونت آن‌ها ۲۰ پیکسل خواهد بود.

اما تگ `h1` هیچ تغییری نمی‌کند؛ چون سلکتور ما فقط تگ‌های `p` را انتخاب کرده است.

### مثال دوم: انتخاب تمام عنوان‌ها

HTML:

```html
<h1>عنوان اول</h1>

<h2>عنوان دوم</h2>

<h3>عنوان سوم</h3>
```

CSS:

```css
h1 {
    color: red;
}

h2 {
    color: green;
}

h3 {
    color: blue;
}
```

در این مثال هر نوع عنوان به‌صورت جداگانه انتخاب شده است.

### مثال سوم: انتخاب تمام تصاویر

HTML:

```html
<img src="image1.jpg" alt="تصویر اول">

<img src="image2.jpg" alt="تصویر دوم">
```

CSS:

```css
img {
    width: 200px;
    height: 150px;
    border: 2px solid black;
}
```

در این مثال تمام تصاویر موجود در صفحه دارای عرض ۲۰۰ پیکسل، ارتفاع ۱۵۰ پیکسل و حاشیه مشکی می‌شوند.

### ویژگی‌های سلکتور تگی

- برای انتخاب تمام عناصر دارای یک نام تگ استفاده می‌شود.
- نیازی به تعریف `class` یا `id` در HTML ندارد.
- روی تمام عناصر مشابه در صفحه تأثیر می‌گذارد.
- میزان اختصاصی بودن آن نسبت به سلکتور کلاس و آیدی کمتر است.

**چه زمانی از آن استفاده کنیم؟**

زمانی که بخواهیم یک استایل عمومی روی تمام عناصر مشابه اعمال کنیم، مانند:

- تعیین فونت تمام پاراگراف‌ها
- تعیین رنگ تمام عنوان‌ها
- تنظیم استایل تمام تصاویر
- حذف فاصله پیش‌فرض برخی تگ‌ها

---

## ۲. سلکتور کلاسی (Class Selector)

سلکتور کلاسی برای انتخاب یک یا چند عنصر HTML که دارای کلاس مشخصی هستند استفاده می‌شود.

کلاس به ما اجازه می‌دهد عناصر مختلف را دسته‌بندی کنیم و استایل مشترکی به آن‌ها بدهیم.

برای تعریف کلاس در HTML از ویژگی `class` استفاده می‌کنیم.

برای انتخاب کلاس در CSS باید قبل از نام کلاس از نقطه (`.`) استفاده کنیم.

### ساختار

HTML:

```html
<tag class="className">محتوا</tag>
```

CSS:

```css
.className {
    property: value;
}
```

**نکته مهم:** نقطه فقط در CSS نوشته می‌شود و هنگام تعریف کلاس در HTML نیازی به استفاده از نقطه نیست.

### مثال اول: انتخاب یک عنصر با کلاس مشخص

HTML:

```html
<p class="text-red">این متن قرمز است.</p>

<p>این متن معمولی است.</p>
```

CSS:

```css
.text-red {
    color: red;
}
```

**نتیجه:**

فقط پاراگرافی که کلاس `text-red` دارد قرمز می‌شود.

### مثال دوم: استفاده از یک کلاس برای چند عنصر

یکی از مهم‌ترین مزایای کلاس این است که می‌توانیم یک کلاس را به چند عنصر مختلف اختصاص دهیم.

HTML:

```html
<h1 class="title">عنوان صفحه</h1>

<p class="title">این یک پاراگراف است.</p>

<div class="title">این یک بخش از صفحه است.</div>
```

CSS:

```css
.title {
    color: blue;
    font-size: 24px;
}
```

**نتیجه:**

هر سه عنصر دارای متن آبی و اندازه فونت ۲۴ پیکسل خواهند بود.

زیرا هر سه عنصر کلاس `title` را دارند.

### مثال سوم: استفاده از چند کلاس برای یک عنصر

یک عنصر HTML می‌تواند هم‌زمان چند کلاس داشته باشد.

برای این کار نام کلاس‌ها را با فاصله از یکدیگر جدا می‌کنیم.

HTML:

```html
<p class="text-red bold large">
    این یک متن آزمایشی است.
</p>
```

CSS:

```css
.text-red {
    color: red;
}

.bold {
    font-weight: bold;
}

.large {
    font-size: 25px;
}
```

در این مثال:

- کلاس `text-red` رنگ متن را قرمز می‌کند.
- کلاس `bold` متن را ضخیم می‌کند.
- کلاس `large` اندازه متن را افزایش می‌دهد.

در نتیجه هر سه استایل روی یک عنصر اعمال می‌شوند.

### مثال چهارم: کلاس‌های مشترک بین عناصر مختلف

HTML:

```html
<button class="btn">ثبت</button>

<button class="btn">ارسال</button>

<a href="#" class="btn">مشاهده</a>
```

CSS:

```css
.btn {
    background-color: blue;
    color: white;
    padding: 10px 20px;
    border: none;
}
```

در این مثال حتی با وجود متفاوت بودن نوع تگ‌ها، هر سه عنصر به دلیل داشتن کلاس `btn` استایل یکسانی دریافت می‌کنند.

### ویژگی‌های سلکتور کلاسی

- با علامت نقطه (`.`) در CSS مشخص می‌شود.
- یک کلاس می‌تواند به چند عنصر اختصاص داده شود.
- یک عنصر می‌تواند چند کلاس داشته باشد.
- برای دسته‌بندی عناصر و ایجاد استایل‌های قابل استفاده مجدد بسیار مناسب است.
- میزان اختصاصی بودن آن از سلکتور تگی بیشتر است.

**چه زمانی از آن استفاده کنیم؟**

زمانی که بخواهیم استایل مشخصی را به چند عنصر مختلف اختصاص دهیم یا فقط عناصر خاصی از یک نوع را انتخاب کنیم.

## ۳. سلکتور آیدی (ID Selector)

سلکتور آیدی برای انتخاب یک عنصر مشخص با شناسه منحصربه‌فرد استفاده می‌شود.

برای تعریف شناسه در HTML از ویژگی `id` استفاده می‌کنیم.

برای انتخاب آن در CSS باید قبل از نام آیدی از علامت مربع (`#`) استفاده کنیم.

### ساختار

HTML:

```html
<tag id="idName">محتوا</tag>
```

CSS:

```css
#idName {
    property: value;
}
```

**نکته مهم:** علامت `#` فقط در CSS نوشته می‌شود و هنگام تعریف آیدی در HTML نیازی به استفاده از آن نیست.

### مثال اول: انتخاب یک عنصر با آیدی مشخص

HTML:

```html
<h1 id="main-title">
    به وب‌سایت من خوش آمدید
</h1>

<p>
    این یک پاراگراف معمولی است.
</p>
```

CSS:

```css
#main-title {
    color: red;
    font-size: 32px;
}
```

**نتیجه:**

فقط عنوانی که آیدی `main-title` دارد قرمز و بزرگ می‌شود.

### مثال دوم: استفاده از آیدی برای یک بخش مشخص

HTML:

```html
<div id="header">
    <h1>سربرگ سایت</h1>
</div>

<div id="content">
    <p>محتوای اصلی سایت</p>
</div>

<div id="footer">
    <p>پاورقی سایت</p>
</div>
```

CSS:

```css
#header {
    background-color: blue;
    color: white;
}

#content {
    background-color: lightgray;
    padding: 20px;
}

#footer {
    background-color: black;
    color: white;
}
```

در این مثال هر بخش با استفاده از آیدی مخصوص خودش انتخاب شده است.

### قوانین مهم آیدی

**۱. آیدی باید در یک صفحه HTML یکتا باشد.**

یعنی بهتر است یک مقدار `id` فقط برای یک عنصر استفاده شود.

روش صحیح:

```html
<h1 id="main-title">عنوان اصلی</h1>

<p id="description">توضیحات صفحه</p>
```

روش نادرست:

```html
<h1 id="title">عنوان اول</h1>

<h2 id="title">عنوان دوم</h2>
```

در مثال دوم یک آیدی برای دو عنصر مختلف استفاده شده است که با هدف یکتایی آیدی سازگار نیست.

**۲. هر عنصر فقط یک آیدی دارد.**

روش صحیح:

```html
<div id="main-content"></div>
```

روش نادرست:

```html
<div id="main content"></div>
```

برای داشتن چند شناسه روی یک عنصر باید از `class` استفاده کنیم، نه چند مقدار مجزا در `id`.

**۳. آیدی نسبت به کلاس اختصاصی‌تر است.**

در CSS، سلکتور آیدی از سلکتور کلاس و تگ قدرت بیشتری دارد.

**چه زمانی از آن استفاده کنیم؟**

زمانی که بخواهیم یک عنصر مشخص و یکتا را انتخاب کنیم؛ برای مثال:

- سربرگ اصلی صفحه
- بخش اصلی محتوا
- پاورقی سایت
- یک بخش منحصربه‌فرد از صفحه

## مقایسه انواع سلکتورها

سه سلکتور اصلی که بررسی کردیم عبارت‌اند از:

| نوع سلکتور | علامت | مثال CSS | کاربرد |
|---|---|---|---|
| تگی | بدون علامت | `p` | انتخاب تمام تگ‌های مشابه |
| کلاسی | `.` | `.title` | انتخاب تمام عناصر دارای کلاس |
| آیدی | `#` | `#header` | انتخاب عنصر دارای آیدی مشخص |

### مثال مقایسه‌ای

HTML:

```html
<h1 id="main-title" class="title">
    عنوان اصلی
</h1>

<h2 class="title">
    عنوان دوم
</h2>

<p class="description">
    توضیحات صفحه
</p>

<p>
    یک پاراگراف دیگر
</p>
```

CSS:

```css
h1 {
    color: green;
}

.title {
    font-size: 30px;
}

#main-title {
    color: red;
}
```

در این مثال:

- سلکتور `h1` تمام تگ‌های `h1` را انتخاب می‌کند.
- سلکتور `.title` تمام عناصری را انتخاب می‌کند که کلاس `title` دارند.
- سلکتور `#main-title` فقط عنصری را انتخاب می‌کند که آیدی `main-title` دارد.

عنوان اصلی هم‌زمان هر سه سلکتور را دارد.

اما رنگ نهایی آن قرمز خواهد بود؛ زیرا سلکتور آیدی اختصاصی‌تر از سلکتور تگ و کلاس است.

## مفهوم Specificity یا میزان اختصاصی بودن

یکی از مفاهیم مهم CSS، ویژگی Specificity است.

Specificity مشخص می‌کند زمانی که چند قانون CSS برای یک عنصر مقدار متفاوتی از یک ویژگی تعیین می‌کنند، کدام قانون اولویت بیشتری دارد.

برای سه نوع سلکتور موردبحث، ترتیب اولویت به شکل زیر است:

1. سلکتور آیدی (`#id`)
2. سلکتور کلاسی (`.class`)
3. سلکتور تگی (`tag`)

### مثال

HTML:

```html
<p id="text" class="description">
    آموزش CSS
</p>
```

CSS:

```css
p {
    color: green;
}

.description {
    color: blue;
}

#text {
    color: red;
}
```

نتیجه:

رنگ متن قرمز خواهد بود.

چرا؟

زیرا:

- سلکتور تگی اولویت کمتری دارد.
- سلکتور کلاسی اولویت بیشتری دارد.
- سلکتور آیدی بالاترین اولویت را در بین این سه نوع دارد.

### امتیاز Specificity

برای درک بهتر، می‌توانیم میزان اختصاصی بودن این سلکتورها را به شکل زیر نمایش دهیم:

| سلکتور | امتیاز |
|---|---:|
| `p` | 0,0,1 |
| `.title` | 0,1,0 |
| `#header` | 1,0,0 |

هرچه امتیاز اختصاصی بودن بیشتر باشد، اولویت آن در مقایسه با سلکتورهای کم‌امتیازتر بیشتر است.

توجه: این امتیازها نمایش ساده‌شده‌ای از محاسبه Specificity هستند و ترتیب منبع، `!important` و برخی قواعد دیگر CSS نیز می‌توانند در نتیجه نهایی تأثیر داشته باشند.

## ترکیب سلکتورها

در CSS می‌توانیم سلکتورها را با یکدیگر ترکیب کنیم تا عناصر را دقیق‌تر انتخاب کنیم.

### ۱. ترکیب تگ و کلاس

```css
p.description {
    color: blue;
}
```

این سلکتور فقط پاراگراف‌هایی را انتخاب می‌کند که کلاس `description` دارند.

HTML:

```html
<p class="description">این متن انتخاب می‌شود.</p>

<div class="description">این متن انتخاب نمی‌شود.</div>
```

### ۲. ترکیب تگ و آیدی

```css
h1#main-title {
    color: red;
}
```

این سلکتور فقط عنصر `h1` دارای آیدی `main-title` را انتخاب می‌کند.

### ۳. ترکیب چند کلاس

```css
.card.active {
    background-color: green;
}
```

این سلکتور فقط عناصری را انتخاب می‌کند که هم کلاس `card` و هم کلاس `active` را داشته باشند.

HTML:

```html
<div class="card active">
    کارت فعال
</div>

<div class="card">
    کارت معمولی
</div>
```

در این مثال فقط کارت اول انتخاب می‌شود.

### ۴. انتخاب چند سلکتور به‌صورت هم‌زمان

با استفاده از کاما (` , `) می‌توانیم چند سلکتور را در یک قانون CSS قرار دهیم.

```css
h1, h2, p {
    font-family: Arial;
    color: blue;
}
```

در این مثال تمام عناصر `h1`، `h2` و `p` استایل یکسانی دریافت می‌کنند.

**نکته:** کاما به معنی انتخاب هم‌زمان چند گروه از عناصر است و با ترکیب سلکتورها تفاوت دارد.

## نکات مهم

۱. برای انتخاب تگ‌ها نیازی به استفاده از علامت خاصی نیست.

```css
p {}
```

۲. برای انتخاب کلاس باید از نقطه استفاده کنیم.

```css
.title {}
```

۳. برای انتخاب آیدی باید از علامت `#` استفاده کنیم.

```css
#header {}
```

۴. نام کلاس و آیدی در HTML بدون نقطه و `#` نوشته می‌شود.

```html
<p class="title" id="main-title">
    متن آزمایشی
</p>
```

۵. نام کلاس می‌تواند در چند عنصر تکرار شود.

۶. مقدار آیدی باید در هر صفحه یکتا باشد.

۷. یک عنصر می‌تواند چند کلاس داشته باشد.

۸. یک عنصر فقط باید یک مقدار آیدی داشته باشد.

۹. سلکتور آیدی نسبت به سلکتور کلاس اختصاصی‌تر است.

۱۰. سلکتور کلاس برای استایل‌دهی مجدد و استفاده در بخش‌های مختلف سایت انعطاف‌پذیرتر است.

## تمرین

برای تسلط بیشتر روی این سه نوع سلکتور، تمرین زیر را انجام دهید.

### صورت سؤال

کد HTML زیر را در نظر بگیرید:

```html
<h1 id="main-title">آموزش CSS</h1>

<p class="text">این اولین پاراگراف است.</p>

<p class="text">این دومین پاراگراف است.</p>

<p id="special-text">این یک متن ویژه است.</p>

<div class="box">بخش اول</div>

<div class="box">بخش دوم</div>

<h2>عنوان دوم</h2>
```

### وظایف

۱. تمام تگ‌های `p` را به رنگ آبی تبدیل کنید.

۲. تمام عناصر دارای کلاس `box` را دارای پس‌زمینه زرد کنید.

۳. عنصر دارای آیدی `main-title` را به رنگ قرمز تبدیل کنید.

۴. تمام عناصر دارای کلاس `text` را دارای اندازه فونت ۲۰ پیکسل کنید.

۵. عنصر دارای آیدی `special-text` را به رنگ سبز تبدیل کنید.

۶. تگ `h2` را دارای پس‌زمینه خاکستری کنید.

### پاسخ تمرین

```css
p {
    color: blue;
}

.box {
    background-color: yellow;
}

#main-title {
    color: red;
}

.text {
    font-size: 20px;
}

#special-text {
    color: green;
}

h2 {
    background-color: lightgray;
}
```

## جمع‌بندی

در این آموزش با سه نوع اصلی سلکتور در CSS آشنا شدیم:

| ویژگی | Tag Selector | Class Selector | ID Selector |
|---|---|---|---|
| نحوه نوشتن | `p` | `.title` | `#header` |
| نیاز به ویژگی در HTML | خیر | `class` | `id` |
| امکان استفاده مجدد | برای تمام تگ‌های مشابه | بله | مقدار آیدی باید یکتا باشد |
| انتخاب چند عنصر | بله | بله | برای یک عنصر مشخص طراحی شده است |
| میزان اختصاصی بودن | کم | متوسط | زیاد |

**نتیجه نهایی:**

- از سلکتور تگی برای انتخاب تمام عناصر دارای یک نام تگ استفاده می‌کنیم.
- از سلکتور کلاسی برای دسته‌بندی و استایل‌دهی به چند عنصر استفاده می‌کنیم.
- از سلکتور آیدی برای انتخاب یک عنصر مشخص و یکتا استفاده می‌کنیم.

با یادگیری این سه سلکتور، پایه اصلی انتخاب عناصر در CSS را یاد گرفته‌اید و می‌توانید در مراحل بعدی سراغ سلکتورهای پیشرفته‌تر بروید.
