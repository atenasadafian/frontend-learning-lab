# HTML Semantic Elements (تگ‌های مفهومی HTML5)
..
## استفاده از تگ‌های مفهومی مدرن برای بهبود ساختار SEO و خوانایی کد

در طراحی صفحات وب، ساختار HTML نقش بسیار مهمی در تعیین مفهوم، ترتیب و ارتباط بخش‌های مختلف یک صفحه دارد.

در گذشته، توسعه‌دهندگان برای ساخت تقریباً تمام قسمت‌های صفحات وب از تگ عمومی `<div>` استفاده می‌کردند. این روش اگرچه از نظر فنی امکان ایجاد ساختارهای پیچیده را فراهم می‌کرد، اما مشکل مهمی داشت: مرورگرها، موتورهای جستجو و فناوری‌های کمکی نمی‌توانستند به‌راحتی مفهوم هر قسمت را از روی تگ HTML تشخیص دهند.

برای حل این مشکل، HTML5 مجموعه‌ای از تگ‌های معنایی یا Semantic Elements را معرفی کرد.

این تگ‌ها به‌جای اینکه صرفاً یک بخش از صفحه را مشخص کنند، مفهوم و نقش آن بخش را نیز بیان می‌کنند.

برای مثال:

- `<header>` نشان‌دهنده بخش سربرگ است.
- `<nav>` برای مجموعه لینک‌های ناوبری استفاده می‌شود.
- `<main>` محتوای اصلی صفحه را مشخص می‌کند.
- `<article>` محتوایی مستقل و قابل استفاده مجدد را نمایش می‌دهد.
- `<section>` یک بخش موضوعی از محتوا را مشخص می‌کند.
- `<aside>` محتوای جانبی و مرتبط را نمایش می‌دهد.
- `<footer>` اطلاعات انتهایی یک صفحه یا بخش را مشخص می‌کند.

استفاده صحیح از این تگ‌ها باعث ایجاد ساختاری استاندارد، قابل فهم و قابل نگهداری می‌شود.

---

## Semantic HTML چیست؟

Semantic HTML به معنای استفاده از تگ‌های HTML بر اساس مفهوم و نقش واقعی محتوای آن‌ها است.

به عبارت دیگر، هر تگ باید با توجه به معنایی که دارد برای محتوای مناسب استفاده شود.

برای مثال، اگر بخواهیم عنوان اصلی یک صفحه را مشخص کنیم، استفاده از تگ `<h1>` مناسب‌تر از قرار دادن آن در یک `<div>` عمومی است.

همچنین اگر بخواهیم منوی اصلی سایت را مشخص کنیم، باید از `<nav>` استفاده کنیم؛ زیرا این تگ به‌صورت معنایی مشخص می‌کند که محتوای داخل آن مربوط به ناوبری سایت است.

### یک مثال ساده

ساختار غیرمعنایی:

```html
<div class="header">
    <div class="menu">
        <a href="/">خانه</a>
        <a href="/about">درباره ما</a>
        <a href="/contact">تماس با ما</a>
    </div>
</div>

<div class="content">
    <h1>آموزش HTML</h1>
    <p>محتوای آموزشی HTML</p>
</div>

<div class="footer">
    <p>تمامی حقوق محفوظ است.</p>
</div>
```

ساختار معنایی:

```html
<header>
    <nav>
        <a href="/">خانه</a>
        <a href="/about">درباره ما</a>
        <a href="/contact">تماس با ما</a>
    </nav>
</header>

<main>
    <h1>آموزش HTML</h1>
    <p>محتوای آموزشی HTML</p>
</main>

<footer>
    <p>تمامی حقوق محفوظ است.</p>
</footer>
```

در مثال دوم، بدون نیاز به بررسی نام کلاس‌ها، نقش بخش‌های مختلف صفحه از روی تگ‌های HTML قابل تشخیص است.

## چرا استفاده از تگ‌های معنایی اهمیت دارد؟

استفاده از Semantic HTML چندین مزیت مهم دارد:

### بهبود ساختار SEO

موتورهای جستجو برای درک محتوای صفحات وب، ساختار HTML را بررسی می‌کنند.

تگ‌های معنایی به توصیف بهتر بخش‌های مختلف صفحه کمک می‌کنند و باعث می‌شوند ساختار محتوا برای موتورهای جستجو قابل فهم‌تر باشد.

البته استفاده از این تگ‌ها به‌تنهایی تضمین‌کننده رتبه بهتر در نتایج جستجو نیست.

### افزایش خوانایی کد

زمانی که از تگ‌هایی مانند `<header>`، `<main>` و `<footer>` استفاده می‌کنیم، توسعه‌دهندگان راحت‌تر متوجه می‌شوند هر قسمت از صفحه چه وظیفه‌ای دارد.

### بهبود Accessibility

فناوری‌های کمکی مانند Screen Readerها می‌توانند از ساختار معنایی HTML برای شناسایی بخش‌های مختلف صفحه استفاده کنند.

این موضوع به کاربران دارای محدودیت‌های بینایی کمک می‌کند تا راحت‌تر در صفحه حرکت کنند.

### نگهداری آسان‌تر پروژه

در پروژه‌های بزرگ، استفاده از تگ‌های معنایی باعث می‌شود ساختار صفحات منظم‌تر باشد و توسعه‌دهندگان بتوانند بخش‌های مختلف را سریع‌تر شناسایی و مدیریت کنند.

### استانداردسازی ساختار صفحات

استفاده از Semantic Elements باعث می‌شود صفحات وب از یک الگوی ساختاری مشخص و قابل فهم پیروی کنند.

## تفاوت تگ‌های Semantic و Non-Semantic

تگ‌های HTML را از نظر معنایی می‌توان به دو گروه کلی تقسیم کرد.

### تگ‌های Semantic

این تگ‌ها مفهوم مشخصی دارند و نقش محتوای خود را بیان می‌کنند.

نمونه‌ها:

| تگ | مفهوم |
|---|---|
| `<header>` | سربرگ |
| `<nav>` | ناوبری |
| `<main>` | محتوای اصلی |
| `<section>` | بخش موضوعی |
| `<article>` | محتوای مستقل |
| `<aside>` | محتوای جانبی |
| `<footer>` | پابرگ |
| `<figure>` | محتوای تصویری یا مستقل |
| `<figcaption>` | توضیح محتوای figure |

### تگ‌های Non-Semantic

این تگ‌ها به‌تنهایی مفهوم خاصی درباره نوع محتوای خود ارائه نمی‌کنند.

| تگ | کاربرد |
|---|---|
| `<div>` | ایجاد یک بخش عمومی و بلوکی |
| `<span>` | مشخص کردن یک بخش عمومی درون متن |

برای مثال:

```html
<div>
    <h2>درباره ما</h2>
    <p>اطلاعات مربوط به مجموعه</p>
</div>
```

در این مثال، مشخص نیست که این قسمت یک بخش موضوعی، محتوای مستقل یا قسمت دیگری از صفحه است.

اما با استفاده از تگ مناسب:

```html
<section>
    <h2>درباره ما</h2>
    <p>اطلاعات مربوط به مجموعه</p>
</section>
```

مفهوم این قسمت مشخص‌تر می‌شود.

**نکته:** استفاده از `<div>` و `<span>` اشتباه نیست. هر زمان تگ معنایی مناسبی برای یک محتوا وجود نداشته باشد، استفاده از این تگ‌ها کاملاً منطقی است.

# معرفی تگ‌های مفهومی اصلی

## header

تگ `<header>` برای مشخص کردن سربرگ یک صفحه یا یک بخش مستقل از محتوا استفاده می‌شود.

این تگ معمولاً شامل موارد زیر است:

- لوگوی سایت
- عنوان سایت
- عنوان یک مقاله
- توضیحات ابتدایی
- لینک‌های معرفی یا ناوبری

### مثال:

```html
<header>
    <h1>وب‌سایت آموزش برنامه‌نویسی</h1>

    <p>مرجع آموزش توسعه وب</p>

    <nav>
        <a href="/">خانه</a>
        <a href="/courses">دوره‌ها</a>
        <a href="/about">درباره ما</a>
    </nav>
</header>
```

در این مثال، تگ `<header>` سربرگ اصلی سایت را مشخص می‌کند.

### نکات مهم درباره header

1. یک صفحه می‌تواند بیش از یک تگ `<header>` داشته باشد.
2. می‌توان از `<header>` داخل تگ‌های `<article>` و `<section>` استفاده کرد.
3. تگ `<header>` الزاماً نباید شامل منوی سایت باشد.
4. استفاده از `<header>` برای سربرگ مقاله یا یک بخش نیز کاملاً معتبر است.
5. تگ `<header>` نباید داخل `<footer>`، `<address>` یا یک تگ `<header>` دیگر قرار بگیرد.

### نمونه:

```html
<article>
    <header>
        <h2>آموزش HTML5</h2>
        <p>نویسنده: علی رضایی</p>
        <p>تاریخ انتشار: 1405/01/15</p>
    </header>

    <p>
        در این مقاله با مفاهیم HTML5 آشنا می‌شویم.
    </p>
</article>
```

در این مثال، `<header>` مربوط به خود مقاله است، نه کل وب‌سایت.

## nav

تگ `<nav>` برای مشخص کردن بخش‌هایی از صفحه استفاده می‌شود که شامل لینک‌های ناوبری مهم هستند.

هدف این تگ کمک به کاربران و فناوری‌های کمکی برای پیدا کردن قسمت‌های مختلف سایت است.

### کاربردهای nav

- منوی اصلی سایت
- منوی دسته‌بندی‌ها
- لینک‌های ناوبری مقالات
- فهرست مطالب یک صفحه
- لینک‌های هدایت به صفحات مهم

### مثال:

```html
<nav>
    <ul>
        <li>
            <a href="/">صفحه اصلی</a>
        </li>

        <li>
            <a href="/articles">مقالات</a>
        </li>

        <li>
            <a href="/products">محصولات</a>
        </li>

        <li>
            <a href="/contact">تماس با ما</a>
        </li>
    </ul>
</nav>
```

### استفاده از چند nav در یک صفحه

یک صفحه می‌تواند چندین تگ `<nav>` داشته باشد.

برای مثال:

```html
<header>
    <nav aria-label="منوی اصلی">
        <a href="/">خانه</a>
        <a href="/blog">وبلاگ</a>
        <a href="/contact">تماس</a>
    </nav>
</header>

<main>
    <article>
        <h1>آموزش HTML</h1>

        <nav aria-label="فهرست مطالب">
            <ul>
                <li><a href="#intro">مقدمه</a></li>
                <li><a href="#elements">تگ‌های HTML</a></li>
                <li><a href="#summary">جمع‌بندی</a></li>
            </ul>
        </nav>

        <section id="intro">
            <h2>مقدمه</h2>
            <p>محتوای مقدمه</p>
        </section>

        <section id="elements">
            <h2>تگ‌های HTML</h2>
            <p>محتوای آموزشی</p>
        </section>

        <section id="summary">
            <h2>جمع‌بندی</h2>
            <p>خلاصه مطالب</p>
        </section>
    </article>
</main>
```

در این مثال دو تگ `<nav>` وجود دارد:

- یکی برای منوی اصلی سایت
- دیگری برای فهرست مطالب مقاله

استفاده از ویژگی `aria-label` باعث می‌شود هدف هر ناوبری برای فناوری‌های کمکی مشخص‌تر باشد.

### نکته مهم

تمام لینک‌های موجود در صفحه نباید داخل `<nav>` قرار بگیرند.

برای مثال، لینک‌های پراکنده در متن یک مقاله یا لینک‌های معمولی داخل توضیحات، الزاماً ناوبری محسوب نمی‌شوند.

## main

تگ `<main>` برای مشخص کردن محتوای اصلی و منحصربه‌فرد یک صفحه استفاده می‌شود.

محتوای این تگ باید با هدف اصلی صفحه ارتباط مستقیم داشته باشد.

### مثال:

```html
<main>
    <h1>آموزش طراحی سایت</h1>

    <section>
        <h2>آموزش HTML</h2>
        <p>آشنایی با ساختار صفحات وب</p>
    </section>

    <section>
        <h2>آموزش CSS</h2>
        <p>آشنایی با طراحی و ظاهر صفحات وب</p>
    </section>

    <section>
        <h2>آموزش JavaScript</h2>
        <p>آشنایی با برنامه‌نویسی در وب</p>
    </section>
</main>
```

در این مثال، تمام محتوای اصلی صفحه داخل `<main>` قرار گرفته است.

### نکات مهم درباره main

1. در هر صفحه نباید بیش از یک تگ `<main>` بدون ویژگی `hidden` وجود داشته باشد.
2. تگ `<main>` نباید داخل تگ‌های `<header>`، `<footer>`، `<nav>`، `<article>`، `<aside>` یا `<section>` قرار بگیرد.
3. محتوای تکرارشونده بین صفحات، مانند منوی اصلی، لوگو و اطلاعات عمومی سایت، معمولاً نباید داخل `<main>` قرار بگیرد.
4. بهتر است تگ `<main>` مستقیماً در ساختار اصلی صفحه قرار بگیرد.

### ساختار پیشنهادی:

```html
<body>

    <header>
        <h1>نام وب‌سایت</h1>
    </header>

    <nav>
        <a href="/">خانه</a>
        <a href="/about">درباره ما</a>
    </nav>

    <main>
        <h1>عنوان اصلی صفحه</h1>
        <p>محتوای اصلی صفحه</p>
    </main>

    <footer>
        <p>تمامی حقوق محفوظ است.</p>
    </footer>

</body>
```

## section

تگ `<section>` برای گروه‌بندی محتوایی استفاده می‌شود که از نظر موضوعی با یکدیگر ارتباط دارند.

در واقع، زمانی که می‌خواهیم یک قسمت مشخص از صفحه را به یک موضوع اختصاص دهیم، استفاده از `<section>` انتخاب مناسبی است.

### مثال:

```html
<main>

    <h1>آموزش برنامه‌نویسی</h1>

    <section>
        <h2>آموزش HTML</h2>

        <p>
            HTML زبان نشانه‌گذاری صفحات وب است.
        </p>
    </section>

    <section>
        <h2>آموزش CSS</h2>

        <p>
            CSS برای تعریف ظاهر و نحوه نمایش صفحات وب استفاده می‌شود.
        </p>
    </section>

    <section>
        <h2>آموزش JavaScript</h2>

        <p>
            JavaScript برای افزودن رفتار و تعامل به صفحات وب استفاده می‌شود.
        </p>
    </section>

</main>
```

در این مثال، سه بخش موضوعی مجزا داریم.

### چه زمانی از section استفاده کنیم؟

زمانی از این تگ استفاده کنید که:

- محتوای صفحه به چند موضوع مشخص تقسیم شده باشد.
- هر قسمت دارای عنوان یا مفهوم مستقل باشد.
- بخواهید ساختار موضوعی صفحه را مشخص کنید.
- محتوای داخل یک قسمت از نظر معنایی با یکدیگر ارتباط داشته باشند.

### نکته مهم درباره section

معمولاً بهتر است هر `<section>` دارای یک عنوان مشخص باشد.

این عنوان می‌تواند با یکی از تگ‌های زیر تعریف شود:

```html
<h1>
<h2>
<h3>
<h4>
<h5>
<h6>
```

مثال:

```html
<section>
    <h2>مزایای HTML5</h2>

    <p>
        HTML5 ساختار استانداردتری برای صفحات وب فراهم می‌کند.
    </p>
</section>
```

اگر هدف شما صرفاً گروه‌بندی عناصر برای مقاصد عمومی و بدون ایجاد یک بخش موضوعی باشد، بهتر است از `<div>` استفاده کنید.

## article

تگ `<article>` برای نمایش محتوایی مستقل و خودکفا استفاده می‌شود.

محتوایی که داخل این تگ قرار می‌گیرد باید به‌گونه‌ای باشد که بتوان آن را به‌صورت مستقل منتشر کرد یا در قسمت دیگری از سایت نمایش داد.

### نمونه کاربردهای article

- مقالات وبلاگ
- اخبار
- پست‌های انجمن
- نظرات کاربران
- معرفی محصولات
- مطالب آموزشی مستقل

### مثال:

```html
<main>

    <h1>آخرین مقالات</h1>

    <article>
        <header>
            <h2>آموزش HTML5</h2>
            <p>نویسنده: علی رضایی</p>
        </header>

        <p>
            HTML5 یکی از استانداردهای مهم توسعه صفحات وب است.
        </p>

        <a href="/articles/html5">
            مطالعه مقاله
        </a>

        <footer>
            <p>دسته‌بندی: آموزش وب</p>
        </footer>
    </article>

    <article>
        <header>
            <h2>آشنایی با Semantic HTML</h2>
            <p>نویسنده: محمد احمدی</p>
        </header>

        <p>
            تگ‌های معنایی باعث بهبود ساختار صفحات HTML می‌شوند.
        </p>

        <a href="/articles/semantic-html">
            مطالعه مقاله
        </a>
    </article>

</main>
```

در این مثال هر مقاله یک محتوای مستقل است؛ بنابراین از `<article>` استفاده شده است.

### امکان استفاده از article تو در تو

در بعضی ساختارها می‌توان یک `<article>` را داخل یک `<article>` دیگر قرار داد.

برای مثال:

```html
<article>
    <h1>آموزش HTML</h1>

    <p>
        این مقاله درباره زبان HTML است.
    </p>

    <article>
        <h2>نظر کاربر اول</h2>
        <p>مقاله بسیار مفیدی بود.</p>
    </article>

    <article>
        <h2>نظر کاربر دوم</h2>
        <p>توضیحات کاملی داشت.</p>
    </article>
</article>
```

در این ساختار، نظرات کاربران به‌عنوان محتواهای مستقل درون مقاله اصلی قرار گرفته‌اند.

## aside

تگ `<aside>` برای نمایش محتوای جانبی و مرتبط با محتوای اصلی صفحه استفاده می‌شود.

این محتوا معمولاً نقش مکمل دارد و در صورت حذف آن، مفهوم اصلی محتوای صفحه همچنان قابل درک خواهد بود.

### کاربردهای aside

- مطالب مرتبط
- لینک‌های پیشنهادی
- معرفی نویسنده
- فهرست مقالات محبوب
- تبلیغات مرتبط
- اطلاعات تکمیلی
- منابع و مراجع مرتبط

### مثال:

```html
<main>

    <article>
        <h1>آموزش HTML5</h1>

        <p>
            HTML5 استانداردی برای ساختار صفحات وب است.
        </p>

        <p>
            با استفاده از HTML می‌توان بخش‌های مختلف یک صفحه را مشخص کرد.
        </p>
    </article>

    <aside>
        <h2>مطالب مرتبط</h2>

        <ul>
            <li>
                <a href="/html-basics">
                    مبانی HTML
                </a>
            </li>

            <li>
                <a href="/semantic-html">
                    آموزش Semantic HTML
                </a>
            </li>

            <li>
                <a href="/html5">
                    ویژگی‌های HTML5
                </a>
            </li>
        </ul>
    </aside>

</main>
```

در این مثال، مقاله محتوای اصلی است و قسمت مطالب مرتبط در تگ `<aside>` قرار گرفته است.

### استفاده از aside داخل article

تگ `<aside>` می‌تواند در داخل یک مقاله نیز قرار بگیرد.

مثال:

```html
<article>

    <h1>آموزش HTML</h1>

    <p>
        HTML زبان نشانه‌گذاری صفحات وب است.
    </p>

    <aside>
        <h2>نکته آموزشی</h2>

        <p>
            HTML مخفف HyperText Markup Language است.
        </p>
    </aside>

    <p>
        با استفاده از HTML می‌توان ساختار محتوای وب را مشخص کرد.
    </p>

</article>
```

در این مثال، محتوای داخل `<aside>` یک توضیح تکمیلی مرتبط با مقاله است.

### نکته مهم

از `<aside>` صرفاً برای هر محتوایی که در کنار محتوای اصلی قرار گرفته است استفاده نکنید.

مهم‌ترین معیار، ارتباط معنایی و جانبی بودن محتوا است، نه موقعیت ظاهری آن.

## footer

تگ `<footer>` برای مشخص کردن اطلاعات انتهایی یک صفحه یا یک بخش مستقل استفاده می‌شود.

این تگ معمولاً شامل اطلاعاتی مانند موارد زیر است:

- اطلاعات کپی‌رایت
- اطلاعات نویسنده
- لینک‌های مرتبط
- اطلاعات تماس
- لینک‌های قوانین و مقررات
- منابع و مراجع

### مثال:

```html
<footer>
    <p>تمامی حقوق این وب‌سایت محفوظ است.</p>

    <nav aria-label="لینک‌های پایین صفحه">
        <a href="/about">درباره ما</a>
        <a href="/privacy">حریم خصوصی</a>
        <a href="/contact">تماس با ما</a>
    </nav>
</footer>
```

### نکات مهم درباره footer

1. یک صفحه می‌تواند چندین تگ `<footer>` داشته باشد.
2. می‌توان از `<footer>` برای انتهای یک مقاله یا بخش استفاده کرد.
3. تگ `<footer>` الزاماً فقط برای انتهای کل صفحه نیست.
4. معمولاً اطلاعات نویسنده، تاریخ انتشار و منابع مقاله می‌توانند داخل footer مقاله قرار بگیرند.

### مثال footer داخل article

```html
<article>

    <header>
        <h1>آموزش HTML5</h1>
    </header>

    <p>
        در این مقاله با ساختار HTML5 آشنا می‌شویم.
    </p>

    <footer>
        <p>نویسنده: علی رضایی</p>
        <p>دسته‌بندی: HTML</p>
    </footer>

</article>
```

# تفاوت section و article

یکی از سؤالات مهم هنگام استفاده از Semantic HTML این است که چه زمانی باید از `<section>` و چه زمانی از `<article>` استفاده کنیم.

هر دو تگ برای سازمان‌دهی محتوا استفاده می‌شوند، اما مفهوم متفاوتی دارند.

| ویژگی | section | article |
|---|---|---|
| مفهوم | بخش موضوعی محتوا | محتوای مستقل |
| استقلال محتوا | لزوماً مستقل نیست | باید خودکفا باشد |
| کاربرد | تقسیم محتوا به موضوعات | مقاله، خبر، پست |
| امکان استفاده تو در تو | بله | بله |
| نیاز معمول به عنوان | بله | بله |

### مثال section

```html
<section>
    <h2>مزایای HTML5</h2>

    <p>HTML5 ساختار استانداردتری ایجاد می‌کند.</p>
</section>
```

این بخش موضوعی از یک صفحه است و لزوماً به‌تنهایی یک محتوای مستقل محسوب نمی‌شود.

### مثال article

```html
<article>
    <h2>HTML5 چیست؟</h2>

    <p>
        HTML5 مجموعه‌ای از قابلیت‌ها و استانداردهای مرتبط
        با توسعه صفحات وب را معرفی می‌کند.
    </p>
</article>
```

این محتوا می‌تواند به‌عنوان یک مقاله مستقل منتشر شود.

### استفاده هم‌زمان از section و article

این دو تگ می‌توانند در کنار یکدیگر استفاده شوند.

```html
<main>

    <section>
        <h1>مقالات برنامه‌نویسی</h1>

        <article>
            <h2>آموزش HTML</h2>
            <p>محتوای مقاله HTML</p>
        </article>

        <article>
            <h2>آموزش CSS</h2>
            <p>محتوای مقاله CSS</p>
        </article>

    </section>

</main>
```

در این مثال:

- `<section>` مجموعه مقالات برنامه‌نویسی را مشخص می‌کند.
- هر `<article>` یک مقاله مستقل است.

**قاعده ساده:** اگر محتوا یک بخش موضوعی از صفحه است، از `section` استفاده کنید؛ اگر محتوا به‌تنهایی یک واحد مستقل و قابل انتشار است، از `article` استفاده کنید.

# تفاوت header و footer

این دو تگ از نظر نقش مکمل یکدیگر هستند.

| ویژگی | header | footer |
|---|---|---|
| کاربرد | معرفی و سربرگ | اطلاعات انتهایی |
| محل استفاده | ابتدای صفحه یا بخش | انتهای صفحه یا بخش |
| محتوای معمول | عنوان، لوگو، معرفی | نویسنده، منابع، کپی‌رایت |
| تعداد مجاز | چندین مورد | چندین مورد |

مثال:

```html
<article>

    <header>
        <h1>آموزش Semantic HTML</h1>
        <p>آشنایی با تگ‌های معنایی</p>
    </header>

    <p>
        تگ‌های معنایی باعث بهبود ساختار HTML می‌شوند.
    </p>

    <footer>
        <p>نویسنده: علی رضایی</p>
        <p>تاریخ انتشار: 1405/01/15</p>
    </footer>

</article>
```

در این مثال، header اطلاعات ابتدایی مقاله و footer اطلاعات انتهایی همان مقاله را مشخص می‌کند.

# نحوه ترکیب تگ‌های Semantic

قدرت اصلی تگ‌های معنایی زمانی مشخص می‌شود که بتوانیم آن‌ها را به‌درستی در کنار یکدیگر استفاده کنیم.

برای طراحی ساختار یک وب‌سایت معمولاً از ترکیب چند تگ استفاده می‌شود.

### الگوی کلی ساختار صفحه

```text
body
│
├── header
│   ├── Logo
│   └── nav
│
├── main
│   ├── section
│   │   ├── article
│   │   └── article
│   │
│   ├── section
│   │   └── article
│   │
│   └── aside
│
└── footer
```

این ساختار یک الگوی رایج است، اما تنها ساختار معتبر HTML نیست.

برای مثال، می‌توان `<aside>` را داخل `<article>` قرار داد یا برای هر مقاله یک `<header>` و `<footer>` جداگانه تعریف کرد.
