# تگ‌های متنی HTML (HTML Text Tags)

HTML مخفف **HyperText Markup Language** است و برای ساختاردهی محتوای صفحات وب استفاده می‌شود.

تگ‌های متنی HTML به مرورگر کمک می‌کنند تا بخش‌های مختلف متن را تشخیص دهد؛ برای مثال:

- عنوان اصلی صفحه
- عنوان بخش‌ها و زیربخش‌ها
- پاراگراف‌های متنی
- نقل‌قول‌ها
- متن‌های مهم و تأکیدی
- متن‌های کوتاه کد و اطلاعات تخصصی

هر تگ HTML معمولاً از یک تگ شروع و یک تگ پایان تشکیل می‌شود.

ساختار عمومی:

```html
<tagname>محتوای متنی</tagname>
```

مثال:

```html
<p>این یک پاراگراف ساده است.</p>
```

در این مثال:

- `<p>` تگ شروع پاراگراف است.
- `این یک پاراگراف ساده است.` محتوای پاراگراف است.
- `</p>` تگ پایان پاراگراف است.

**نکته:** بعضی از تگ‌های HTML، مانند `<br>` و `<hr>`، تگ پایان ندارند.

## سرتیترها (Headings)

سرتیترها برای مشخص‌کردن عنوان اصلی و عنوان بخش‌های مختلف یک صفحه استفاده می‌شوند.

HTML شش سطح سرتیتر دارد:

- `<h1>` : بالاترین سطح عنوان
- `<h2>` : عنوان بخش اصلی
- `<h3>` : عنوان زیربخش
- `<h4>` : عنوان زیرمجموعه
- `<h5>` : سطح پایین‌تر عنوان
- `<h6>` : پایین‌ترین سطح عنوان

### تگ `<h1>`

تگ `<h1>` برای عنوان اصلی و مهم‌ترین عنوان محتوای صفحه یا بخش استفاده می‌شود.

مثال:

```html
<h1>آموزش HTML از صفر تا صد</h1>
```

کاربردهای متداول:

- عنوان اصلی یک مقاله
- عنوان صفحه معرفی محصول
- عنوان اصلی محتوای یک صفحه آموزشی

بهتر است هر صفحه یک عنوان اصلی مشخص و معنادار داشته باشد؛ بااین‌حال، استفاده از چند `<h1>` نیز در HTML معتبر است، اگر ساختار محتوا آن را توجیه کند.

### تگ `<h2>`

تگ `<h2>` برای عنوان بخش‌های اصلی زیرمجموعه عنوان بالاتر استفاده می‌شود.

```html
<h1>آموزش HTML</h1>

<h2>مقدمه</h2>
<p>HTML زبان نشانه‌گذاری صفحات وب است.</p>

<h2>ساختار یک صفحه</h2>
<p>هر صفحه HTML معمولاً ساختار مشخصی دارد.</p>
```

در این مثال، دو بخش اصلی زیر عنوان `<h1>` قرار گرفته‌اند.

### تگ `<h3>`

تگ `<h3>` برای زیربخش‌های یک عنوان `<h2>` استفاده می‌شود.

```html
<h2>تگ‌های متنی</h2>

<h3>سرتیترها</h3>
<p>برای ساخت عنوان‌ها استفاده می‌شوند.</p>

<h3>پاراگراف‌ها</h3>
<p>برای نمایش متن‌های معمولی استفاده می‌شوند.</p>
```

### تگ‌های `<h4>`، `<h5>` و `<h6>`

این تگ‌ها برای نمایش سطوح پایین‌تر عنوان در ساختارهای پیچیده‌تر کاربرد دارند.

```html
<h1>آموزش طراحی وب</h1>

<h2>HTML</h2>
<h3>تگ‌های متنی</h3>
<h4>تگ‌های تأکیدی</h4>
<h5>تأکید معنایی</h5>
<h6>مثال‌های تکمیلی</h6>
```

این مثال صرفاً نحوه استفاده از سطوح مختلف را نشان می‌دهد. در یک صفحه واقعی، باید از این سطح‌بندی فقط زمانی استفاده کرد که ساختار معنایی محتوا به آن نیاز داشته باشد.

### تفاوت اندازه و اهمیت سرتیترها

مرورگرها معمولاً سرتیترهای سطح بالاتر را بزرگ‌تر نمایش می‌دهند؛ اما اندازه ظاهری آن‌ها قابل تغییر با CSS است.

| تگ | سطح معنایی | اندازه پیش‌فرض معمول |
|---|---|---|
| `<h1>` | ۱، بالاترین سطح | بزرگ‌ترین |
| `<h2>` | ۲ | بزرگ |
| `<h3>` | ۳ | متوسط رو به بزرگ |
| `<h4>` | ۴ | متوسط |
| `<h5>` | ۵ | کوچک |
| `<h6>` | ۶، پایین‌ترین سطح | کوچک‌ترین |

اندازه دقیق به مرورگر و شیوه‌نامه CSS بستگی دارد.

مثال تغییر اندازه با CSS:

```html
<h1 class="page-title">عنوان صفحه</h1>

<style>
  .page-title {
    font-size: 32px;
    color: #2563eb;
  }
</style>
```

**نکته مهم:** سرتیترها را صرفاً برای بزرگ یا کوچک کردن متن انتخاب نکنید. برای تغییر اندازه ظاهری متن، از CSS استفاده کنید.

### ساختار صحیح سرتیترها

ساختار مناسب:

```html
<h1>آموزش برنامه‌نویسی</h1>

<h2>مبانی HTML</h2>

<h3>تگ‌های متنی</h3>
<p>تگ‌های متنی ساختار محتوا را مشخص می‌کنند.</p>

<h3>تگ‌های تصویری</h3>
<p>تگ‌های تصویری برای نمایش تصاویر کاربرد دارند.</p>

<h2>مبانی CSS</h2>

<h3>انتخابگرها</h3>
<p>انتخابگرها عناصر موردنظر را مشخص می‌کنند.</p>
```

در این ساختار، عنوان‌ها سلسله‌مراتب مشخصی دارند.

از پرش بی‌دلیل بین سطوح، مانند رفتن مستقیم از `<h2>` به `<h5>`، خودداری کنید؛ مگر اینکه ساختار معنایی محتوا چنین سطحی را واقعاً ایجاب کند.

## پاراگراف‌ها (Paragraphs)

تگ `<p>` برای تعریف یک پاراگراف از متن استفاده می‌شود.

### ساختار تگ پاراگراف

```html
<p>این یک پاراگراف در HTML است.</p>
```

پاراگراف‌ها معمولاً به‌صورت یک بلوک مستقل نمایش داده می‌شوند و مرورگر به‌طور پیش‌فرض برای آن‌ها فاصله عمودی در نظر می‌گیرد.

### استفاده از چند پاراگراف

```html
<h1>آشنایی با HTML</h1>

<p>
  HTML زبان نشانه‌گذاری استاندارد برای ساختاردهی صفحات وب است.
</p>

<p>
  با استفاده از HTML می‌توان عنوان‌ها، پاراگراف‌ها، تصاویر،
  پیوندها و عناصر مختلف صفحه را تعریف کرد.
</p>
```

هر پاراگراف یک واحد مستقل از محتواست.

### تفاوت پاراگراف با نوشتن متن ساده

نمونه بدون پاراگراف:

```html
این متن اول است.
این متن دوم است.
```

مرورگر ممکن است هر دو جمله را در یک جریان متنی نمایش دهد و شکست خط موجود در فایل HTML را حفظ نکند.

نمونه با پاراگراف:

```html
<p>این متن اول است.</p>
<p>این متن دوم است.</p>
```

در این حالت، هر متن در یک بلوک جداگانه نمایش داده می‌شود.

### فاصله‌گذاری بین پاراگراف‌ها

فاصله پاراگراف‌ها را می‌توان با CSS تنظیم کرد.

```html
<p class="paragraph">پاراگراف اول</p>
<p class="paragraph">پاراگراف دوم</p>

<style>
  .paragraph {
    margin-bottom: 20px;
    line-height: 1.8;
  }
</style>
```

در این مثال:

- `margin-bottom` فاصله بیرونی پایین پاراگراف را تعیین می‌کند.
- `line-height` فاصله خطوط داخل پاراگراف را تنظیم می‌کند.

### ویژگی‌های مهم تگ `<p>`

تگ `<p>` می‌تواند از ویژگی‌های عمومی HTML مانند `id` و `class` استفاده کند.

```html
<p id="intro" class="description">
  این پاراگراف توضیحات ابتدایی صفحه است.
</p>
```

- `id` شناسه‌ای برای یک عنصر مشخص است.
- `class` برای گروه‌بندی عناصر و اعمال CSS یا انتخاب آن‌ها با JavaScript کاربرد دارد.

**نکته:** داخل `<p>` نباید عناصر بلوکی نامعتبر، مانند یک `<div>`، قرار دهید. مرورگر ممکن است پاراگراف را هنگام مواجهه با چنین عناصری به‌صورت خودکار ببندد.

## شکستن خط و خط افقی

### تگ `<br>`

تگ `<br>` برای ایجاد شکست خط در داخل یک جریان متنی استفاده می‌شود.

```html
<p>
  نام: علی رضایی<br>
  شهر: تهران<br>
  کشور: ایران
</p>
```

هر `<br>` باعث می‌شود متن بعدی از خط جدید آغاز شود.

کاربردهای مناسب:

- نشانی پستی
- شعر
- متن‌هایی که شکست خط بخشی از محتوای آن‌هاست

از `<br>` برای ایجاد فاصله‌های بزرگ بین بخش‌های صفحه استفاده نکنید؛ برای فاصله‌گذاری از CSS بهره ببرید.

### تگ `<hr>`

تگ `<hr>` نشان‌دهنده یک تغییر موضوعی یا جداکننده معنایی بین بخش‌های محتواست. مرورگرها معمولاً آن را به شکل یک خط افقی نمایش می‌دهند.

```html
<h2>بخش اول</h2>
<p>توضیحات بخش اول.</p>

<hr>

<h2>بخش دوم</h2>
<p>توضیحات بخش دوم.</p>
```

تفاوت این دو تگ:

- `<br>` شکست خط ایجاد می‌کند.
- `<hr>` جدایی موضوعی بین بخش‌های محتوا را نشان می‌دهد.

## نقل‌قول‌ها (Quotes)

HTML تگ‌های اختصاصی برای نقل‌قول‌های کوتاه و بلند دارد.

### تگ `<q>` برای نقل‌قول کوتاه

تگ `<q>` برای نقل‌قولی استفاده می‌شود که درون یک جمله قرار دارد.

```html
<p>
  معلم گفت:
  <q>تمرین مداوم، مهارت را افزایش می‌دهد.</q>
</p>
```

مرورگرها معمولاً برای `<q>` علامت نقل‌قول اضافه می‌کنند. نوع علامت به زبان و تنظیمات مرورگر بستگی دارد.

بنابراین معمولاً نیازی نیست علامت نقل‌قول را به‌صورت دستی داخل تگ قرار دهید.

### تگ `<blockquote>` برای نقل‌قول بلند

تگ `<blockquote>` برای نقل‌قول‌هایی استفاده می‌شود که به‌صورت یک بخش مستقل از متن نمایش داده می‌شوند.

```html
<blockquote>
  <p>
    یادگیری یک مهارت جدید به تمرین، تکرار و استمرار نیاز دارد.
  </p>
</blockquote>
```

مرورگرها معمولاً نقل‌قول را با تورفتگی نمایش می‌دهند، اما ظاهر آن با CSS قابل تغییر است.

### مشخص کردن منبع نقل‌قول

ویژگی `cite` می‌تواند نشانی منبع نقل‌قول را مشخص کند.

```html
<blockquote cite="https://example.com/article">
  <p>این متن از یک منبع دیگر نقل شده است.</p>
</blockquote>
```

ویژگی `cite` معمولاً به‌تنهایی پیوند قابل مشاهده‌ای در صفحه ایجاد نمی‌کند؛ بلکه اطلاعاتی درباره منبع فراهم می‌کند.

اگر بخواهید نام منبع را به کاربر نشان دهید، می‌توانید آن را جداگانه اضافه کنید:

```html
<blockquote cite="https://example.com/article">
  <p>یادگیری با تمرین بهتر می‌شود.</p>
</blockquote>

<p>
  منبع:
  <a href="https://example.com/article">مقاله آموزشی</a>
</p>
```

در این مثال، `<a>` یک پیوند واقعی برای دسترسی به منبع ایجاد می‌کند.

### استناد به منبع با تگ `<cite>`

تگ `<cite>` برای مشخص کردن عنوان یک اثر خلاقانه یا منبعی مانند کتاب، مقاله، فیلم یا اثر هنری استفاده می‌شود.

```html
<p>
  این مطلب از کتاب
  <cite>مبانی طراحی وب</cite>
  نقل شده است.
</p>
```

`<cite>` برای عنوان اثر مناسب است، نه لزوماً نام شخصی که نقل‌قول را بیان کرده است.

### تفاوت `<q>` و `<blockquote>`

| ویژگی | `<q>` | `<blockquote>` |
|---|---|---|
| کاربرد | نقل‌قول کوتاه درون متن | نقل‌قول مستقل و بلند |
| نوع نمایش | درون‌خطی | بلوکی |
| علامت نقل‌قول خودکار | معمولاً بله | معمولاً خیر |
| ویژگی `cite` | پشتیبانی می‌شود | پشتیبانی می‌شود |

## متن‌های تأکیدی و مهم

HTML تگ‌های متفاوتی برای برجسته‌کردن متن دارد. بعضی از آن‌ها اهمیت معنایی دارند و برخی بیشتر برای نمایش ظاهری به کار می‌روند.

### تگ `<strong>` برای اهمیت زیاد

تگ `<strong>` نشان می‌دهد که بخشی از محتوا اهمیت بالایی دارد.

```html
<p>
  <strong>هشدار:</strong>
  پیش از حذف فایل‌ها از اطلاعات خود نسخه پشتیبان تهیه کنید.
</p>
```

مرورگرها معمولاً متن داخل `<strong>` را ضخیم نمایش می‌دهند.

کاربردهای متداول:

- هشدارها
- نکات مهم
- اطلاعات ضروری
- بخش‌هایی که اهمیت ویژه‌ای در محتوا دارند

### تگ `<em>` برای تأکید

تگ `<em>` برای تأکید معنایی روی یک کلمه یا عبارت استفاده می‌شود.

```html
<p>
  برای یادگیری برنامه‌نویسی، <em>تمرین روزانه</em> اهمیت زیادی دارد.
</p>
```

مرورگرها معمولاً متن داخل `<em>` را مورب نمایش می‌دهند.

تأکید در این تگ می‌تواند با توجه به جایگاه آن در جمله معنای جمله را تغییر دهد.

مثال:

```html
<p>من نگفتم او فایل را حذف کرد.</p>
<p>من <em>نگفتم</em> او فایل را حذف کرد.</p>
```

در مثال دوم، روی واژه «نگفتم» تأکید شده است.

### تگ `<b>` برای جلب توجه ظاهری

تگ `<b>` متن را از نظر بصری برجسته می‌کند، بدون اینکه به‌خودی‌خود اهمیت معنایی ویژه‌ای مانند `<strong>` به آن بدهد.

```html
<p>
  کلمه <b>HTML</b> مخفف HyperText Markup Language است.
</p>
```

از `<b>` زمانی استفاده کنید که می‌خواهید توجه خواننده به یک بخش جلب شود، اما قصد انتقال اهمیت ویژه یا تأکید معنایی ندارید.

### تگ `<i>` برای متن با صدای متفاوت یا اصطلاحات

تگ `<i>` برای متنی استفاده می‌شود که از نظر معنایی با متن اطراف تفاوت دارد؛ مانند اصطلاحات تخصصی، عبارت‌های خارجی یا برخی نام‌گذاری‌ها.

```html
<p>
  عبارت <i>Responsive Design</i> به طراحی واکنش‌گرا اشاره دارد.
</p>
```

مرورگرها معمولاً متن داخل `<i>` را مورب نمایش می‌دهند.

### تگ `<u>` برای متن دارای نشانه‌گذاری

تگ `<u>` برای متن دارای نشانه‌گذاری غیرمتنی، مانند نشانه‌گذاری یک غلط املایی، قابل استفاده است.

```html
<p>
  این کلمه دارای <u>غلط املایی</u> است.
</p>
```

برای تأکید معنایی از `<em>` یا `<strong>` استفاده کنید. همچنین از زیرخط برای متن معمولی با احتیاط استفاده کنید، چون کاربران ممکن است آن را با پیوند اشتباه بگیرند.

### تگ `<mark>` برای برجسته‌سازی

تگ `<mark>` برای مشخص کردن بخشی از متن که در زمینه فعلی اهمیت یا ارتباط ویژه‌ای دارد، مناسب است.

```html
<p>
  برای شروع آموزش، ابتدا بخش <mark>مقدمات HTML</mark> را مطالعه کنید.
</p>
```

مرورگرها معمولاً متن داخل `<mark>` را با پس‌زمینه رنگی نمایش می‌دهند.

کاربردها:

- برجسته کردن نتیجه جست‌وجو
- مشخص کردن عبارت مرتبط
- نمایش بخش مهمی از متن در یک زمینه خاص

### تگ `<small>` برای توضیحات فرعی

تگ `<small>` برای توضیحات جانبی، محدودیت‌ها، یادداشت‌های حقوقی یا اطلاعات کم‌اهمیت‌تر استفاده می‌شود.

```html
<p>
  قیمت محصول: ۵۰۰ هزار تومان
  <small>قیمت‌ها ممکن است تغییر کنند.</small>
</p>
```

مرورگرها معمولاً متن داخل `<small>` را کوچک‌تر نمایش می‌دهند.

### تگ `<del>` برای متن حذف‌شده

تگ `<del>` نشان می‌دهد که بخشی از محتوا از نسخه قبلی حذف شده است.

```html
<p>
  قیمت قبلی:
  <del>۸۰۰ هزار تومان</del>
</p>
```

مرورگرها معمولاً روی متن خط می‌کشند.

### تگ `<ins>` برای متن اضافه‌شده

تگ `<ins>` برای نشان دادن محتوایی استفاده می‌شود که به سند اضافه شده است.

```html
<p>
  قیمت جدید:
  <ins>۶۰۰ هزار تومان</ins>
</p>
```

مرورگرها معمولاً متن اضافه‌شده را زیرخط‌دار نمایش می‌دهند.

### تفاوت تگ‌های مهم و تأکیدی

| تگ | مفهوم اصلی | نمایش معمول |
|---|---|---|
| `<strong>` | اهمیت زیاد | ضخیم |
| `<em>` | تأکید معنایی | مورب |
| `<b>` | جلب توجه بدون اهمیت معنایی ویژه | ضخیم |
| `<i>` | متن با حالت یا صدای متفاوت | مورب |
| `<u>` | نشانه‌گذاری غیرمتنی | زیرخط |
| `<mark>` | برجسته‌سازی مرتبط با زمینه | پس‌زمینه رنگی |
| `<small>` | توضیحات فرعی | کوچک‌تر |
| `<del>` | محتوای حذف‌شده | خط‌خورده |
| `<ins>` | محتوای اضافه‌شده | معمولاً زیرخط‌دار |

**نکته کلیدی:** ظاهر عناصر را می‌توان با CSS تغییر داد. انتخاب تگ باید بر اساس معنای محتوا باشد، نه فقط شکل ظاهری آن.

## سایر تگ‌های متنی پرکاربرد

### تگ `<span>`

تگ `<span>` یک ظرف درون‌خطی عمومی است که برای انتخاب یا استایل‌دهی به بخشی از متن استفاده می‌شود. این تگ به‌تنهایی معنای خاصی به محتوا اضافه نمی‌کند.

```html
<p>
  زبان <span class="highlight">HTML</span> ساختار صفحه را مشخص می‌کند.
</p>

<style>
  .highlight {
    color: blue;
    font-weight: bold;
  }
</style>
```

### تگ `<code>`

تگ `<code>` برای نمایش قطعه‌های کد برنامه‌نویسی درون متن استفاده می‌شود.

```html
<p>
  برای ایجاد پاراگراف از تگ <code>&lt;p&gt;</code> استفاده می‌کنیم.
</p>
```

در این مثال از `&lt;` و `&gt;` استفاده شده تا علامت‌های `<` و `>` به‌عنوان متن نمایش داده شوند.

### تگ `<pre>`

تگ `<pre>` متن از پیش قالب‌بندی‌شده را نمایش می‌دهد و معمولاً فاصله‌ها و شکست خطوط آن را حفظ می‌کند.

```html
<pre>
خط اول
    خط دوم با فاصله ابتدایی
خط سوم
</pre>
```

برای نمایش بلوک کد می‌توان آن را همراه با `<code>` استفاده کرد:

```html
<pre><code>
function greet() {
  console.log("Hello!");
}
</code></pre>
```

### تگ `<sub>` برای زیرنویس

تگ `<sub>` متن را به‌صورت زیرنویس نمایش می‌دهد.

```html
<p>فرمول شیمیایی آب: H<sub>2</sub>O</p>
```

### تگ `<sup>` برای بالانویس

تگ `<sup>` متن را به‌صورت بالانویس نمایش می‌دهد.

```html
<p>مساحت مربع: a<sup>2</sup></p>
```

### تگ `<abbr>` برای مخفف‌ها

تگ `<abbr>` برای مشخص کردن یک مخفف یا عبارت کوتاه‌شده استفاده می‌شود.

```html
<p>
  <abbr title="HyperText Markup Language">HTML</abbr>
  زبان نشانه‌گذاری صفحات وب است.
</p>
```

ویژگی `title` معمولاً توضیح کامل مخفف را در اختیار کاربر قرار می‌دهد، هرچند نحوه دسترسی به این توضیح در دستگاه‌های مختلف یکسان نیست.

### تگ `<time>` برای تاریخ و زمان

تگ `<time>` برای مشخص کردن تاریخ یا زمان استفاده می‌شود.

```html
<p>
  تاریخ انتشار:
  <time datetime="2026-10-26">۲۶ اکتبر ۲۰۲۶</time>
</p>
```

مقدار `datetime` تاریخ را در قالبی ماشین‌خوان مشخص می‌کند.

## تفاوت تگ‌های مشابه

برخی تگ‌ها ممکن است ظاهر یکسانی داشته باشند، اما از نظر معنایی متفاوت‌اند.

### تفاوت `<strong>` و `<b>`

```html
<p><strong>هشدار مهم</strong></p>
<p><b>نام محصول</b></p>
```

- `<strong>` اهمیت محتوایی را مشخص می‌کند.
- `<b>` توجه بصری را به متن جلب می‌کند، بدون اینکه الزاماً اهمیت معنایی ویژه‌ای داشته باشد.

### تفاوت `<em>` و `<i>`

```html
<p>این کار <em>بسیار مهم</em> است.</p>
<p>اصطلاح <i>Frontend</i> در توسعه وب کاربرد دارد.</p>
```

- `<em>` برای تأکید معنایی استفاده می‌شود.
- `<i>` برای متن با حالت یا ماهیت متفاوت، مانند اصطلاحات تخصصی، استفاده می‌شود.

### تفاوت `<p>` و `<br>`

```html
<p>پاراگراف اول</p>
<p>پاراگراف دوم</p>
```

در مقابل:

```html
<p>خط اول<br>خط دوم</p>
```

- `<p>` یک پاراگراف مستقل می‌سازد.
- `<br>` فقط شکست خط ایجاد می‌کند.

### تفاوت `<q>` و `<blockquote>`

- `<q>` برای نقل‌قول درون‌خطی مناسب است.
- `<blockquote>` برای نقل‌قول مستقل و معمولاً طولانی مناسب است.

### تفاوت `<h1>` تا `<h6>` با متن ضخیم

این دو روش معادل نیستند:

```html
<h2>عنوان بخش</h2>
```

```html
<p><strong>عنوان بخش</strong></p>
```

هر دو ممکن است متن برجسته‌ای نمایش دهند، اما فقط `<h2>` یک عنوان واقعی در ساختار سند ایجاد می‌کند.

## نکات مهم و بهترین روش‌ها

### از تگ مناسب برای معنای مناسب استفاده کنید

تگ HTML را با توجه به هدف محتوایی آن انتخاب کنید.

مثال صحیح:

```html
<h2>مزایای HTML</h2>
<p>HTML ساختار صفحه را تعریف می‌کند.</p>
```

برای ایجاد ظاهر متفاوت، از CSS استفاده کنید؛ نه اینکه عنوان‌ها را صرفاً برای اندازه فونت انتخاب کنید.

###  ساختار عنوان‌ها را رعایت کنید

عنوان‌ها باید سلسله‌مراتب منطقی داشته باشند.

```html
<h1>عنوان اصلی</h1>
<h2>بخش اول</h2>
<h3>زیربخش اول</h3>
<h2>بخش دوم</h2>
```

ساختار صحیح عنوان‌ها به کاربران، فناوری‌های کمکی و موتورهای جست‌وجو در درک بهتر محتوا کمک می‌کند.

### از تگ‌های معنایی برای دسترس‌پذیری استفاده کنید

تگ‌هایی مانند `<strong>`، `<em>` و سرتیترها اطلاعات معنایی ارائه می‌دهند. این اطلاعات می‌تواند به کاربران فناوری‌های کمکی کمک کند تا ساختار و اهمیت محتوا را بهتر درک کنند.

رنگ یا ضخامت به‌تنهایی نباید تنها راه انتقال یک هشدار یا مفهوم مهم باشد.

### از `<br>` برای فاصله‌گذاری استفاده نکنید

روش نامناسب:

```html
<p>پاراگراف اول</p>
<br><br><br>
<p>پاراگراف دوم</p>
```

روش بهتر:

```html
<p class="first">پاراگراف اول</p>
<p>پاراگراف دوم</p>

<style>
  .first {
    margin-bottom: 30px;
  }
</style>
```

### تگ‌ها را به‌درستی تو در تو قرار دهید

ساختار صحیح:

```html
<p>
  این یک <strong>متن مهم</strong> است.
</p>
```

ساختار نادرست:

```html
<p>
  این یک <strong>متن مهم</p></strong>
```

تگ‌ها باید به ترتیب معکوس باز شدنشان بسته شوند.

### جهت نوشتار فارسی را مشخص کنید

برای صفحات فارسی بهتر است زبان و جهت نوشتار سند را مشخص کنید.

```html
<html lang="fa" dir="rtl">
```

این کار به مرورگر و فناوری‌های کمکی کمک می‌کند زبان و جهت کلی متن را تشخیص دهند.

برای متن‌های دارای جهت متفاوت، مانند قطعه کد یا برخی عبارت‌های انگلیسی، می‌توان از CSS یا ویژگی‌های مناسب جهت نوشتار استفاده کرد.

### از تگ‌های منسوخ‌شده استفاده نکنید

برای مثال، تگ قدیمی `<font>` برای تغییر فونت و رنگ استفاده می‌شد؛ اما در HTML مدرن باید این کار را با CSS انجام داد.

روش قدیمی:

```html
<font color="red" size="5">متن نمونه</font>
```

روش پیشنهادی:

```html
<p class="sample">متن نمونه</p>

<style>
  .sample {
    color: red;
    font-size: 24px;
  }
</style>
```

### محتوای فارسی و کد را درست نمایش دهید

در فایل HTML فارسی از UTF-8 استفاده کنید:

```html
<meta charset="UTF-8">
```

برای نمایش تگ‌ها به‌عنوان متن، از نویسه‌های مخصوص HTML استفاده کنید:

```html
<p>تگ پاراگراف: &lt;p&gt;</p>
```

در این حالت، مرورگر عبارت `<p>` را به‌عنوان متن نمایش می‌دهد، نه به‌عنوان یک تگ واقعی.
