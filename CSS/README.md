# CSS 

**CSS (Cascading Style Sheets)** زبانی برای طراحی و زیباسازی صفحات وب است. با استفاده از CSS می‌توان ظاهر عناصر HTML را تغییر داد و نحوه نمایش آن‌ها را در مرورگر کنترل کرد.

## کاربردهای CSS
- تغییر رنگ متن و پس‌زمینه
- تنظیم اندازه و نوع فونت
- تعیین فاصله بین عناصر
- طراحی چیدمان صفحات وب
- ایجاد انیمیشن و افکت‌های بصری
- واکنش‌گرا کردن صفحات برای موبایل و تبلت (Responsive Design)

## روش استفاده از CSS

### 1. Inline CSS
نوشتن CSS مستقیماً داخل تگ HTML:

```html
<p style="color: red;">Hello World</p>
```

### 2. Internal CSS
نوشتن CSS داخل تگ `<style>` در فایل HTML:

```html
<style>
  p {
    color: blue;
  }
</style>
```

### 3. External CSS
نوشتن کدهای CSS در یک فایل جداگانه با پسوند `.css`:

```css
/* style.css */
p {
  color: green;
  font-size: 18px;
}
```

اتصال فایل CSS به HTML:

```html
<link rel="stylesheet" href="style.css">
```

## ساختار دستورات CSS

```css
selector {
  property: value;
}
```

- **Selector:** انتخاب عنصر HTML
- **Property:** ویژگی موردنظر
- **Value:** مقدار ویژگی

## مثال

```css
h1 {
  color: red;
  font-size: 32px;
  text-align: center;
}
```

## ویژگی‌های مهم CSS

| ویژگی | کاربرد |
|---|---|
| `color` | رنگ متن |
| `background-color` | رنگ پس‌زمینه |
| `font-size` | اندازه فونت |
| `margin` | فاصله خارجی |
| `padding` | فاصله داخلی |
| `border` | حاشیه |
| `display` | نحوه نمایش عناصر |
| `position` | موقعیت عناصر |
| `flex` | چیدمان انعطاف‌پذیر |
| `grid` | چیدمان شبکه‌ای |

## مفاهیم و مباحث کلیدی

در این بخش، تمرین‌ها و نمونه‌کارهای مرتبط با موارد زیر قرار می‌گیرد:

1.**مبانی و سلکتورها:**
   - انواع سلکتورها: تگی (`tag`)، کلاسی (`.class`)، آیدی (`#id`)
   - ترکیب سلکتورها و سلکتورهای پیشرفته (Attribute, Child, Pseudo-classes)
   - ویژگی‌های پایه‌ای مانند رنگ (`color`)، پس‌زمینه (`background`) و فونت‌ها (`font`)

2.**مدل جعبه‌ای (Box Model):**
   - درک عمیق `margin`، `padding`، `border` و `content`
   - کنترل ابعاد عناصر با `width` و `height` و ویژگی `box-sizing`

3.**سیستم‌های چیدمان (Layout):**
   - چیدمان‌های سنتی با `display: block`, `inline` و `float`
   - چیدمان مدرن و مقیاس‌پذیر با **Flexbox**
   - طراحی صفحات پیچیده‌تر با **CSS Grid**

4.**واکنش‌گرایی (Responsive Design):**
   - استفاده از **Media Queries** برای طراحی صفحات سازگار با موبایل، تبلت و دسکتاپ
   - واحدهای اندازه‌گیری نسبی (`%`, `em`, `rem`, `vh`, `vw`)

5.**افکت‌ها و ژرفای بصری:**
   - فیلترها، سایه‌ها (`box-shadow`, `text-shadow`)
   - ترنزیشن‌ها (Transitions) برای تغییرات نرم
   - ساخت انیمیشن‌های ساده و کاربردی با **Keyframes**
