# تگ‌های متنی در HTML

تگ‌های متنی در HTML برای ساختاربندی نوشته‌ها و مشخص‌کردن نقش هر بخش از متن به کار می‌روند. با استفاده از این تگ‌ها می‌توان عنوان‌ها، پاراگراف‌ها، نقل‌قول‌ها و بخش‌های مهم یا تأکیدی متن را مشخص کرد. این ساختار علاوه بر مرتب‌کردن محتوا، به مرورگرها، موتورهای جست‌وجو و ابزارهای دسترسی‌پذیری کمک می‌کند تا معنای بخش‌های مختلف صفحه را بهتر درک کنند.

## سرتیترها؛ از `<h1>` تا `<h6>`

برای عنوان‌گذاری در HTML از تگ‌های `<h1>` تا `<h6>` استفاده می‌شود. `<h1>` مهم‌ترین و اصلی‌ترین عنوان صفحه است و `<h6>` کم‌اهمیت‌ترین سطح عنوان را نشان می‌دهد. این تگ‌ها فقط برای بزرگ یا کوچک‌کردن نوشته نیستند؛ آن‌ها سلسله‌مراتب و ساختار محتوای صفحه را مشخص می‌کنند.

```html
<h1>عنوان اصلی صفحه</h1>
<h2>عنوان یک بخش</h2>
<h3>عنوان یک زیربخش</h3>
<h4>عنوان سطح چهارم</h4>
<h5>عنوان سطح پنجم</h5>
<h6>عنوان سطح ششم</h6>
```
## پاراگراف‌ها؛ <p></p>
برای نمایش یک پاراگراف از `<p>` تگ استفاده می‌شود. مرورگر معمولاً پیش و پس از هر پاراگراف فاصله‌ای ایجاد می‌کند تا متن از بخش‌های دیگر جدا و خواناتر شود. هر پاراگراف باید یک ایده یا موضوع مشخص را بیان کند.
```html
<p>
HTML برای ساختاربندی محتوای صفحه‌های وب استفاده می‌شود.
</p>
```
## تگ‌های شکست خط و جداکننده (`<br>` و `<hr>`)

تا اینجا یاد گرفتیم چطور با تگ‌های سرتیتر و پاراگراف محتوا ایجاد کنیم. اما گاهی اوقات می‌خواهیم در ظاهر صفحه تغییراتی ایجاد کنیم که ربطی به ایجاد پاراگراف جدید یا عنوان ندارد؛ مثلاً فقط می‌خواهیم متن به خط بعد برود یا یک خط جداکننده بین دو بخش بکشیم. اینجا جایی است که تگ‌های `<br>` و `<hr>` به کمک ما می‌آیند.

یک نکته بسیار مهم قبل از شروع: این دو تگ، تگ‌های **«خودبسته»** یا **Void Elements** هستند؛ یعنی برخلاف بسیاری از تگ‌های دیگر، تگ پایانی (مثل `</br>`) ندارند و بسته شدن آن‌ها درون همان تگ انجام می‌شود.

## تگ (Line Break) `<br>`

وقتی از این تگ استفاده می‌کنید، مرورگر متن را به خط بعد می‌برد، اما پاراگراف جدید نمی‌سازد (یعنی آن فاصله اضافیِ بالای و پایین پاراگراف را ایجاد نمی‌کند). این تگ معمولاً در مواردی مثل نوشتن شعر، آدرس پستی یا متن‌هایی که نیاز به شکستن مداوم خطوط دارند استفاده می‌شود.
```html
<p>
خط اول متن.<br>
این متن به دلیل استفاده از تگ بریک، در خط بعدی و بدون فاصله پاراگراف جدید نمایش داده می‌شود.
</p>
```
## تگ (Horizontal Rule) `<hr>`
این تگ یک خط افقی در عرض صفحه می‌کشد که معمولاً برای جداسازی بصری موضوعات مختلف، تغییر سکانس در داستان‌ها یا بخش‌بندی محتوا در صفحات وب به کار می‌رود.تگ `<hr>` علاوه بر کاربرد ظاهری، به مرورگر و ابزارهای خوانش صفحه نشان می‌دهد که یک تغییر موضوعی یا تماتیک در متن رخ داده است.
```html
<p>این بخش اول محتوای ما است.</p>
<hr>
<p>این بخش دوم محتوای ما است که با یک خط افقی از بخش قبل جدا شده است.</p>
```
## نقل‌قول‌ها؛ <blockquote></blockquote>
برای نمایش نقل‌قولی که از منبع دیگری گرفته شده و به‌صورت یک بخش مستقل آمده است، از `<blockquote>` تگ استفاده می‌شود. مرورگر ممکن است این بخش را با تورفتگی یا ظاهر متفاوتی نمایش دهد، اما برای تغییر ظاهر آن می‌توان از CSS کمک گرفت.
```html
<blockquote>
  <p>یادگیری هر مهارت تازه با یک گام کوچک آغاز می‌شود.</p>
</blockquote>
```
اگر لازم باشد منبع نقل‌قول را مشخص کنیم، می‌توانیم از ویژگی cite استفاده کنیم. این ویژگی نشانی منبع را نگه می‌دارد، اما معمولاً به‌تنهایی آن را به کاربر نمایش نمی‌دهد. برای نمایش نام منبع، می‌توانیم آن را جداگانه در متن بنویسیم.
```html
<blockquote cite="https://example.com/source">
  <p>یادگیری هر مهارت تازه با یک گام کوچک آغاز می‌شود.</p>
</blockquote>
<p>منبع: نام نویسنده یا کتاب</p>
```
برای نقل‌قول کوتاهی که داخل یک جمله قرار می‌گیرد، از تگ `<q>` استفاده می‌شود. مرورگرها معمولاً علامت نقل‌قول را به‌طور خودکار در اطراف محتوای آن نمایش می‌دهند.
```html
<p>
معلم گفت: <q>برای یادگیری، تمرین مداوم اهمیت دارد.</q>
</p>
```
## متن‌های تأکیدی و مهم
برای تأکید معنایی بر بخشی از متن از تگ `<em>` استفاده می‌شود. این تگ نشان می‌دهد که خواننده باید روی آن بخش تأکید کند. مرورگر معمولاً متن داخل `<em>` را به‌صورت مورب نمایش می‌دهد، اما نقش اصلی این تگ معنایی است، نه ظاهری.
```html
<p>
برای یادگیری HTML، <em>تمرین‌کردن</em> بسیار مهم است.
</p>
```
برای مشخص‌کردن متنی که اهمیت ویژه یا فوریت دارد، از تگ `<strong>` استفاده می‌شود. مرورگر معمولاً متن داخل آن را پررنگ نمایش می‌دهد. این تگ نیز معنای متن را مشخص می‌کند و فقط برای ضخیم‌کردن نوشته نیست.
```html
<p>
<strong>هشدار:</strong> پیش از انتشار صفحه، کدهای خود را بررسی کنید.
</p>
```
اگر هدف فقط تغییر ظاهر متن باشد و قصد تأکید معنایی نداشته باشیم، می‌توانیم از CSS استفاده کنیم. انتخاب تگ مناسب مهم است، چون مرورگرها و فناوری‌های کمکی مانند صفحه‌خوان‌ها از ساختار معنایی HTML برای درک بهتر محتوا استفاده می‌کنند.
