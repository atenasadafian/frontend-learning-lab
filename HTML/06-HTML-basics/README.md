# المان‌های انتخاب و ارسال اطلاعات
## بررسی `select`، `textarea` و `button`

HTML مجموعه‌ای از المان‌ها را برای دریافت اطلاعات از کاربران و ارسال آن‌ها در اختیار توسعه‌دهندگان قرار می‌دهد. سه مورد از این المان‌ها عبارت‌اند از:

| المان | کاربرد اصلی |
|---|---|
| `select` | انتخاب یک یا چند گزینه از فهرست |
| `textarea` | دریافت متن چندخطی |
| `button` | ایجاد دکمه برای ارسال فرم یا انجام یک عمل |

این المان‌ها معمولاً درون المان `form` استفاده می‌شوند، اما در صورت نیاز می‌توان آن‌ها را در بخش‌های دیگر سند HTML نیز قرار داد.

## المان `select`

المان `<select>` برای ایجاد یک فهرست انتخابی به کار می‌رود. کاربر می‌تواند از میان گزینه‌های تعریف‌شده، یک گزینه یا در صورت استفاده از ویژگی مناسب، چند گزینه را انتخاب کند.

موارد استفاده متداول:

- انتخاب کشور یا شهر
- انتخاب رشته تحصیلی
- انتخاب دسته‌بندی محصول
- انتخاب وضعیت سفارش
- انتخاب نوع حساب کاربری

### ساختار و مثال

ساختار پایه:

```html
<label for="country">کشور:</label>

<select id="country" name="country">
    <option value="ir">ایران</option>
    <option value="de">آلمان</option>
    <option value="fr">فرانسه</option>
</select>
```

در این مثال:

- `select` فهرست انتخابی را ایجاد می‌کند.
- `label` عنوان فهرست را مشخص می‌کند.
- `for="country"` بر اساس مقدار `id` به فهرست متصل می‌شود.
- `name="country"` نام فیلدی است که هنگام ارسال فرم برای این مقدار استفاده می‌شود.
- `option` هر یک از گزینه‌های قابل انتخاب را تعریف می‌کند.
- `value` مقدار ارسالی هر گزینه را تعیین می‌کند.

برای مثال، اگر کاربر گزینه آلمان را انتخاب کند، مقدار فیلد `country` برابر `de` خواهد بود.

### ویژگی‌های مهم `select`

| ویژگی | توضیح |
|---|---|
| `name` | نام فیلد هنگام ارسال فرم |
| `id` | شناسه یکتای المان در سند |
| `required` | الزامی کردن انتخاب یک گزینه معتبر |
| `multiple` | امکان انتخاب چند گزینه |
| `size` | تعداد گزینه‌هایی که به‌صورت هم‌زمان نمایش داده می‌شوند |
| `disabled` | غیرفعال کردن فهرست |
| `autofocus` | درخواست تمرکز اولیه هنگام بارگذاری صفحه |
| `form` | اتصال فهرست به یک فرم مشخص با استفاده از شناسه آن فرم |

مثال استفاده از `required`:

```html
<label for="education">مقطع تحصیلی:</label>

<select id="education" name="education" required>
    <option value="">انتخاب کنید</option>
    <option value="diploma">دیپلم</option>
    <option value="bachelor">کارشناسی</option>
    <option value="master">کارشناسی ارشد</option>
</select>
```

در این مثال، گزینه ابتدایی مقدار خالی دارد. در یک فهرست تک‌انتخابی که `required` دارد، این گزینه به‌عنوان گزینه معتبر برای تکمیل فیلد پذیرفته نمی‌شود.

### المان `option`

المان `<option>` برای تعریف هر گزینه داخل `select` استفاده می‌شود.

ویژگی‌های مهم آن عبارت‌اند از:

| ویژگی | توضیح |
|---|---|
| `value` | مقدار گزینه هنگام ارسال فرم |
| `selected` | انتخاب اولیه گزینه |
| `disabled` | جلوگیری از انتخاب گزینه |
| `label` | تعیین برچسب متنی گزینه |

مثال:

```html
<select name="language" id="language">
    <option value="">یک زبان انتخاب کنید</option>
    <option value="fa" selected>فارسی</option>
    <option value="en">انگلیسی</option>
    <option value="de">آلمانی</option>
    <option value="ru" disabled>روسی (غیرفعال)</option>
</select>
```

در این مثال، گزینه فارسی در ابتدا انتخاب شده است و گزینه روسی قابل انتخاب نیست.

**نکته:** اگر ویژگی `value` مشخص نشده باشد، مرورگر معمولاً متن گزینه را به‌عنوان مقدار آن در نظر می‌گیرد. با این حال، تعیین صریح `value` برای کنترل بهتر داده‌های ارسالی توصیه می‌شود.

### ۲.۵. المان `optgroup`

المان `<optgroup>` برای دسته‌بندی گزینه‌ها در فهرست‌های طولانی به کار می‌رود.

مثال:

```html
<label for="course">دوره آموزشی:</label>

<select id="course" name="course">
    <option value="">انتخاب دوره</option>

    <optgroup label="برنامه‌نویسی">
        <option value="html">HTML</option>
        <option value="python">Python</option>
    </optgroup>

    <optgroup label="طراحی">
        <option value="ui">طراحی رابط کاربری</option>
        <option value="ux">تجربه کاربری</option>
    </optgroup>
</select>
```

ویژگی‌های مهم `optgroup`:

- `label`: عنوان گروه گزینه‌ها
- `disabled`: غیرفعال کردن گزینه‌های آن گروه

این المان به سازمان‌دهی گزینه‌ها کمک می‌کند، به‌خصوص زمانی که تعداد گزینه‌ها زیاد باشد.

### ۲.۶. انتخاب چندگانه

با افزودن ویژگی `multiple` می‌توان امکان انتخاب چند گزینه را فراهم کرد.

```html
<label for="skills">مهارت‌ها:</label>

<select id="skills" name="skills" multiple size="4">
    <option value="html">HTML</option>
    <option value="git">Git</option>
    <option value="python">Python</option>
    <option value="sql">SQL</option>
</select>
```

در این مثال:

- `multiple` انتخاب چند گزینه را مجاز می‌کند.
- `size="4"` درخواست نمایش چهار ردیف گزینه را می‌دهد.
- برای انتخاب چند گزینه، روش تعامل ممکن است با توجه به سیستم‌عامل و مرورگر متفاوت باشد.
- هنگام ارسال فرم، مقادیر انتخاب‌شده به‌صورت چند مقدار برای نام فیلد ارسال می‌شوند.

در برنامه‌هایی که از پردازش استاندارد فرم استفاده می‌کنند، نامی مانند `skills[]` نیز ممکن است برای سازگاری با قراردادهای سمت سرور به کار رود؛ اما خود HTML الزام نمی‌کند که نام حتماً دارای براکت باشد.

## ۳. المان `textarea`

### ۳.۱. کاربرد

المان `<textarea>` برای دریافت متن چندخطی از کاربر استفاده می‌شود.

برخلاف `input` با نوع `text` که عموماً برای متن کوتاه طراحی شده است، `textarea` برای متن‌های طولانی‌تر مناسب است.

موارد استفاده:

- توضیحات محصول
- نظر کاربران
- پیام تماس با ما
- شرح مشکل
- آدرس یا اطلاعات متنی چندخطی
- توضیحات تکمیلی فرم

### ۳.۲. ساختار و مثال

```html
<label for="description">توضیحات:</label>

<textarea
    id="description"
    name="description"
    rows="5"
    cols="40"
    placeholder="توضیحات خود را وارد کنید..."
></textarea>
```

توضیح بخش‌های مختلف:

- `textarea`: ایجاد کادر ورود متن چندخطی
- `id`: شناسه المان
- `name`: نام فیلد برای ارسال فرم
- `rows`: تعداد تقریبی ردیف‌های متنی قابل مشاهده
- `cols`: عرض تقریبی بر اساس تعداد نویسه‌ها
- `placeholder`: متن راهنمایی که تا زمان ورود متن نمایش داده می‌شود.

مقادیر `rows` و `cols` ابعاد دقیق بر حسب پیکسل نیستند؛ آن‌ها ابعاد تقریبی متنی را مشخص می‌کنند.

### ۳.۳. ویژگی‌های مهم `textarea`

| ویژگی | توضیح |
|---|---|
| `name` | نام فیلد هنگام ارسال فرم |
| `id` | شناسه المان |
| `rows` | تعداد ردیف‌های قابل مشاهده |
| `cols` | عرض تقریبی بر اساس تعداد نویسه‌ها |
| `placeholder` | متن راهنما |
| `required` | الزامی کردن ورود متن |
| `minlength` | حداقل تعداد نویسه‌ها |
| `maxlength` | حداکثر تعداد نویسه‌ها |
| `readonly` | جلوگیری از ویرایش متن توسط کاربر |
| `disabled` | غیرفعال کردن المان |
| `wrap` | تعیین نحوه مدیریت شکست خطوط هنگام ارسال متن |
| `autofocus` | درخواست تمرکز اولیه |
| `form` | اتصال المان به فرم مشخص |

#### مثال استفاده از محدودیت طول متن

```html
<label for="message">پیام شما:</label>

<textarea
    id="message"
    name="message"
    rows="6"
    cols="40"
    minlength="10"
    maxlength="500"
    required
    placeholder="پیام خود را بنویسید..."
></textarea>
```

در این مثال:

- ورود پیام الزامی است.
- طول متن نباید کمتر از ۱۰ نویسه باشد.
- طول متن نباید بیشتر از ۵۰۰ نویسه باشد.

این محدودیت‌ها بخشی از اعتبارسنجی بومی مرورگر هستند. برای امنیت و صحت داده‌ها، بررسی سمت سرور نیز ضروری است.

#### تفاوت `readonly` و `disabled`

```html
<textarea name="readonly_text" readonly>
این متن قابل ویرایش نیست، اما معمولاً همراه فرم ارسال می‌شود.
</textarea>

<textarea name="disabled_text" disabled>
این فیلد غیرفعال است و همراه فرم ارسال نمی‌شود.
</textarea>
```

تفاوت اصلی:

- `readonly`: کاربر نمی‌تواند مقدار را ویرایش کند، اما مقدار فیلد معمولاً هنگام ارسال فرم فرستاده می‌شود.
- `disabled`: کاربر نمی‌تواند با فیلد تعامل کند و مقدار آن در ارسال استاندارد فرم شرکت نمی‌کند.

**نکته مهم:** `readonly` و `disabled` معادل یکدیگر نیستند.

#### تعیین متن اولیه

متن اولیه `textarea` برخلاف `input` در ویژگی `value` تعریف نمی‌شود؛ بلکه بین تگ آغازین و پایانی قرار می‌گیرد.

```html
<textarea name="comment" rows="4" cols="30">متن اولیه</textarea>
```

در این مثال، عبارت «متن اولیه» از ابتدا داخل کادر نمایش داده می‌شود و کاربر می‌تواند آن را ویرایش کند.

#### ویژگی `wrap`

این ویژگی رفتار شکست خطوط را هنگام ارسال مقدار مشخص می‌کند.

مقادیر رایج:

- `soft`: شکست خطوط بصری الزاماً به‌عنوان شکست خط اضافی در مقدار ارسالی ثبت نمی‌شود.
- `hard`: شکست خطوط متناسب با عرض فیلد هنگام ارسال نیز اعمال می‌شود؛ برای این حالت تعیین `cols` لازم است.

مثال:

```html
<textarea name="notes" rows="5" cols="30" wrap="soft"></textarea>
```

در صورت حذف `wrap`، رفتار پیش‌فرض مرورگر اعمال می‌شود.

## ۴. المان `button`

### ۴.۱. کاربرد

المان `<button>` برای ایجاد دکمه‌های تعاملی استفاده می‌شود. این دکمه می‌تواند فرم را ارسال کند، فرم را بازنشانی کند یا برای کاربردهای دیگر مورد استفاده قرار گیرد.

مثال ساده:

```html
<button type="button">کلیک کنید</button>
```

ویژگی `type="button"` مشخص می‌کند که این دکمه به‌خودی‌خود رفتار ارسال فرم را ندارد.

### ۴.۲. انواع دکمه

دکمه‌های HTML معمولاً سه نوع اصلی دارند:

#### الف) دکمه ارسال (`submit`)

این نوع دکمه برای ارسال فرم استفاده می‌شود.

```html
<form action="/submit" method="post">
    <label for="username">نام کاربری:</label>
    <input type="text" id="username" name="username" required>

    <button type="submit">ارسال اطلاعات</button>
</form>
```

ویژگی‌های رفتار این دکمه:

- تلاش برای ارسال فرم مرتبط را آغاز می‌کند.
- اعتبارسنجی بومی فرم، در صورت فعال بودن، پیش از ارسال انجام می‌شود.
- داده‌های معتبر فرم به مقصد مشخص‌شده فرستاده می‌شوند.
- اگر `action` مشخص نشده باشد، مقصد پیش‌فرض فرم معمولاً نشانی فعلی صفحه است.

#### ب) دکمه بازنشانی (`reset`)

این دکمه مقادیر کنترل‌های فرم را به مقادیر اولیه آن‌ها بازمی‌گرداند.

```html
<form>
    <label for="fullname">نام:</label>
    <input type="text" id="fullname" name="fullname" value="علی">

    <button type="reset">بازنشانی فرم</button>
</form>
```

اگر کاربر مقدار نام را تغییر دهد و سپس دکمه بازنشانی را بزند، مقدار اولیه «علی» بازگردانده می‌شود.

نکته: بازنشانی به معنای خالی کردن همه فیلدها نیست؛ مقادیر اولیه تعریف‌شده در HTML مبنا هستند.

#### ج) دکمه معمولی (`button`)

این نوع دکمه به‌طور پیش‌فرض عملیات ارسال یا بازنشانی فرم را انجام نمی‌دهد.

```html
<button type="button">دکمه معمولی</button>
```

این نوع دکمه برای تعاملات عمومی مناسب است. عملکردهای سفارشی آن معمولاً به JavaScript نیاز دارند، اما تعریف خود دکمه صرفاً با HTML امکان‌پذیر است.

### ۴.۳. ویژگی‌های مهم `button`

| ویژگی | توضیح |
|---|---|
| `type` | تعیین نوع دکمه: `submit`، `reset` یا `button` |
| `name` | نام دکمه هنگام ارسال فرم، در صورت مشارکت آن در ارسال |
| `value` | مقدار مرتبط با دکمه در زمان ارسال |
| `disabled` | غیرفعال کردن دکمه |
| `autofocus` | درخواست تمرکز اولیه |
| `form` | اتصال دکمه به یک فرم مشخص |
| `formaction` | تغییر مقصد ارسال برای همان دکمه ارسال |
| `formenctype` | تعیین نوع رمزگذاری داده‌ها برای همان دکمه ارسال |
| `formmethod` | تعیین روش ارسال برای همان دکمه ارسال |
| `formnovalidate` | درخواست ارسال بدون اعتبارسنجی بومی |
| `formtarget` | تعیین محل نمایش پاسخ ارسال فرم |

#### ویژگی `disabled`

```html
<button type="submit" disabled>ارسال غیرفعال</button>
```

دکمه غیرفعال معمولاً قابل کلیک یا فعال‌سازی با صفحه‌کلید نیست و در فرایند ارسال فرم به‌عنوان دکمه ارسال‌کننده قابل استفاده نخواهد بود.

#### ویژگی‌های اختصاصی دکمه ارسال

```html
<form action="/save" method="post">
    <input type="text" name="title" required>

    <button
        type="submit"
        formaction="/publish"
        formmethod="post"
    >
        انتشار
    </button>
</form>
```

در این مثال، کلیک روی دکمه «انتشار» مقصد و روش ارسال تعریف‌شده برای همان دکمه را اعمال می‌کند. این ویژگی‌ها برای فرم‌هایی مفید هستند که چند عملیات ارسال متفاوت دارند.

**هشدار:** ویژگی `formnovalidate` اعتبارسنجی بومی مرورگر را برای ارسال مربوط غیرفعال می‌کند. این ویژگی جایگزین بررسی صحت و امنیت داده‌ها در سمت سرور نیست.

### ۴.۴. تفاوت `button` و `input`

هر دو المان می‌توانند برای ساخت دکمه به کار روند، اما ساختار آن‌ها متفاوت است.

نمونه با `button`:

```html
<button type="submit">
    ارسال فرم
</button>
```

نمونه با `input`:

```html
<input type="submit" value="ارسال فرم">
```

تفاوت‌ها:

- `button` می‌تواند محتوای متنی و المان‌های HTML دیگر را درون خود داشته باشد، با رعایت محدودیت‌های محتوایی HTML.
- `input` یک المان بدون تگ پایانی است و برای دکمه‌های متداول معمولاً متن خود را از `value` می‌گیرد.
- برای دکمه‌های ارسال و بازنشانی ساده، هر دو می‌توانند کاربرد داشته باشند.

به‌طور کلی، `button` انعطاف بیشتری در ساختار محتوای دکمه دارد.

## ۵. استفاده از این المان‌ها در فرم

در این بخش، سه المان `select`، `textarea` و `button` در یک فرم واحد قرار گرفته‌اند.

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>فرم ثبت درخواست</title>
</head>
<body>

    <h1>فرم ثبت درخواست</h1>

    <form action="/submit-request" method="post">

        <label for="subject">موضوع درخواست:</label>

        <select id="subject" name="subject" required>
            <option value="">انتخاب موضوع</option>
            <option value="support">پشتیبانی</option>
            <option value="sales">فروش</option>
            <option value="other">سایر موارد</option>
        </select>

        <br><br>

        <label for="message">شرح درخواست:</label>

        <textarea
            id="message"
            name="message"
            rows="6"
            cols="40"
            minlength="10"
            maxlength="1000"
            placeholder="درخواست خود را شرح دهید..."
            required
        ></textarea>

        <br><br>

        <button type="submit">ثبت درخواست</button>

        <button type="reset">پاک‌سازی تغییرات</button>

    </form>

</body>
</html>
```

### توضیح فرم

- `lang="fa"` زبان اصلی سند را فارسی معرفی می‌کند.
- `dir="rtl"` جهت کلی نوشتار را راست‌به‌چپ تعیین می‌کند.
- `action="/submit-request"` مقصد ارسال داده‌ها را مشخص می‌کند.
- `method="post"` روش ارسال فرم را تعیین می‌کند.
- `select` موضوع درخواست را دریافت می‌کند.
- `textarea` شرح درخواست را دریافت می‌کند.
- دکمه `submit` ارسال فرم را آغاز می‌کند.
- دکمه `reset` مقادیر کنترل‌ها را به وضعیت اولیه بازمی‌گرداند.

**توجه:** مسیر `/submit-request` نمونه است و برای دریافت واقعی اطلاعات باید در سمت سرور پیاده‌سازی شده باشد. همچنین استفاده از `method="post"` به‌تنهایی به معنی رمزگذاری یا امن بودن ارتباط نیست؛ برای انتقال امن داده‌ها باید از HTTPS استفاده شود.

## ۶. اعتبارسنجی و دسترس‌پذیری

### ۶.۱. استفاده از `label`

برای هر فیلد ورودی، عنوان واضح تعریف کنید.

روش پیشنهادی:

```html
<label for="email">ایمیل:</label>
<input type="email" id="email" name="email" required>
```

مقدار `for` در `label` باید با `id` فیلد مرتبط مطابقت داشته باشد.

این ارتباط باعث می‌شود کاربران صفحه‌خوان بهتر بتوانند مفهوم فیلد را تشخیص دهند و کلیک روی عنوان نیز معمولاً کنترل مرتبط را فعال کند.

### ۶.۲. استفاده از `required`

ویژگی `required` برای الزامی کردن ورود یا انتخاب مقدار مناسب است.

```html
<select name="department" required>
    <option value="">انتخاب واحد</option>
    <option value="it">فناوری اطلاعات</option>
    <option value="finance">مالی</option>
</select>
```

در این مثال، گزینه دارای مقدار خالی برای انتخاب معتبر کافی نیست.

### ۶.۳. اعتبارسنجی سمت مرورگر و سرور

ویژگی‌هایی مانند `required`، `minlength` و `maxlength` به مرورگر کمک می‌کنند بعضی خطاهای ورودی را پیش از ارسال تشخیص دهد.

بااین‌حال، اعتبارسنجی سمت مرورگر به‌تنهایی کافی نیست؛ زیرا درخواست‌ها ممکن است بدون استفاده از فرم مرورگر ارسال شوند یا کنترل‌های HTML دور زده شوند.

بنابراین:

- اعتبارسنجی سمت مرورگر برای تجربه کاربری مناسب است.
- اعتبارسنجی سمت سرور برای صحت داده‌ها و امنیت ضروری است.
- داده‌های ورودی نباید بدون بررسی به‌عنوان داده معتبر پذیرفته شوند.

### ۶.۴. پشتیبانی از صفحه‌کلید

المان‌های بومی HTML مانند `select` و `textarea` و همچنین `button` به‌طور معمول از تعامل صفحه‌کلید پشتیبانی می‌کنند.

برای حفظ دسترس‌پذیری:

- ترتیب منطقی فیلدها را رعایت کنید.
- عنوان فیلدها را به‌صورت متنی و قابل تشخیص تعریف کنید.
- دکمه‌ها را با متن واضح نام‌گذاری کنید.
- از غیرفعال کردن غیرضروری کنترل‌ها خودداری کنید.
- برای کاربردهای پیچیده، رفتار صفحه‌کلید و صفحه‌خوان را آزمایش کنید.

## ۷. نکات مهم و بهترین شیوه‌ها

۱. **همیشه از `name` مناسب استفاده کنید.** فیلدی که `name` ندارد معمولاً در ارسال استاندارد فرم به‌عنوان یک فیلد داده شرکت نمی‌کند.

۲. **برای فیلدها `label` تعریف کنید.** از `placeholder` به‌عنوان تنها عنوان فیلد استفاده نکنید؛ زیرا متن راهنما جایگزین مناسبی برای عنوان دائمی نیست.

۳. **نوع دکمه را مشخص کنید.** داخل فرم، دکمه‌ای که فقط قرار است یک دکمه معمولی باشد باید `type="button"` داشته باشد. دکمه بدون `type` در بسیاری از شرایط داخل فرم رفتار پیش‌فرض `submit` دارد.

۴. **از `select` برای گزینه‌های محدود استفاده کنید.** اگر تعداد گزینه‌ها بسیار زیاد است، بهتر است ساختار انتخاب را از نظر سهولت استفاده و دسترس‌پذیری بررسی کنید.

۵. **برای متن‌های چندخطی از `textarea` استفاده کنید.** برای مقادیر کوتاه و تک‌خطی معمولاً `input` مناسب‌تر است.

۶. **مقادیر ارسالی را مشخص کنید.** برای گزینه‌های `select` از `value`های معنادار و پایدار استفاده کنید.

۷. **به تفاوت `disabled` و `readonly` توجه کنید.** فیلد غیرفعال معمولاً ارسال نمی‌شود، اما فیلد فقط‌خواندنی معمولاً همراه فرم ارسال می‌شود.

۸. **اعتبارسنجی سمت سرور را فراموش نکنید.** اعتبارسنجی HTML برای راحتی کاربران است و نباید مرز امنیتی تلقی شود.

۹. **از متن روشن برای دکمه‌ها استفاده کنید.** عنوان‌هایی مانند «ثبت درخواست»، «ذخیره تغییرات» و «ارسال پیام» از عنوان‌های مبهمی مانند «کلیک کنید» کاربردی‌تر هستند.

۱۰. **رفتار فرم را آزمایش کنید.** مطمئن شوید گزینه‌ها، مقادیر اولیه، محدودیت طول متن و عملکرد دکمه‌های ارسال و بازنشانی مطابق انتظار هستند.

## ۸. جمع‌بندی

سه المان بررسی‌شده، نقش‌های متفاوتی در فرم‌های HTML دارند:

| المان | نقش | ویژگی‌های پرکاربرد |
|---|---|---|
| `select` | انتخاب از میان گزینه‌ها | `name`، `required`، `multiple`، `size` |
| `textarea` | ورود متن چندخطی | `name`، `rows`، `cols`، `minlength`، `maxlength` |
| `button` | ارسال، بازنشانی یا تعامل عمومی | `type`، `disabled`، `name`، `value` |

در طراحی فرم‌های استاندارد HTML، شناخت این المان‌ها و ویژگی‌های آن‌ها به ایجاد فرم‌هایی قابل فهم، کاربردی و دسترس‌پذیر کمک می‌کند.

این مستند عمداً به HTML محدود شده است و شامل آموزش CSS یا JavaScript نیست.
