# HTML | اسکلت و ساختار وب

HTML مخفف **HyperText Markup Language** است و زبان نشانه‌گذاری استاندارد برای ساختاردهی صفحات وب محسوب می‌شود. با استفاده از HTML می‌توان بخش‌هایی مانند عنوان‌ها، متن‌ها، تصاویر، لینک‌ها، جدول‌ها و فرم‌ها را در صفحات وب ایجاد کرد.

## کاربردهای HTML
- ایجاد ساختار صفحات وب
- نمایش متن، تصویر، ویدئو و لینک
- ساخت فرم‌های ورود اطلاعات
- سازمان‌دهی محتوای وب‌سایت
- همکاری با CSS برای طراحی ظاهری و JavaScript برای ایجاد تعامل

## ساختار ساده HTML

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>صفحه من</title>
</head>
<body>
    <h1>سلام دنیا!</h1>
    <p>این اولین صفحه HTML من است.</p>
    <a href="https://example.com">مشاهده لینک</a>
</body>
</html>
```

## تگ‌های پرکاربرد

| تگ | کاربرد |
|---|---|
| `<h1>` تا `<h6>` | عنوان‌ها |
| `<p>` | ایجاد پاراگراف |
| `<a>` | ایجاد لینک |
| `<img>` | نمایش تصویر |
| `<ul>` و `<ol>` | ایجاد فهرست |
| `<li>` | ایجاد یک آیتم فهرست |
| `<div>` | گروه‌بندی عناصر |
| `<form>` | ایجاد فرم |
| `<input>` | دریافت ورودی کاربر |

## ابزارهای موردنیاز
- یک ویرایشگر کد مانند Visual Studio Code
- یک مرورگر مانند Chrome یا Firefox

## چگونه شروع کنیم؟
1. یک فایل با نام `index.html` بسازید.
2. کد HTML را داخل آن بنویسید.
3. فایل را در مرورگر باز کنید.
4. با تغییر کد، نتیجه را مشاهده کنید.

**نتیجه:** HTML نقطه شروع یادگیری توسعه وب است و یادگیری آن، پایه‌ای برای کار با CSS و JavaScript فراهم می‌کند.

## مفاهیم و مباحث کلیدی

در این بخش، تمرین‌ها و نمونه‌کارهای مرتبط با موارد زیر قرار می‌گیرد:

1.**مبانی و تگ‌های پایه:**
   - آشنایی با ساختار استاندارد یک سند HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
   - تگ‌های متنی (سرتیترها از `<h1>` تا `<h6>`، پاراگراف‌ها، نقل‌قول‌ها و متن‌های تاکیدی)
   - لینک‌ها (`<a>`) و تصاویر (`<img>`)

2.**لیست‌ها و جداول:**
   - لیست‌های مرتب (`<ol>`) و نامرتب (`<ul>`)
   - ساخت جدول‌های اطلاعاتی ساختاریافته (`<table>`, `<tr>`, `<th>`, `<td>`)

3.**فرم‌های تعاملی:**
   - دریافت اطلاعات از کاربر با انواع `input`ها (متن، ایمیل، پسورد، تاریخ و...)
   - المان‌های انتخاب مانند `select`، `textarea` و دکمه‌های ارسال (`button`)
   - برچسب‌گذاری صحیح (`<label>`) برای بهبود تجربه کاربری و دسترسی‌پذیری

4.**استانداردهای معنایی (Semantic HTML):**
   - استفاده از تگ‌های مفهومی مدرن مانند `<header>`، `<nav>`، `<main>`، `<section>`، `<article>`، `<aside>` و `<footer>` برای بهبود ساختار سئو (SEO) و خوانایی کد.
