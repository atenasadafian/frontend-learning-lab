# لینک‌ها (`<a>`) و تصاویر (`<img>`) در HTML

صفحات وب بدون پیوندها و رسانه‌های بصری معنایی ندارند؛ واژه «وب» یا تار عنکبوت دقیقاً از همین قابلیت تنیده‌شدن صفحات به یکدیگر به وجود آمده است. در HTML، برای برقراری ارتباط میان صفحات مختلف یا بخش‌های یک صفحه از تگ `<a>` و برای نمایش تصاویر از تگ `<img>` استفاده می‌کنیم. هر دو تگ به ویژگی‌ها (Attributes) وابسته‌اند و بدون آن‌ها کارایی نخواهند داشت.

---

## تگ لینک ؛ (Anchor) `<a>`

تگ `<a>` برای ایجاد هایپرلینک (Hyperlink) به کار می‌رود. این تگ متنی یا حتی تصویری را به یک نشانی وب (URL)، یک فایل یا بخشی از همان صفحه متصل می‌کند.

### ساختار پایه و ویژگی `href`

مهم‌ترین ویژگی این تگ `href` (مخفف Hypertext Reference) است که مقصد لینک را مشخص می‌کند:
```html
<a href="https://example.com">برای ورود به وب‌سایت کلیک کنید</a>
```
اگر ویژگی href را ننویسید، متن درون تگ رفتار یک لینک فعال را نخواهد داشت.
### ویژگی target (نحوه باز شدن لینک)
به‌صورت پیش‌فرض، کلیک روی یک لینک باعث باز شدن مقصد در همان تب فعلی مرورگر می‌شود.
مقدارهای مهم:
_blank: در پنجره جدید باز می‌شود.
_self: در همان پنجره (پیش‌فرض).
_parent, _top: برای پنجره‌های iframe و موارد خاص.
### ویژگی title
متن راهنمایی که هنگام قرار گرفتن موس روی لینک ظاهر می‌شود.
