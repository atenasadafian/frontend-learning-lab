# آشنایی با ساختار استاندارد یک سند HTML

HTML یکی از اصلی‌ترین فناوری‌های توسعه وب است. برای ساخت هر صفحه وب، ابتدا باید با ساختار استاندارد یک سند HTML آشنا شویم.

هر سند HTML از بخش‌های مختلفی تشکیل شده است که هرکدام وظیفه مشخصی دارند. چهار بخش اصلی که در این آموزش بررسی می‌کنیم عبارت‌اند از:

1. `<!DOCTYPE html>`
2. `<html>`
3. `<head>`
4. `<body>`

شناخت این بخش‌ها به ما کمک می‌کند صفحات وب را به‌صورت استاندارد، خوانا و قابل نگهداری طراحی کنیم.

## HTML

HTML مخفف عبارت **HyperText Markup Language** به معنی «زبان نشانه‌گذاری ابرمتن» است.

HTML یک زبان برنامه‌نویسی به معنای متداول آن نیست؛ بلکه از تگ‌ها و عناصر برای مشخص کردن ساختار و معنای محتوای صفحات وب استفاده می‌کند.

با استفاده از HTML می‌توانیم عناصر مختلفی مانند موارد زیر را در صفحه قرار دهیم:

- عنوان‌ها و پاراگراف‌ها
- تصاویر و پیوندها
- فهرست‌ها و جدول‌ها
- فرم‌های ورودی اطلاعات
- فایل‌های صوتی و ویدئویی
- بخش‌های معنایی مانند سربرگ، منوی ناوبری و پاورقی

برای مثال:

```html
<h1>سلام، دنیا!</h1>
<p>این اولین صفحه HTML من است.</p>
```

در این مثال، تگ `<h1>` یک عنوان اصلی و تگ `<p>` یک پاراگراف را مشخص می‌کند.

## ساختار استاندارد یک سند HTML

یک سند استاندارد HTML5 معمولاً از ساختار زیر پیروی می‌کند:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>عنوان صفحه</title>
</head>
<body>
    <h1>سلام، دنیا!</h1>
    <p>به اولین صفحه HTML من خوش آمدید.</p>
</body>
</html>
```

در این ساختار:

| بخش | کاربرد |
|---|---|
| `<!DOCTYPE html>` | اعلام استفاده از استاندارد HTML5 |
| `<html>` | عنصر ریشه سند HTML |
| `<head>` | نگهداری اطلاعات و تنظیمات سند |
| `<body>` | نگهداری محتوای اصلی صفحه |
| `<meta charset="UTF-8">` | تعیین کدگذاری نویسه‌ها |
| `<meta name="viewport">` | تنظیم نمایش صفحه در دستگاه‌های مختلف |
| `<title>` | تعیین عنوان سند در مرورگر |

در ادامه، هر بخش را با جزئیات بررسی می‌کنیم.

## دستور `<!DOCTYPE html>`

دستور `<!DOCTYPE html>` در ابتدای سند HTML قرار می‌گیرد و به مرورگر اعلام می‌کند که صفحه باید با استفاده از استانداردهای مدرن HTML، یعنی HTML5، پردازش شود.

مثال:

```html
<!DOCTYPE html>
```

### چرا از DOCTYPE استفاده می‌کنیم؟

مرورگرها برای نمایش صفحات وب می‌توانند از حالت‌های مختلفی استفاده کنند. یکی از این حالت‌ها، حالت استاندارد (Standards Mode) است.

قرار دادن دستور `<!DOCTYPE html>` در ابتدای سند کمک می‌کند مرورگر صفحه را در حالت استاندارد نمایش دهد.

اگر این دستور حذف شود یا به‌درستی در ابتدای سند قرار نگیرد، ممکن است مرورگر وارد حالت Quirks Mode شود. این حالت برای سازگاری با صفحات قدیمی طراحی شده است و می‌تواند باعث تفاوت در نحوه نمایش برخی عناصر شود.

### نکات مهم

- این دستور یک تگ HTML معمولی نیست.
- این دستور نیازی به تگ بسته ندارد.
- در HTML5، شکل استاندارد آن بسیار ساده است.
- بهتر است اولین خط فایل HTML باشد.

نمونه صحیح:

```html
<!DOCTYPE html>
<html>
    <!-- محتوای سند -->
</html>
```

## تگ `<html>`

تگ `<html>` عنصر ریشه (Root Element) یک سند HTML است. تمام عناصر اصلی سند، به‌جز دستور DOCTYPE، درون این عنصر قرار می‌گیرند.

ساختار کلی:

```html
<!DOCTYPE html>
<html>
    <head>
        <!-- اطلاعات و تنظیمات سند -->
    </head>
    <body>
        <!-- محتوای صفحه -->
    </body>
</html>
```

تگ `<html>` معمولاً دو بخش اصلی را در خود جای می‌دهد:

- `<head>`
- `<body>`

### تعیین زبان صفحه با ویژگی `lang`

می‌توان با ویژگی `lang` زبان اصلی محتوای صفحه را مشخص کرد.

برای مثال:

```html
<html lang="fa">
```

مقادیر متداول این ویژگی عبارت‌اند از:

| مقدار | زبان |
|---|---|
| `fa` | فارسی |
| `en` | انگلیسی |
| `ar` | عربی |
| `fr` | فرانسوی |
| `de` | آلمانی |

تعیین زبان صفحه به ابزارهای کمکی، فناوری‌های صفحه‌خوان و برخی پردازش‌های مرورگر کمک می‌کند زبان محتوا را بهتر تشخیص دهند.

### تعیین جهت نوشتار با ویژگی `dir`

برای مشخص کردن جهت نوشتار می‌توان از ویژگی `dir` استفاده کرد.

مقادیر اصلی:

- `ltr`: از چپ به راست (Left to Right)
- `rtl`: از راست به چپ (Right to Left)
- `auto`: تشخیص خودکار جهت بر اساس محتوای متن

برای یک صفحه فارسی معمولاً از ترکیب زیر استفاده می‌کنیم:

```html
<html lang="fa" dir="rtl">
```

در این مثال:

- `lang="fa"` زبان صفحه را فارسی مشخص می‌کند.
- `dir="rtl"` جهت پیش‌فرض نوشتار را راست به چپ تعیین می‌کند.

**نکته:** ویژگی `dir` جهت نوشتار را تعیین می‌کند، اما برای کنترل دقیق چیدمان، فاصله‌ها و موقعیت عناصر معمولاً به CSS نیز نیاز داریم.

## بخش `<head>`

عنصر `<head>` شامل اطلاعات توصیفی و تنظیمات مربوط به سند HTML است.

این بخش معمولاً مستقیماً در صفحه وب نمایش داده نمی‌شود؛ اما اطلاعات آن می‌تواند روی عنوان مرورگر، نحوه نمایش متن، سازگاری با دستگاه‌های مختلف و پردازش صفحه تأثیر بگذارد.

ساختار کلی:

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>صفحه اصلی</title>
</head>
```

### تگ `<title>`

تگ `<title>` عنوان سند را مشخص می‌کند.

مثال:

```html
<title>آموزش HTML</title>
```

این عنوان معمولاً در موارد زیر استفاده می‌شود:

- عنوان تب مرورگر
- عنوان صفحه در نتایج موتورهای جست‌وجو، در صورت انتخاب آن توسط موتور جست‌وجو
- نام پیش‌فرض صفحه هنگام افزودن آن به نشانک‌ها (Bookmarks)

تگ `<title>` باید داخل `<head>` قرار بگیرد.

نمونه:

```html
<head>
    <title>آموزش HTML برای مبتدیان</title>
</head>
```

بهتر است عنوان هر صفحه، دقیق، قابل‌فهم و متناسب با محتوای همان صفحه باشد.

### تگ `<meta charset="UTF-8">`

این تگ کدگذاری نویسه‌های سند را مشخص می‌کند.

```html
<meta charset="UTF-8">
```

UTF-8 یکی از رایج‌ترین کدگذاری‌های نویسه است و از فارسی، انگلیسی و بسیاری از زبان‌های دیگر پشتیبانی می‌کند.

اگر کدگذاری فایل و تنظیمات مرورگر هماهنگ نباشند، ممکن است برخی نویسه‌ها به‌درستی نمایش داده نشوند.

برای مثال، در یک صفحه فارسی استفاده از UTF-8 اهمیت زیادی دارد.

**نکات مهم:**

- این تگ نیازی به تگ بسته ندارد.
- بهتر است در ابتدای بخش `<head>` قرار بگیرد.
- فایل HTML نیز باید با کدگذاری UTF-8 ذخیره شود.

### تگ `<meta name="viewport">`

این تگ تنظیمات مربوط به ناحیه قابل مشاهده صفحه در دستگاه‌های مختلف را مشخص می‌کند.

نمونه استاندارد:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

معنی بخش‌های مختلف:

| ویژگی | توضیح |
|---|---|
| `name="viewport"` | مشخص می‌کند متا تگ برای تنظیم ناحیه نمایش است |
| `width=device-width` | عرض ناحیه نمایش را با عرض دستگاه هماهنگ می‌کند |
| `initial-scale=1.0` | مقیاس اولیه نمایش را روی مقدار ۱ قرار می‌دهد |

این تنظیم برای طراحی واکنش‌گرا (Responsive Design) اهمیت دارد.

طراحی واکنش‌گرا یعنی صفحه وب بتواند در اندازه‌های مختلف نمایشگر، مانند موبایل، تبلت و رایانه، به‌شکل مناسبی نمایش داده شود.

البته این متا تگ به‌تنهایی طراحی واکنش‌گرا ایجاد نمی‌کند؛ برای آن معمولاً باید از CSS، چیدمان‌های انعطاف‌پذیر و در صورت نیاز Media Queryها استفاده کنیم.

### تگ `<meta name="description">`

این متا تگ توضیح کوتاهی درباره محتوای صفحه ارائه می‌کند.

مثال:

```html
<meta name="description" content="آموزش مقدماتی HTML و آشنایی با ساختار استاندارد صفحات وب.">
```

موتورهای جست‌وجو ممکن است از این توضیح برای نمایش خلاصه صفحه در نتایج جست‌وجو استفاده کنند؛ با این حال، نمایش آن تضمین‌شده نیست.

### اتصال فایل CSS

برای جدا کردن ظاهر صفحه از ساختار آن، معمولاً از CSS استفاده می‌کنیم.

برای اتصال یک فایل CSS خارجی، از تگ `<link>` استفاده می‌شود:

```html
<link rel="stylesheet" href="style.css">
```

در این مثال:

- `rel="stylesheet"` مشخص می‌کند فایل مربوط به شیوه‌نامه است.
- `href="style.css"` مسیر فایل CSS را مشخص می‌کند.

نمونه استفاده در سند:

```html
<head>
    <meta charset="UTF-8">
    <title>صفحه من</title>
    <link rel="stylesheet" href="style.css">
</head>
```

### اتصال فایل JavaScript

برای افزودن قابلیت‌های تعاملی می‌توان فایل JavaScript را به سند متصل کرد.

یکی از روش‌های رایج:

```html
<script src="script.js" defer></script>
```

ویژگی `defer` باعث می‌شود مرورگر فایل اسکریپت خارجی را هم‌زمان با پردازش HTML دریافت کند، اما اجرای آن را تا پایان پردازش سند به تعویق بیندازد.

این روش برای بسیاری از اسکریپت‌هایی که به عناصر صفحه نیاز دارند، انتخاب مناسبی است.

نمونه:

```html
<head>
    <meta charset="UTF-8">
    <title>صفحه تعاملی</title>
    <script src="script.js" defer></script>
</head>
```

**نکته:** اسکریپت‌های ماژولی و برخی شیوه‌های دیگر بارگذاری JavaScript قواعد متفاوتی دارند؛ بنابراین انتخاب روش مناسب به نیاز پروژه بستگی دارد.

## بخش `<body>`

عنصر `<body>` محتوای اصلی سند HTML را در بر می‌گیرد. این همان بخشی است که معمولاً کاربران در صفحه مرورگر مشاهده می‌کنند.

محتوای آن می‌تواند شامل عنوان‌ها، متن‌ها، تصاویر، پیوندها، فرم‌ها، جدول‌ها و سایر عناصر HTML باشد.

مثال:

```html
<body>
    <h1>به وب‌سایت من خوش آمدید</h1>
    <p>این اولین صفحه وب من است.</p>
    <a href="https://example.com">مشاهده یک وب‌سایت نمونه</a>
</body>
```

### عنوان‌ها

برای مشخص کردن عنوان‌ها در HTML از عناصر `h1` تا `h6` استفاده می‌کنیم.

```html
<h1>عنوان اصلی صفحه</h1>
<h2>عنوان یک بخش</h2>
<h3>عنوان یک زیربخش</h3>
```

این عناصر ساختار سلسله‌مراتبی محتوا را مشخص می‌کنند.

- `<h1>` بالاترین سطح عنوان را نشان می‌دهد.
- `<h2>` سطح بعدی است.
- `<h3>` زیربخش سطح دوم را مشخص می‌کند.
- همین الگو تا `<h6>` ادامه پیدا می‌کند.

از عنوان‌ها باید برای سازمان‌دهی منطقی محتوا استفاده کرد، نه صرفاً برای بزرگ یا کوچک کردن متن. اندازه ظاهری عنوان‌ها را می‌توان با CSS تغییر داد.

### پاراگراف‌ها

برای ایجاد یک پاراگراف از تگ `<p>` استفاده می‌شود.

```html
<p>HTML ساختار محتوای صفحات وب را مشخص می‌کند.</p>
<p>CSS برای طراحی ظاهر صفحات به کار می‌رود.</p>
```

هر عنصر `<p>` یک پاراگراف مستقل را نشان می‌دهد.

### پیوندها

برای ایجاد پیوند به صفحات دیگر یا منابع اینترنتی از تگ `<a>` استفاده می‌کنیم.

```html
<a href="https://example.com">ورود به وب‌سایت نمونه</a>
```

ویژگی `href` مقصد پیوند را مشخص می‌کند.

برای پیوند به صفحه‌ای در همان پروژه می‌توان نوشت:

```html
<a href="about.html">درباره ما</a>
```

### تصاویر

برای نمایش تصویر از تگ `<img>` استفاده می‌شود.

```html
<img src="images/photo.jpg" alt="توضیح تصویر">
```

- `src`: مسیر فایل تصویر
- `alt`: متن جایگزین تصویر

متن جایگزین برای دسترس‌پذیری اهمیت دارد و در صورت نیاز به کاربران صفحه‌خوان کمک می‌کند محتوای تصویر را درک کنند. اگر تصویر صرفاً تزئینی باشد، معمولاً باید از `alt=""` استفاده شود.

تگ `<img>` یک عنصر تهی است و تگ بسته معمولی ندارد.

### فهرست‌ها

برای نمایش فهرست بدون ترتیب از `<ul>` و برای فهرست شماره‌گذاری‌شده از `<ol>` استفاده می‌کنیم.

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

نمونه فهرست شماره‌گذاری‌شده:

```html
<ol>
    <li>ایجاد فایل HTML</li>
    <li>نوشتن ساختار اصلی</li>
    <li>اجرای فایل در مرورگر</li>
</ol>
```

هر مورد فهرست داخل عنصر `<li>` قرار می‌گیرد.

### عناصر معنایی HTML

برای سازمان‌دهی بهتر محتوای صفحه می‌توان از عناصر معنایی استفاده کرد:

```html
<body>
    <header>
        <h1>وب‌سایت من</h1>
    </header>

    <nav>
        <a href="index.html">خانه</a>
        <a href="about.html">درباره ما</a>
    </nav>

    <main>
        <h2>محتوای اصلی</h2>
        <p>این بخش محتوای اصلی صفحه را شامل می‌شود.</p>
    </main>

    <footer>
        <p>تمام حقوق محفوظ است.</p>
    </footer>
</body>
```

کاربرد عناصر:

| عنصر | کاربرد |
|---|---|
| `<header>` | سربرگ صفحه یا یک بخش |
| `<nav>` | مجموعه پیوندهای ناوبری |
| `<main>` | محتوای اصلی و غالب صفحه |
| `<section>` | گروه‌بندی موضوعی محتوا |
| `<article>` | محتوای مستقل و قابل تفکیک |
| `<aside>` | محتوای جانبی و مرتبط |
| `<footer>` | اطلاعات پایانی صفحه یا یک بخش |

این عناصر به معنای محتوا کمک می‌کنند و ساختار صفحه را برای توسعه‌دهندگان و فناوری‌های کمکی قابل‌فهم‌تر می‌سازند.

## بررسی یک نمونه کامل

در این بخش یک صفحه HTML ساده می‌سازیم که تمام اجزای اصلی را در کنار یکدیگر دارد.

### کد کامل

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <meta
        name="description"
        content="یک صفحه نمونه برای یادگیری ساختار استاندارد HTML."
    >

    <title>آموزش ساختار HTML</title>

    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
</head>
<body>
    <header>
        <h1>به دنیای HTML خوش آمدید</h1>
        <p>این صفحه برای یادگیری ساختار استاندارد HTML ساخته شده است.</p>
    </header>

    <nav>
        <a href="#introduction">مقدمه</a>
        <a href="#topics">موضوعات</a>
    </nav>

    <main>
        <section id="introduction">
            <h2>HTML چیست؟</h2>
            <p>
                HTML زبان نشانه‌گذاری استاندارد برای ساختاردهی
                محتوای صفحات وب است.
            </p>
        </section>

        <section id="topics">
            <h2>موضوعات آموزشی</h2>
            <ul>
                <li>ساختار سند HTML</li>
                <li>عنوان‌ها و پاراگراف‌ها</li>
                <li>پیوندها و تصاویر</li>
            </ul>
        </section>
    </main>

    <footer>
        <p>این یک پروژه آموزشی HTML است.</p>
    </footer>
</body>
</html>
```

### تحلیل کد

۱. `<!DOCTYPE html>` به مرورگر اعلام می‌کند که سند از HTML5 استفاده می‌کند.

۲. `<html lang="fa" dir="rtl">` عنصر ریشه سند را تعریف می‌کند و زبان و جهت نوشتار را مشخص می‌سازد.

۳. `<head>` شامل اطلاعات توصیفی، عنوان صفحه، تنظیمات نمایش و پیوند به فایل‌های خارجی است.

۴. `<body>` محتوای اصلی قابل مشاهده را در بر می‌گیرد.

۵. `<header>` بخش سربرگ صفحه را مشخص می‌کند.

۶. `<nav>` پیوندهای ناوبری را گروه‌بندی می‌کند.

۷. `<main>` محتوای اصلی صفحه را مشخص می‌کند.

۸. `<section>` مطالب مرتبط را در بخش‌های موضوعی قرار می‌دهد.

۹. `<footer>` اطلاعات پایانی صفحه را نمایش می‌دهد.

۱۰. ویژگی‌های `id` در بخش‌های محتوا امکان ایجاد پیوند داخلی را فراهم می‌کنند.

**نکته:** فایل‌های `style.css` و `script.js` در این مثال فقط به سند متصل شده‌اند. برای استفاده واقعی، باید این فایل‌ها نیز در مسیر مناسب وجود داشته باشند.

## نحوه اجرای فایل HTML

برای اجرای این مثال به ابزار پیچیده‌ای نیاز ندارید.

### مرحله اول: ایجاد پوشه پروژه

یک پوشه با نام دلخواه ایجاد کنید:

```text
html-project/
```

### مرحله دوم: ایجاد فایل HTML

داخل پوشه، فایلی با نام `index.html` بسازید.

ساختار پوشه می‌تواند به شکل زیر باشد:

```text
html-project/
├── index.html
├── style.css
└── script.js
```

### مرحله سوم: نوشتن کد

کد HTML نمونه را داخل فایل `index.html` قرار دهید و فایل را با کدگذاری UTF-8 ذخیره کنید.

### مرحله چهارم: اجرای فایل

روی فایل `index.html` دوبار کلیک کنید یا آن را با یک مرورگر مانند Chrome، Firefox، Edge یا Safari باز کنید.

مرورگر کد HTML را پردازش کرده و محتوای صفحه را نمایش می‌دهد.

### مرحله پنجم: مشاهده تغییرات

متن‌های داخل `<body>` را تغییر دهید، فایل را ذخیره کنید و صفحه مرورگر را مجدداً بارگذاری کنید.

برای یادگیری بهتر می‌توانید از یک ویرایشگر کد مانند Visual Studio Code نیز استفاده کنید.

## نکات مهم و بهترین روش‌ها

برای نوشتن یک سند HTML استاندارد، موارد زیر را رعایت کنید:

- همیشه از `<!DOCTYPE html>` در ابتدای سند استفاده کنید.
- زبان اصلی صفحه را با ویژگی `lang` مشخص کنید.
- برای محتوای فارسی، در صورت نیاز جهت نوشتار را با `dir="rtl"` تنظیم کنید.
- از `<meta charset="UTF-8">` برای تعیین کدگذاری نویسه‌ها استفاده کنید.
- متا تگ viewport را برای نمایش مناسب در دستگاه‌های مختلف در نظر بگیرید.
- عنوان معناداری برای صفحه در `<title>` انتخاب کنید.
- ساختار محتوا را با عناصر معنایی مناسب سازمان‌دهی کنید.
- از تورفتگی و فاصله‌گذاری منظم برای افزایش خوانایی کد استفاده کنید.
- ظاهر صفحه را تا حد امکان در فایل CSS و رفتار تعاملی را در فایل JavaScript مدیریت کنید.
- از ویژگی `alt` برای تصاویر استفاده کنید و متن آن را متناسب با هدف تصویر انتخاب کنید.
- ساختار HTML را با ابزارهای اعتبارسنجی بررسی کنید.

### آیا HTML به حروف بزرگ و کوچک حساس است؟

در HTML، نام عناصر و ویژگی‌ها نسبت به بزرگی و کوچکی حروف حساس نیستند؛ اما استفاده از حروف کوچک یک قرارداد رایج و توصیه‌شده است.

برای مثال، این دو شکل از نظر نام عنصر یکسان هستند:

```html
<body>
```

```html
<BODY>
```

بااین‌حال، بهتر است همیشه از شکل کوچک، مانند `<body>`، استفاده کنید.
