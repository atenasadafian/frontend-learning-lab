# لیست‌های مرتب (`<ol>`) و نامرتب (`<ul>`)

در HTML، لیست‌ها یکی از عناصر مهم برای نمایش اطلاعات به‌شکل منظم و قابل فهم هستند. از لیست‌ها می‌توان برای نمایش مراحل انجام یک کار، فهرست محصولات، منوها، ویژگی‌های یک محصول، دستورالعمل‌ها و بسیاری از موارد دیگر استفاده کرد.

HTML دو نوع اصلی لیست برای نمایش مجموعه‌ای از موارد دارد:

1. **لیست مرتب (`Ordered List`)** با تگ `<ol>`
2. **لیست نامرتب (`Unordered List`)** با تگ `<ul>`

هر دو نوع لیست معمولاً از تگ `<li>` برای تعریف هر مورد استفاده می‌کنند.

### نمونه ساده

```html
<h2>زبان‌های برنامه‌نویسی</h2>

<ul>
    <li>JavaScript</li>
    <li>Python</li>
    <li>Java</li>
</ul>

<h2>مراحل یادگیری HTML</h2>

<ol>
    <li>یادگیری ساختار اولیه HTML</li>
    <li>آشنایی با تگ‌ها و ویژگی‌ها</li>
    <li>یادگیری CSS</li>
</ol>
```

در مثال بالا، زبان‌های برنامه‌نویسی در یک لیست نامرتب و مراحل یادگیری در یک لیست مرتب نمایش داده شده‌اند.

---

## لیست در HTML چیست؟

لیست مجموعه‌ای از موارد مرتبط است که در کنار یکدیگر و با ساختاری مشخص نمایش داده می‌شوند.

برای مثال، فرض کنید می‌خواهیم موارد زیر را نمایش دهیم:

- لپ‌تاپ
- تلفن همراه
- تبلت

این موارد را می‌توان داخل یک لیست HTML قرار داد تا مرورگر آن‌ها را به‌صورت ساختاریافته نمایش دهد.

### ساختار کلی لیست

```html
<ul>
    <li>مورد اول</li>
    <li>مورد دوم</li>
    <li>مورد سوم</li>
</ul>
```

ساختار کلی شامل سه بخش است:

| تگ | وظیفه |
|---|---|
| `<ul>` | ایجاد یک لیست نامرتب |
| `<ol>` | ایجاد یک لیست مرتب |
| `<li>` | تعریف یک مورد از لیست |

لیست‌ها علاوه بر نمایش بصری، ساختار معنایی مناسبی برای مرورگرها، موتورهای جست‌وجو و فناوری‌های کمکی فراهم می‌کنند.

---

## لیست مرتب (`<ol>`)

تگ `<ol>` مخفف عبارت `Ordered List` است و برای نمایش لیستی استفاده می‌شود که ترتیب موارد آن اهمیت دارد.

در این نوع لیست، مرورگر معمولاً برای هر مورد یک شماره یا نشانگر ترتیبی نمایش می‌دهد.

### ساختار پایه

```html
<ol>
    <li>روشن کردن کامپیوتر</li>
    <li>باز کردن مرورگر</li>
    <li>ورود به وب‌سایت</li>
</ol>
```

خروجی تقریبی:

1. روشن کردن کامپیوتر
2. باز کردن مرورگر
3. ورود به وب‌سایت

### چه زمانی از `<ol>` استفاده کنیم؟

از لیست مرتب زمانی استفاده می‌کنیم که ترتیب موارد معنا داشته باشد.

مثال‌ها:

- مراحل نصب یک نرم‌افزار
- دستورالعمل پخت غذا
- رتبه‌بندی افراد یا محصولات
- مراحل ثبت‌نام
- ترتیب انجام یک فرایند
- فهرست فصل‌هایی که ترتیب آن‌ها اهمیت دارد

### ویژگی `type`

ویژگی `type` نوع نشانگر لیست مرتب را مشخص می‌کند.

| مقدار | نوع نشانگر | مثال |
|---|---|---|
| `1` | اعداد معمولی | 1, 2, 3 |
| `A` | حروف بزرگ انگلیسی | A, B, C |
| `a` | حروف کوچک انگلیسی | a, b, c |
| `I` | اعداد رومی بزرگ | I, II, III |
| `i` | اعداد رومی کوچک | i, ii, iii |

مثال:

```html
<h3>اعداد معمولی</h3>
<ol type="1">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

<h3>حروف بزرگ</h3>
<ol type="A">
    <li>طراحی</li>
    <li>توسعه</li>
    <li>آزمایش</li>
</ol>

<h3>اعداد رومی</h3>
<ol type="I">
    <li>مقدمه</li>
    <li>مفاهیم پایه</li>
    <li>مفاهیم پیشرفته</li>
</ol>
```
نکته: مقدار پیش‌فرض `type` در `<ol>` برابر `1` است.

### ویژگی `start`

ویژگی `start` مشخص می‌کند شماره‌گذاری لیست از چه عددی آغاز شود.

```html
<ol start="5">
    <li>مورد اول</li>
    <li>مورد دوم</li>
    <li>مورد سوم</li>
</ol>
```

خروجی:

5. مورد اول
6. مورد دوم
7. مورد سوم

این ویژگی زمانی کاربرد دارد که بخشی از یک لیست بزرگ‌تر را نمایش می‌دهیم یا شماره‌گذاری باید از عدد مشخصی آغاز شود.

همچنین `start` می‌تواند همراه با `type` استفاده شود:

```html
<ol type="A" start="3">
    <li>مورد اول</li>
    <li>مورد دوم</li>
    <li>مورد سوم</li>
</ol>
```

خروجی:

C. مورد اول  
D. مورد دوم  
E. مورد سوم

### ویژگی `reversed`

ویژگی بولی `reversed` ترتیب شماره‌گذاری را معکوس می‌کند.

```html
<ol reversed>
    <li>مرحله سوم</li>
    <li>مرحله دوم</li>
    <li>مرحله اول</li>
</ol>
```

خروجی:

3. مرحله سوم
2. مرحله دوم
1. مرحله اول

اگر تعداد موارد مشخص باشد، شماره‌گذاری از تعداد کل موارد شروع می‌شود؛ بنابراین در مثال بالا شماره‌ها از ۳ آغاز می‌شوند.

می‌توان از `start` نیز برای تعیین نقطه شروع استفاده کرد:

```html
<ol reversed start="10">
    <li>مورد اول</li>
    <li>مورد دوم</li>
    <li>مورد سوم</li>
</ol>
```

خروجی:

10. مورد اول
9. مورد دوم
8. مورد سوم

### ویژگی `value` در تگ `<li>`

ویژگی `value` می‌تواند شماره یک مورد مشخص از لیست مرتب را تعیین کند. شماره‌گذاری موارد بعدی نیز بر اساس آن ادامه پیدا می‌کند.

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li value="10">JavaScript</li>
    <li>Python</li>
</ol>
```

خروجی:

1. HTML
2. CSS
10. JavaScript
11. Python

این ویژگی مخصوص شماره‌گذاری موارد در لیست مرتب است و برای تغییر مستقیم شماره یک مورد کاربرد دارد.

---

## ویژگی‌های تگ `<ol>`

ویژگی‌های مهم تگ `<ol>` عبارت‌اند از:

| ویژگی | کاربرد |
|---|---|
| `type` | تعیین نوع نشانگر شماره‌گذاری |
| `start` | تعیین شماره یا موقعیت شروع |
| `reversed` | معکوس کردن ترتیب شماره‌گذاری |
| `id` | اختصاص شناسه یکتا به عنصر |
| `class` | اختصاص یک یا چند کلاس CSS |
| `style` | اعمال استایل درون‌خطی |
| `title` | ارائه اطلاعات تکمیلی درباره عنصر |

سه ویژگی اول از ویژگی‌های اختصاصی و شناخته‌شده لیست مرتب هستند. ویژگی‌های `id`، `class`، `style` و `title` نیز از ویژگی‌های عمومی HTML محسوب می‌شوند.

مثال:

```html
<ol
    id="installation-steps"
    class="steps"
    type="1"
    start="1"
>
    <li>دانلود نرم‌افزار</li>
    <li>اجرای فایل نصب</li>
    <li>تکمیل نصب</li>
</ol>
```

در این مثال:

- `id` برای شناسایی عنصر استفاده شده است.
- `class` برای اعمال استایل CSS کاربرد دارد.
- `type` نوع شماره‌گذاری را تعیین می‌کند.
- `start` نقطه آغاز شماره‌گذاری را مشخص می‌کند.

## ۵. لیست نامرتب (`<ul>`)

تگ `<ul>` مخفف عبارت `Unordered List` است و برای نمایش مجموعه‌ای از موارد استفاده می‌شود که ترتیب شماره‌ای یا رتبه‌ای آن‌ها اهمیت ندارد.

مرورگر معمولاً کنار هر مورد یک نشانگر مانند دایره نمایش می‌دهد.

### ۵.۱. ساختار پایه

```html
<ul>
    <li>سیب</li>
    <li>موز</li>
    <li>پرتقال</li>
</ul>
```

خروجی تقریبی:

- سیب
- موز
- پرتقال

### ۵.۲. چه زمانی از `<ul>` استفاده کنیم؟

لیست نامرتب زمانی مناسب است که موارد مستقل یا هم‌سطح باشند و ترتیب آن‌ها معنای خاصی نداشته باشد.

مثال‌ها:

- فهرست محصولات
- ویژگی‌های یک محصول
- مهارت‌ها
- دسته‌بندی‌ها
- گزینه‌های منو
- فهرست ابزارهای موردنیاز
- مزایا و معایب
- فهرست پیوندهای مرتبط

### ۵.۳. نشانگرهای لیست نامرتب

مرورگرها معمولاً از نشانگرهای زیر استفاده می‌کنند:

- `disc`: دایره توپر
- `circle`: دایره توخالی
- `square`: مربع توپر

برای کنترل نشانگرها بهتر است از CSS استفاده کنیم.

مثال:

```html
<ul class="disc-list">
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ul class="circle-list">
    <li>Python</li>
    <li>JavaScript</li>
</ul>

<ul class="square-list">
    <li>React</li>
    <li>Vue</li>
</ul>
```

```css
.disc-list {
    list-style-type: disc;
}

.circle-list {
    list-style-type: circle;
}

.square-list {
    list-style-type: square;
}
```

نکته: `disc` معمولاً نوع پیش‌فرض نشانگر `<ul>` است؛ برای طراحی دقیق و سازگار، CSS انتخاب بهتری محسوب می‌شود.

### ۵.۴. ویژگی‌های تگ `<ul>`

تگ `<ul>` برخلاف `<ol>` ویژگی استانداردی برای تعیین نوع نشانگر با نام `type` ندارد که استفاده از آن توصیه شود.

برای کنترل ظاهر لیست از CSS و برای شناسایی عنصر از ویژگی‌های عمومی HTML استفاده می‌کنیم.

```html
<ul id="skills" class="skill-list">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

```css
.skill-list {
    list-style-type: square;
    padding-inline-start: 24px;
}
```

## ۶. تفاوت `<ol>` و `<ul>`

مهم‌ترین تفاوت این دو تگ در معنای لیست است، نه صرفاً شکل نشانگرهای آن.

| ویژگی | `<ol>` | `<ul>` |
|---|---|---|
| نام کامل | Ordered List | Unordered List |
| کاربرد | موارد دارای ترتیب معنادار | موارد بدون ترتیب معنادار |
| نشانگر پیش‌فرض | شماره | دایره |
| شماره‌گذاری | پشتیبانی می‌شود | به‌صورت پیش‌فرض ندارد |
| ویژگی `start` | دارد | ندارد |
| ویژگی `reversed` | دارد | ندارد |
| ویژگی `type` | برای نوع شماره‌گذاری | برای این کاربرد استاندارد نیست |
| تگ مورد استفاده برای هر مورد | `<li>` | `<li>` |

### مثال مقایسه‌ای

```html
<h2>مراحل ارسال سفارش</h2>

<ol>
    <li>انتخاب محصول</li>
    <li>ثبت اطلاعات</li>
    <li>پرداخت</li>
    <li>تأیید سفارش</li>
</ol>

<h2>ویژگی‌های محصول</h2>

<ul>
    <li>سبک و قابل حمل</li>
    <li>مصرف انرژی پایین</li>
    <li>دارای گارانتی</li>
    <li>طراحی مدرن</li>
</ul>
```

در لیست اول ترتیب مراحل اهمیت دارد؛ اما در لیست دوم ویژگی‌ها مستقل از یکدیگر هستند.

**قاعده مهم:** انتخاب بین `<ol>` و `<ul>` باید بر اساس معنای محتوا انجام شود، نه فقط ظاهر موردنظر.

## ۷. تگ `<li>` چیست؟

تگ `<li>` مخفف `List Item` است و برای تعریف هر مورد از یک لیست استفاده می‌شود.

این تگ معمولاً درون `<ol>` یا `<ul>` قرار می‌گیرد.

### ساختار

```html
<ul>
    <li>مورد اول</li>
    <li>مورد دوم</li>
    <li>مورد سوم</li>
</ul>
```

هر تگ `<li>` یک مورد مستقل در لیست ایجاد می‌کند.

### قرار دادن عناصر دیگر داخل `<li>`

محتوای یک مورد لیست می‌تواند شامل متن، پیوند، تصویر، پاراگراف و عناصر دیگر باشد.

```html
<ul>
    <li>
        <a href="https://developer.mozilla.org/">
            مستندات توسعه وب
        </a>
    </li>

    <li>
        <strong>HTML</strong>
        <p>برای ساختاردهی محتوای صفحات وب استفاده می‌شود.</p>
    </li>

    <li>
        <img src="logo.png" alt="لوگوی پروژه">
        لوگوی پروژه
    </li>
</ul>
```

تگ `<li>` به‌خودی‌خود برای ایجاد لیست کافی نیست؛ باید در ساختار مناسب یک لیست قرار گیرد.

نکته: در HTML، تگ‌های `<li>` می‌توانند در بعضی شرایط به‌صورت ضمنی بسته شوند؛ با این حال، نوشتن تگ بسته `</li>` خوانایی و نگهداری کد را بهتر می‌کند.

## ۸. لیست‌های تو در تو

لیست تو در تو (Nested List) به لیستی گفته می‌شود که درون یکی از موارد لیست دیگر قرار گرفته است.

این ساختار برای نمایش دسته‌بندی‌ها، زیرمجموعه‌ها و سلسله‌مراتب اطلاعات بسیار مفید است.

### ۸.۱. لیست نامرتب تو در تو

```html
<ul>
    <li>
        فرانت‌اند
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>
        بک‌اند
        <ul>
            <li>Python</li>
            <li>PHP</li>
            <li>Node.js</li>
        </ul>
    </li>
</ul>
```

خروجی مفهومی:

- فرانت‌اند
  - HTML
  - CSS
  - JavaScript
- بک‌اند
  - Python
  - PHP
  - Node.js

### ۸.۲. لیست مرتب تو در تو

```html
<ol>
    <li>
        آماده‌سازی
        <ol>
            <li>نصب ابزارها</li>
            <li>ایجاد پروژه</li>
        </ol>
    </li>

    <li>
        توسعه
        <ol>
            <li>نوشتن کد</li>
            <li>آزمایش برنامه</li>
        </ol>
    </li>
</ol>
```

### ۸.۳. ترکیب لیست مرتب و نامرتب

می‌توان از انواع مختلف لیست در یک ساختار استفاده کرد.

```html
<ol>
    <li>
        نصب نرم‌افزار
        <ul>
            <li>دانلود فایل</li>
            <li>بررسی سیستم موردنیاز</li>
        </ul>
    </li>

    <li>
        پیکربندی
        <ul>
            <li>تنظیم زبان</li>
            <li>انتخاب مسیر نصب</li>
        </ul>
    </li>
</ol>
```

نکته مهم: لیست فرزند باید داخل تگ `<li>` مربوط به مورد والد قرار گیرد، نه مستقیماً در کنار `<li>`های آن.

ساختار صحیح:

```html
<ul>
    <li>
        عنوان والد

        <ul>
            <li>زیرمورد</li>
        </ul>
    </li>
</ul>
```

ساختار نادرست:

```html
<ul>
    <li>عنوان والد</li>
    <ul>
        <li>زیرمورد</li>
    </ul>
</ul>
```

در نمونه دوم، لیست داخلی مستقیماً درون `<ul>` والد قرار گرفته است؛ در حالی که باید بخشی از محتوای یک `<li>` باشد.

## ۹. استایل‌دهی با CSS

HTML مسئول ساختار و معناست و CSS ظاهر لیست‌ها را کنترل می‌کند.

### ۹.۱. ویژگی `list-style-type`

این ویژگی نوع نشانگر لیست را تعیین می‌کند.

```css
/* لیست نامرتب */
ul {
    list-style-type: square;
}

/* لیست مرتب */
ol {
    list-style-type: upper-roman;
}
```

مقادیر پرکاربرد:

| مقدار | توضیح |
|---|---|
| `disc` | دایره توپر |
| `circle` | دایره توخالی |
| `square` | مربع توپر |
| `decimal` | اعداد معمولی |
| `decimal-leading-zero` | اعداد با صفر ابتدایی |
| `lower-alpha` | حروف کوچک انگلیسی |
| `upper-alpha` | حروف بزرگ انگلیسی |
| `lower-roman` | اعداد رومی کوچک |
| `upper-roman` | اعداد رومی بزرگ |
| `none` | حذف نشانگر |

مثال:

```css
.list-a {
    list-style-type: upper-alpha;
}

.list-b {
    list-style-type: decimal-leading-zero;
}

.list-c {
    list-style-type: none;
}
```

### ۹.۲. ویژگی `list-style-position`

این ویژگی مشخص می‌کند نشانگر در کجای محدوده محتوای مورد لیست قرار گیرد.

مقادیر:

- `outside`: نشانگر بیرون از محدوده اصلی متن قرار می‌گیرد؛ این مقدار پیش‌فرض متداول است.
- `inside`: نشانگر در محدوده محتوای مورد لیست قرار می‌گیرد.

```css
ul {
    list-style-position: inside;
}
```

مثال کامل:

```html
<ul class="inside-list">
    <li>
        این یک متن نسبتاً طولانی است که ممکن است در چند خط نمایش داده شود.
    </li>
</ul>
```

```css
.inside-list {
    list-style-position: inside;
}
```

تفاوت این دو مقدار بیشتر هنگام چندخطی شدن متن مشخص می‌شود.

### ۹.۳. ویژگی `list-style-image`

این ویژگی امکان استفاده از یک تصویر به‌عنوان نشانگر را فراهم می‌کند.

```css
ul {
    list-style-image: url("bullet.png");
}
```

در این مثال، مرورگر تلاش می‌کند تصویر `bullet.png` را به‌عنوان نشانگر استفاده کند.

نکته: اگر به کنترل دقیق اندازه، تراز و فاصله تصویر نیاز دارید، استفاده از `::marker` یا `::before` معمولاً انعطاف بیشتری فراهم می‌کند.

### ۹.۴. ویژگی کوتاه‌نویسی `list-style`

می‌توان چند ویژگی مرتبط با نشانگر را با یک اعلان نوشت.

```css
ul {
    list-style: square inside;
}
```

مثال برای لیست مرتب:

```css
ol {
    list-style: upper-roman outside;
}
```

### ۹.۵. حذف نشانگرهای لیست

برای حذف شماره یا علامت کنار موارد از `list-style-type: none` استفاده می‌شود.

```css
ul {
    list-style-type: none;
}
```

این روش در منوهای ناوبری و فهرست‌های طراحی‌شده کاربرد دارد.

مثال:

```html
<nav aria-label="منوی اصلی">
    <ul class="navigation">
        <li><a href="/">خانه</a></li>
        <li><a href="/about">درباره ما</a></li>
        <li><a href="/contact">تماس با ما</a></li>
    </ul>
</nav>
```

```css
.navigation {
    list-style: none;
    margin: 0;
    padding: 0;
}

.navigation li {
    display: inline-block;
    margin-inline-end: 16px;
}
```

### ۹.۶. استفاده از شبه‌عنصر `::marker`

شبه‌عنصر `::marker` برای استایل‌دهی نشانگر لیست استفاده می‌شود.

```css
ul li::marker {
    color: #2563eb;
    font-size: 1.2em;
}

ol li::marker {
    color: #dc2626;
    font-weight: bold;
}
```

با این روش می‌توان رنگ، اندازه فونت و ضخامت نشانگر را تغییر داد.

توجه کنید که `::marker` فقط برخی ویژگی‌های CSS را می‌پذیرد؛ بنابراین برای طراحی پیچیده نشانگرها ممکن است به روش‌های دیگری نیاز داشته باشید.

### ۹.۷. فاصله‌گذاری و طراحی بهتر

```css
.custom-list {
    padding-inline-start: 24px;
}

.custom-list li {
    margin-block: 8px;
    line-height: 1.8;
}
```

در این مثال:

- `padding-inline-start` فاصله ابتدای منطقی لیست را تنظیم می‌کند.
- `margin-block` فاصله عمودی بین موارد را تعیین می‌کند.
- `line-height` فاصله خطوط متن را افزایش می‌دهد.

استفاده از ویژگی‌های منطقی مانند `padding-inline-start` برای صفحات فارسی و طراحی‌های راست‌به‌چپ مناسب‌تر است.

## ۱۰. استفاده از لیست‌ها در HTML معنایی

لیست‌ها علاوه بر ظاهر، معنای ساختاری مشخصی دارند.

انتخاب صحیح تگ به مرورگر و فناوری‌های کمکی کمک می‌کند روابط میان اطلاعات را بهتر تشخیص دهند.

### ۱۰.۱. فهرست مطالب

```html
<nav aria-label="فهرست مطالب">
    <ul>
        <li><a href="#introduction">مقدمه</a></li>
        <li><a href="#features">ویژگی‌ها</a></li>
        <li><a href="#examples">مثال‌ها</a></li>
    </ul>
</nav>
```

### ۱۰.۲. مراحل انجام کار

```html
<section aria-labelledby="steps-title">
    <h2 id="steps-title">مراحل ثبت‌نام</h2>

    <ol>
        <li>ایجاد حساب کاربری</li>
        <li>تأیید ایمیل</li>
        <li>تکمیل اطلاعات</li>
    </ol>
</section>
```

### ۱۰.۳. منوی ناوبری

```html
<nav aria-label="منوی اصلی">
    <ul>
        <li><a href="/">خانه</a></li>
        <li><a href="/products">محصولات</a></li>
        <li><a href="/services">خدمات</a></li>
        <li><a href="/contact">تماس با ما</a></li>
    </ul>
</nav>
```

### ۱۰.۴. نکته درباره ترتیب معنایی

اگر تغییر ترتیب موارد باعث تغییر معنا شود، معمولاً `<ol>` انتخاب مناسب‌تری است.

اگر موارد صرفاً مجموعه‌ای از گزینه‌ها یا ویژگی‌ها باشند، `<ul>` انتخاب بهتری خواهد بود.

برای مثال، مراحل ثبت‌نام یک ترتیب منطقی دارند؛ اما فهرست رنگ‌های موجود برای یک محصول معمولاً به شماره‌گذاری نیاز ندارد.

## ۱۱. دسترس‌پذیری

دسترس‌پذیری (Accessibility) به معنای طراحی محتوایی است که افراد مختلف، از جمله کاربران فناوری‌های کمکی، بتوانند آن را درک کنند و به کار ببرند.

### ۱۱.۱. از تگ مناسب استفاده کنید

برای مجموعه‌ای از موارد مرتبط، از تگ‌های واقعی لیست استفاده کنید.

روش پیشنهادی:

```html
<ul>
    <li>حساب کاربری</li>
    <li>تنظیمات</li>
    <li>خروج</li>
</ul>
```

روش نامناسب برای ساخت لیست:

```html
<div>• حساب کاربری</div>
<div>• تنظیمات</div>
<div>• خروج</div>
```

نمونه دوم فقط علامت‌ها را به متن اضافه می‌کند و ساختار معنایی لیست را ارائه نمی‌دهد.

### ۱۱.۲. به فهرست‌ها عنوان مناسب بدهید

```html
<section aria-labelledby="benefits-title">
    <h2 id="benefits-title">مزایای محصول</h2>

    <ul>
        <li>استفاده آسان</li>
        <li>سرعت بالا</li>
        <li>مصرف انرژی کم</li>
    </ul>
</section>
```

### ۱۱.۳. به نشانگرها فقط برای انتقال معنا تکیه نکنید

اگر یک مورد اولویت بالایی دارد، تنها با رنگ نشانگر یا شکل آن این موضوع را بیان نکنید. اطلاعات مهم باید در متن نیز قابل درک باشند.

### ۱۱.۴. در حذف نشانگرها دقت کنید

حذف نشانگرها با CSS در بعضی مرورگرها و ترکیب‌های فناوری کمکی می‌تواند بر نحوه تشخیص لیست اثر بگذارد.

اگر یک لیست واقعی دارید، ساختار HTML را حفظ کنید و پس از تغییر ظاهر، رفتار آن را با فناوری‌های کمکی و مرورگرهای هدف بررسی کنید.

## ۱۲. اشتباهات رایج

### اشتباه اول: انتخاب لیست بر اساس ظاهر

اشتباه:

```html
<ol>
    <li>قرمز</li>
    <li>آبی</li>
    <li>سبز</li>
</ol>
```

اگر این رنگ‌ها صرفاً مجموعه‌ای از گزینه‌ها باشند، لیست نامرتب معمولاً معنای مناسب‌تری دارد.

روش پیشنهادی:

```html
<ul>
    <li>قرمز</li>
    <li>آبی</li>
    <li>سبز</li>
</ul>
```

### اشتباه دوم: قرار دادن متن به‌جای ساختار لیست

اشتباه:

```html
<ul>
    HTML
    CSS
    JavaScript
</ul>
```

روش صحیح:

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

### اشتباه سوم: قرار دادن لیست تو در تو در محل نادرست

اشتباه:

```html
<ul>
    <li>فرانت‌اند</li>
    <ul>
        <li>HTML</li>
    </ul>
</ul>
```

روش صحیح:

```html
<ul>
    <li>
        فرانت‌اند
        <ul>
            <li>HTML</li>
        </ul>
    </li>
</ul>
```

### اشتباه چهارم: استفاده از ویژگی‌های نامعتبر یا نامناسب

برای مثال، استفاده از `start` روی `<ul>` شماره شروعی را تعیین نمی‌کند؛ زیرا این ویژگی مربوط به `<ol>` است.

روش صحیح:

```html
<ol start="3">
    <li>مورد اول</li>
    <li>مورد دوم</li>
</ol>
```

### اشتباه پنجم: استفاده بیش از حد از استایل درون‌خطی

روش کم‌انعطاف:

```html
<ul style="list-style-type: square; color: blue;">
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

روش پیشنهادی:

```html
<ul class="technology-list">
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

```css
.technology-list {
    list-style-type: square;
    color: blue;
}
```

روش دوم خواناتر است و نگهداری و استفاده مجدد از استایل‌ها را آسان‌تر می‌کند.

## ۱۳. مثال‌های کاربردی

### مثال اول: فهرست مهارت‌ها

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>مهارت‌های من</title>
</head>
<body>
    <h1>مهارت‌های برنامه‌نویسی</h1>

    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
        <li>Git</li>
    </ul>
</body>
</html>
```

### مثال دوم: مراحل ساخت یک وب‌سایت

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>مراحل ساخت وب‌سایت</title>
</head>
<body>
    <h1>مراحل ساخت وب‌سایت</h1>

    <ol>
        <li>تحلیل نیازمندی‌ها</li>
        <li>طراحی رابط کاربری</li>
        <li>پیاده‌سازی HTML</li>
        <li>استایل‌دهی با CSS</li>
        <li>افزودن تعامل با JavaScript</li>
        <li>آزمایش و انتشار</li>
    </ol>
</body>
</html>
```

### مثال سوم: لیست ترکیبی همراه با CSS

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>فهرست دوره‌ها</title>

    <style>
        body {
            font-family: sans-serif;
            line-height: 1.9;
            margin: 32px;
        }

        .course-list {
            list-style-type: square;
            padding-inline-start: 28px;
        }

        .course-list li {
            margin-block: 8px;
        }

        .course-list li::marker {
            color: #2563eb;
        }

        .steps {
            list-style-type: decimal;
            padding-inline-start: 28px;
        }
    </style>
</head>
<body>
    <h1>دوره‌های برنامه‌نویسی</h1>

    <ul class="course-list">
        <li>
            فرانت‌اند
            <ul>
                <li>HTML</li>
                <li>CSS</li>
                <li>JavaScript</li>
            </ul>
        </li>

        <li>
            بک‌اند
            <ul>
                <li>Python</li>
                <li>Node.js</li>
            </ul>
        </li>
    </ul>

    <h2>مراحل ثبت‌نام</h2>

    <ol class="steps">
        <li>انتخاب دوره</li>
        <li>ایجاد حساب کاربری</li>
        <li>پرداخت هزینه</li>
    </ol>
</body>
</html>
```

در این مثال، `lang="fa"` زبان صفحه را فارسی مشخص می‌کند و `dir="rtl"` جهت پایه متن را راست‌به‌چپ قرار می‌دهد.
