# تگ‌های `<a>` و `<img>` 

HTML مخفف HyperText Markup Language است و برای ساختاردهی محتوای صفحات وب استفاده می‌شود.

در HTML، تگ‌ها وظایف مختلفی دارند. برای مثال:

تگ <a> برای ایجاد لینک استفاده می‌شود.

تگ <img> برای نمایش تصویر استفاده می‌شود.

این دو تگ از پرکاربردترین عناصر HTML هستند و در طراحی وب‌سایت‌ها، وبلاگ‌ها، فروشگاه‌های اینترنتی و صفحات شخصی نقش مهمی دارند.

---
## تگ `<a>`
تگ `<a>` مخفف Anchor است و برای ایجاد پیوند یا لینک به یک مقصد استفاده می‌شود.
مقصد لینک می‌تواند یکی از موارد زیر باشد:
- یک صفحه دیگر از وب‌سایت
- یک وب‌سایت خارجی
- یک بخش مشخص از صفحه فعلی
- یک آدرس ایمیل
- یک شماره تلفن
- یک فایل قابل دانلود

### مثال ساده

```html
<a href="https://example.com">ورود به سایت</a>
```

در این مثال:

- `<a>` تگ آغازین لینک است.
- `href` مقصد لینک را مشخص می‌کند.
- `ورود به سایت` متن قابل مشاهده و کلیک است.
- `</a>` تگ پایانی لینک است.

هنگامی که کاربر روی متن «ورود به سایت» کلیک کند، مرورگر به آدرس تعیین‌شده هدایت می‌شود.

---
## ساختار تگ `<a>`
ساختار عمومی این تگ به شکل زیر است:
```html
<a href="URL" target="_self" title="توضیحات لینک">
    متن لینک
</a>
```
ویژگی‌های استفاده‌شده در این مثال:
| ویژگی | توضیح |
|---|---|
| `href` | مقصد لینک |
| `target` | محل باز شدن مقصد |
| `title` | توضیح تکمیلی درباره لینک |

این ویژگی‌ها اختیاری هستند، اما برای ساخت یک لینک معمولی، معمولاً `href` مهم‌ترین ویژگی است.

### لینک بدون `href`

```html
<a>این فقط یک عنصر بدون مقصد مشخص است</a>
```
این کد یک عنصر Anchor ایجاد می‌کند، اما لینک فعال و معمولی به مقصد مشخصی نیست. برای ایجاد یک لینک واقعی، بهتر است `href` را تعیین کنید.

---
## ویژگی‌های مهم تگ `<a>`

### ویژگی `href`
ویژگی `href` مخفف Hypertext Reference است و آدرس مقصد لینک را مشخص می‌کند.
```html
<a href="https://www.google.com">Google</a>
```
اگر `href` یک آدرس اینترنتی کامل باشد، مرورگر می‌تواند به آن وب‌سایت برود.

### ویژگی `target`
ویژگی `target` تعیین می‌کند که مقصد لینک کجا باز شود.
مقادیر رایج:

| مقدار | عملکرد |
|---|---|
| `_self` | باز شدن در همان تب؛ مقدار پیش‌فرض |
| `_blank` | باز شدن در تب یا پنجره جدید |
| `_parent` | باز شدن در چارچوب والد |
| `_top` | باز شدن در کل پنجره مرورگر |

مثال:
```html
<a href="https://example.com" target="_blank" rel="noopener">
    باز کردن سایت در تب جدید
</a>
```
نکته امنیتی: هنگام استفاده از `target="_blank"`، استفاده از `rel="noopener"` یک انتخاب مناسب برای جلوگیری از دسترسی صفحه مقصد به پنجره مبدأ است. مرورگرهای جدید معمولاً برای `_blank` رفتار مشابهی را به‌صورت پیش‌فرض اعمال می‌کنند.

### ویژگی `title`
این ویژگی توضیح تکمیلی درباره لینک ارائه می‌کند.

```html
<a href="https://example.com" title="مشاهده وب‌سایت نمونه">
    سایت نمونه
</a>
```

در برخی مرورگرها، با قرار گرفتن نشانگر ماوس روی لینک، مقدار `title` نمایش داده می‌شود.
نکته: برای توضیحات ضروری، فقط به `title` تکیه نکنید؛ زیرا نمایش آن در دستگاه‌های لمسی و استفاده از صفحه‌خوان‌ها یکسان نیست.

### ویژگی `download`
برای پیشنهاد دانلود یک فایل استفاده می‌شود.
```html
<a href="files/guide.pdf" download>
    دانلود راهنما
</a>
```

همچنین می‌توان نام پیشنهادی فایل را مشخص کرد:
```html
<a href="files/guide.pdf" download="web-guide.pdf">
    دانلود فایل PDF
</a>
```
مرورگر ممکن است با توجه به سیاست‌های امنیتی، مبدأ فایل و نوع سرور، رفتار متفاوتی داشته باشد. این ویژگی برای همه لینک‌های خارجی تضمین دانلود ایجاد نمی‌کند.

### ویژگی `rel`
ویژگی `rel` رابطه میان صفحه فعلی و مقصد لینک را مشخص می‌کند.
مقادیر رایج:

- `noopener`: جلوگیری از دسترسی صفحه مقصد به پنجره مبدأ از طریق `window.opener`.
- `noreferrer`: ارسال نکردن اطلاعات ارجاع‌دهنده (Referer) و جلوگیری از دسترسی از طریق `window.opener`.
- `nofollow`: اعلام اینکه نویسنده لزوماً رابطه تأییدی با مقصد ندارد؛ بیشتر در زمینه موتورهای جست‌وجو استفاده می‌شود.
- `external`: مشخص کردن لینک خارجی از نظر معنایی.

مثال:
```html
<a
    href="https://example.com"
    target="_blank"
    rel="noopener noreferrer"
>
    مشاهده سایت خارجی
</a>
```

### ویژگی `hreflang`
زبان مقصد لینک را معرفی می‌کند.
```html
<a href="https://example.com/en/" hreflang="en">
    English version
</a>
```
این ویژگی زبان صفحه مقصد را توصیف می‌کند؛ به‌تنهایی زبان مرورگر یا زبان صفحه فعلی را تغییر نمی‌دهد.

## انواع لینک‌ها

### لینک خارجی
لینکی به یک وب‌سایت دیگر:
```html
<a href="https://developer.mozilla.org/">
    مستندات MDN
</a>
```
### لینک داخلی
لینکی به صفحه دیگری از همان وب‌سایت:
```html
<a href="about.html">درباره ما</a>
```
اگر فایل `about.html` در مسیر نسبی مورد انتظار قرار داشته باشد، مرورگر آن را باز می‌کند.

### لینک به پوشه یا مسیر دیگر
فرض کنید ساختار پروژه به شکل زیر است:

```text
project/
├── index.html
├── pages/
│   └── about.html
└── contact.html
```

برای رفتن از `index.html` به `about.html`:
```html
<a href="pages/about.html">درباره ما</a>
```
برای رفتن از `about.html` به `contact.html`:
```html
<a href="../contact.html">تماس با ما</a>
```
عبارت `..` به معنی رفتن به پوشه والد است.

### لینک ایمیل
```html
<a href="mailto:info@example.com">
    ارسال ایمیل
</a>
```
می‌توان موضوع ایمیل را هم مشخص کرد:
```html
<a href="mailto:info@example.com?subject=Hello">
    ارسال پیام
</a>
```
برنامه مدیریت ایمیل کاربر، در صورت پیکربندی بودن، باز خواهد شد.

### لینک تماس تلفنی
```html
<a href="tel:+982112345678">
    تماس با ما
</a>
```
این لینک در دستگاه‌ها و برنامه‌هایی که از پروتکل `tel:` پشتیبانی می‌کنند، امکان شروع تماس را فراهم می‌کند.

### لینک دانلود
```html
<a href="files/report.pdf" download>
    دانلود گزارش
</a>
```
### لینک با مقصد خالی یا نامناسب
گاهی از این کد استفاده می‌شود:
```html
<a href="#">کلیک کنید</a>
```
این کار معمولاً انتخاب خوبی نیست؛ چون ممکن است صفحه را به ابتدای سند ببرد و برای کاربران صفحه‌خوان معنای روشنی نداشته باشد.
اگر مقصد واقعی دارید، آدرس آن را مشخص کنید. اگر قصد اجرای یک عمل را دارید، معمولاً باید از `<button>` استفاده کنید.

## باز کردن لینک در تب جدید
برای باز کردن مقصد در تب جدید از `target="_blank"` استفاده کنید:
```html
<a
    href="https://example.com"
    target="_blank"
    rel="noopener noreferrer"
>
    باز کردن سایت در تب جدید
</a>
```
نکات مهم:

1. باز شدن در تب جدید را، به‌خصوص برای لینک‌های غیرمنتظره، به کاربر اطلاع دهید.
2. از باز کردن همه لینک‌ها در تب جدید خودداری کنید.
3. در صورت نیاز به حفظ حریم خصوصی ارجاع‌دهنده، از `noreferrer` استفاده کنید.
4. رفتار نهایی ممکن است به تنظیمات مرورگر بستگی داشته باشد.

## لینک به بخش مشخصی از صفحه
برای رفتن به یک بخش خاص از صفحه، از شناسه `id` استفاده می‌کنیم.
ابتدا بخش موردنظر را تعریف کنید:

```html
<h2 id="services">خدمات ما</h2>

<p>توضیحات مربوط به خدمات در این قسمت قرار دارد.</p>
```
سپس لینک را بسازید:
```html
<a href="#services">مشاهده خدمات</a>
```
با کلیک روی لینک، مرورگر به عنصری می‌رود که شناسه آن `services` است.

### لینک به بخش صفحه‌ای دیگر
```html
<a href="about.html#team">اعضای تیم</a>
```
در این مثال، مرورگر ابتدا صفحه `about.html` را باز می‌کند و سپس به عنصر دارای `id="team"` می‌رود.
هر `id` باید در همان سند یکتا باشد.

## لینک کردن تصاویر و عناصر دیگر
محتوای داخل `<a>` می‌تواند متن، تصویر یا عناصر مجاز دیگری باشد.
### لینک کردن تصویر

```html
<a href="https://example.com">
    <img src="images/logo.png" alt="لوگوی سایت نمونه">
</a>
```
با کلیک روی تصویر، کاربر به مقصد لینک هدایت می‌شود.

### لینک کردن یک عنوان

```html
<a href="article.html">
    <h2>آموزش HTML</h2>
</a>
```

### ساخت یک کارت قابل کلیک

```html
<a href="product.html" class="product-card">
    <img src="images/product.jpg" alt="کفش ورزشی مشکی">
    <h2>کفش ورزشی</h2>
    <p>مشاهده جزئیات محصول</p>
</a>
```
در HTML مدرن، می‌توان یک لینک را طوری ساخت که چند عنصر محتوایی را در بر بگیرد. با این حال، نباید داخل یک لینک، لینک دیگری قرار دهید یا کنترل‌های تعاملی مستقل مانند دکمه را بدون درنظر گرفتن قواعد HTML تو در تو کنید.

## تگ `<img>`

تگ `<img>` مخفف Image است و برای نمایش تصویر در صفحه وب استفاده می‌شود.
کاربردهای رایج:

- نمایش عکس‌ها
- نمایش لوگو
- نمایش تصاویر محصولات
- نمایش نمودارها و تصاویر آموزشی
- نمایش تصویر شاخص مقاله

### مثال ساده

```html
<img src="photo.jpg" alt="نمایی از یک کوهستان">
```
در این مثال:
- `img` عنصر تصویر را ایجاد می‌کند.
- `src` آدرس فایل تصویر را مشخص می‌کند.
- `alt` متن جایگزین تصویر را مشخص می‌کند.

نکته مهم: تگ `<img>` یک عنصر خالی (Void Element) است و تگ پایانی ندارد.

شکل درست:

```html
<img src="photo.jpg" alt="عکس طبیعت">
```
در HTML نیازی به نوشتن `</img>` نیست.

---
## ساختار تگ `<img>`
ساختار عمومی:
```html
<img
    src="image.jpg"
    alt="توضیحات تصویر"
    width="600"
    height="400"
>
```

| ویژگی | کاربرد |
|---|---|
| `src` | مسیر تصویر |
| `alt` | متن جایگزین |
| `width` | عرض تصویر |
| `height` | ارتفاع تصویر |
| `loading` | شیوه بارگذاری تصویر |
| `decoding` | راهنمای رمزگشایی تصویر |
| `srcset` | مجموعه منابع جایگزین تصویر |
| `sizes` | اندازه نمایشی مورد انتظار برای انتخاب منبع مناسب |
| `crossorigin` | تنظیم حالت درخواست بین‌مبدأ |
| `referrerpolicy` | سیاست ارسال اطلاعات ارجاع‌دهنده |
| `usemap` | اتصال تصویر به یک Image Map |

بعضی از این ویژگی‌ها پیشرفته هستند و فقط در سناریوهای خاص به کار می‌روند.

---
## ویژگی‌های مهم تگ `<img>`

### ویژگی `src`
مهم‌ترین ویژگی تصویر است و مسیر فایل را تعیین می‌کند.
```html
<img src="images/cat.jpg" alt="گربه‌ای روی مبل">
```
اگر مسیر اشتباه باشد یا فایل در دسترس نباشد، تصویر معمولاً نمایش داده نمی‌شود.

### ویژگی `alt`
ویژگی `alt` متن جایگزین تصویر است.
```html
<img src="images/dog.jpg" alt="سگی در حال دویدن در پارک">
```
این متن در شرایطی مانند موارد زیر اهمیت دارد:

- تصویر بارگذاری نشود.
- کاربر از صفحه‌خوان استفاده کند.
- تصویر برای انتقال اطلاعات مهم باشد.

مقدار `alt` باید هدف و محتوای مهم تصویر را بیان کند، نه اینکه همیشه صرفاً نام فایل یا عبارت «تصویر» باشد.

### ویژگی‌های `width` و `height`
برای تعیین عرض و ارتفاع ذاتی تصویر برحسب پیکسل استفاده می‌شوند.
```html
<img
    src="images/banner.jpg"
    alt="بنر معرفی محصولات"
    width="1200"
    height="400"
>
```
این ویژگی‌ها به مرورگر کمک می‌کنند فضای موردنیاز تصویر را از ابتدا رزرو کند و احتمال جابه‌جایی محتوا هنگام بارگذاری را کاهش دهد.
می‌توان با CSS اندازه نمایشی متفاوتی تعیین کرد.

### ویژگی `loading`
دو مقدار متداول دارد:

- `eager`: بارگذاری عادی و بدون تأخیر عمدی توسط قابلیت Lazy Loading.
- `lazy`: به تعویق انداختن بارگذاری تا زمانی که تصویر به محدوده مناسب نزدیک شود.
مثال:
```html
<img
    src="images/gallery.jpg"
    alt="تصویری از گالری"
    width="800"
    height="600"
    loading="lazy"
>
```
برای تصاویر پایین صفحه، `loading="lazy"` می‌تواند مفید باشد.
برای تصویر اصلی و مهمی که از همان ابتدا در صفحه دیده می‌شود، معمولاً نباید بارگذاری را با Lazy Loading به تأخیر انداخت.

### ویژگی `decoding`
این ویژگی راهنمایی برای نحوه رمزگشایی تصویر ارائه می‌کند.
```html
<img
    src="images/photo.jpg"
    alt="منظره دریا"
    decoding="async"
>
```
مقادیر رایج:
- `async`: اجازه می‌دهد رمزگشایی تصویر به‌صورت غیرهم‌زمان انجام شود.
- `sync`: رمزگشایی هم‌زمان را درخواست می‌کند.
- `auto`: تصمیم‌گیری را به مرورگر واگذار می‌کند.

این ویژگی بیشتر یک راهنما برای مرورگر است و تضمین قطعی برای زمان‌بندی رندرینگ نیست.

## فرمت‌های رایج تصاویر

| فرمت | پسوند رایج | کاربرد |
|---|---|---|
| JPEG | `.jpg`, `.jpeg` | عکس‌ها و تصاویر طبیعی |
| PNG | `.png` | تصاویر دارای شفافیت و گرافیک |
| GIF | `.gif` | تصاویر متحرک ساده |
| SVG | `.svg` | لوگوها و تصاویر برداری |
| WebP | `.webp` | عکس و گرافیک با فشرده‌سازی مناسب |
| AVIF | `.avif` | تصاویر فشرده با کیفیت مناسب |
| ICO | `.ico` | آیکون‌ها، به‌ویژه آیکون‌های مرورگر |

مثال:
```html
<img src="images/logo.svg" alt="لوگوی شرکت">
```

```html
<img src="images/nature.webp" alt="منظره طبیعی">
```
انتخاب فرمت مناسب به نوع تصویر، کیفیت موردنیاز، حجم فایل و سازگاری مرورگرها بستگی دارد.

## مسیر تصاویر در HTML
مسیر تصویر مشخص می‌کند مرورگر فایل را از کجا پیدا کند.
فرض کنید ساختار پروژه چنین باشد:

```text
project/
├── index.html
├── images/
│   ├── logo.png
│   └── nature.jpg
└── pages/
    └── gallery.html
```
### مسیر نسبی
اگر فایل HTML در ریشه پروژه باشد:
```html
<img src="images/logo.png" alt="لوگو">
```
اگر فایل `gallery.html` داخل پوشه `pages` باشد:
```html
<img src="../images/nature.jpg" alt="طبیعت">
```

### مسیر مطلق در وب‌سایت
```html
<img src="/images/logo.png" alt="لوگو">
```
اسلش ابتدایی معمولاً به ریشه وب‌سایت اشاره می‌کند، نه لزوماً پوشه‌ای که فایل HTML در آن قرار دارد.

### آدرس کامل اینترنتی
```html
<img
    src="https://example.com/images/banner.jpg"
    alt="بنر وب‌سایت"
>
```
در این حالت، تصویر از یک آدرس اینترنتی بارگذاری می‌شود. در دسترس بودن فایل و سیاست‌های سرور مقصد نیز اهمیت دارند.

---
## ویژگی `alt` و دسترس‌پذیری
نوشتن `alt` مناسب یکی از مهم‌ترین اصول استفاده صحیح از `<img>` است.

### تصویر اطلاعاتی
برای تصویری که اطلاعاتی منتقل می‌کند، متن جایگزین متناسب با محتوای مهم آن بنویسید:
```html
<img
    src="images/chart.png"
    alt="نمودار فروش که رشد فروش را در سه‌ماهه پایانی نشان می‌دهد"
>
```
### تصویر تزئینی
اگر تصویر صرفاً تزئینی است و اطلاعات تازه‌ای ارائه نمی‌کند، از مقدار خالی `alt` استفاده کنید:
```html
<img src="images/decoration.png" alt="">
```
این کار به صفحه‌خوان‌ها کمک می‌کند تصویر تزئینی را نادیده بگیرند.

### تصویر لینک‌شده
وقتی تصویر داخل لینک قرار دارد، متن جایگزین باید هدف لینک را برای کاربر مشخص کند.
```html
<a href="/home">
    <img src="images/logo.png" alt="صفحه اصلی">
</a>
```
اگر لوگو به صفحه اصلی می‌رود، عبارت «صفحه اصلی» می‌تواند از نظر هدف لینک مفیدتر از «تصویر لوگو» باشد.

### اشتباه رایج در `alt`
```html
<img src="cat.jpg" alt="image">
```
این متن اطلاعات مفیدی درباره تصویر ارائه نمی‌کند.
نمونه بهتر:

```html
<img src="cat.jpg" alt="گربه‌ای سفید در حال خوابیدن روی صندلی">
```
نکته: متن جایگزین نباید بیش از حد طولانی یا پر از کلمات کلیدی باشد. هدف آن انتقال اطلاعات مرتبط با تصویر و زمینه استفاده از آن است.

## اندازه و نحوه نمایش تصویر
HTML می‌تواند اندازه ذاتی تصویر را مشخص کند، اما CSS معمولاً برای کنترل ظاهر و واکنش‌گرایی استفاده می‌شود.

### تعیین اندازه با HTML
```html
<img
    src="images/photo.jpg"
    alt="عکس طبیعت"
    width="500"
    height="300"
>
```
### تعیین اندازه با CSS
```html
<img
    src="images/photo.jpg"
    alt="عکس طبیعت"
    class="photo"
>
```

```css
.photo {
    width: 500px;
    height: auto;
}
```
مقدار `height: auto` باعث می‌شود ارتفاع متناسب با عرض و نسبت ابعاد تصویر تعیین شود.

### تصویر واکنش‌گرا
برای جلوگیری از بیرون زدن تصویر از عرض صفحه:
```css
img {
    max-width: 100%;
    height: auto;
}
```
این قانون تصویر را در صورت نیاز کوچک می‌کند، اما معمولاً آن را از اندازه ذاتی بزرگ‌تر نمی‌کند.

### استفاده از `object-fit`
اگر تصویر باید در یک قاب با اندازه مشخص قرار بگیرد:
```html
<img
    class="product-image"
    src="images/shoes.jpg"
    alt="کفش ورزشی"
    width="400"
    height="300"
>
```

```css
.product-image {
    width: 300px;
    height: 200px;
    object-fit: cover;
}
```

مقادیر رایج `object-fit`:

- `cover`: قاب را پر می‌کند؛ ممکن است بخشی از تصویر بریده شود.
- `contain`: کل تصویر را داخل قاب جا می‌دهد؛ ممکن است فضای خالی باقی بماند.
- `fill`: تصویر را به ابعاد قاب می‌کشاند و ممکن است نسبت تصویر تغییر کند.
- `none`: از اندازه ذاتی تصویر استفاده می‌کند.
- `scale-down`: بین `none` و `contain`، اندازه کوچک‌تر را انتخاب می‌کند.

### تنظیم موقعیت برش

```css
.product-image {
    width: 300px;
    height: 200px;
    object-fit: cover;
    object-position: center;
}
```
برای تمرکز روی بخش خاصی از تصویر می‌توانید از مقادیر دیگر `object-position` استفاده کنید.

## بارگذاری بهینه تصاویر
بهینه‌سازی تصاویر می‌تواند سرعت بارگذاری، تجربه کاربری و مصرف اینترنت را بهبود دهد.

### استفاده از `loading="lazy"`
برای تصاویر غیرضروری در ابتدای صفحه:
```html
<img
    src="images/gallery-1.webp"
    alt="نمایی از گالری"
    width="800"
    height="600"
    loading="lazy"
>
```
از Lazy Loading برای تمام تصاویر، بدون توجه به جایگاهشان، استفاده نکنید. تصویر اصلی صفحه ممکن است به بارگذاری فوری نیاز داشته باشد.

### استفاده از `fetchpriority`
برای تصویری که واقعاً مهم است و باید زودتر دریافت شود، می‌توان از اولویت بالا استفاده کرد:
```html
<img
    src="images/hero.webp"
    alt="تصویر اصلی صفحه"
    width="1600"
    height="900"
    fetchpriority="high"
>
```
این ویژگی را بی‌دلیل برای تعداد زیادی از تصاویر فعال نکنید؛ استفاده از آن باید با نیاز واقعی بارگذاری صفحه هماهنگ باشد.

### انتخاب منبع مناسب با `srcset`
فرض کنید چند نسخه از یک تصویر با اندازه‌های متفاوت دارید:

```html
<img
    src="images/photo-800.jpg"
    srcset="
        images/photo-400.jpg 400w,
        images/photo-800.jpg 800w,
        images/photo-1200.jpg 1200w
    "
    sizes="(max-width: 600px) 100vw, 800px"
    alt="منظره کوهستان"
    width="800"
    height="533"
>
```

در این مثال:

- `src` یک منبع جایگزین پایه ارائه می‌کند.
- `srcset` منابع تصویری و عرض ذاتی آن‌ها را معرفی می‌کند.
- `sizes` اندازه نمایشی مورد انتظار را بر اساس شرایط صفحه بیان می‌کند.
- مرورگر با توجه به اندازه نمایشگر، تراکم پیکسل و شرایط دیگر، منبع مناسب را انتخاب می‌کند.

نکته: مقادیر `400w` و `800w` عرض واقعی فایل‌های تصویری را برحسب پیکسل معرفی می‌کنند؛ این مقادیر نباید صرفاً حدس زده شوند.

### کاهش حجم فایل
برای بهبود عملکرد:

- تصاویر را متناسب با اندازه نمایش نهایی تولید کنید.
- از فرمت مناسب استفاده کنید.
- فشرده‌سازی مناسب را انتخاب کنید.
- برای تصاویر بزرگ، نسخه‌های چنداندازه‌ای تهیه کنید.
- از بارگذاری تصاویر غیرضروری در ابتدای صفحه خودداری کنید.

## ویژگی‌های پیشرفته تصویر

### استفاده از `<picture>`
تگ `<picture>` امکان ارائه چند منبع تصویر را فراهم می‌کند. این قابلیت برای انتخاب فرمت یا تصویر متناسب با اندازه نمایشگر مفید است.

```html
<picture>
    <source
        srcset="images/hero.avif"
        type="image/avif"
    >

    <source
        srcset="images/hero.webp"
        type="image/webp"
    >

    <img
        src="images/hero.jpg"
        alt="نمایی از طبیعت"
        width="1200"
        height="800"
    >
</picture>
```
مرورگر منبع مناسب و پشتیبانی‌شده را انتخاب می‌کند. تگ `<img>` داخل `<picture>` ضروری است و منبع جایگزین و اطلاعات جایگزین را فراهم می‌کند.

### ویژگی `crossorigin`
این ویژگی نحوه درخواست منابع بین‌مبدأ را تعیین می‌کند.

```html
<img
    src="https://example.com/photo.jpg"
    alt="تصویر نمونه"
    crossorigin="anonymous"
>
```
این ویژگی در سناریوهایی مانند استفاده از تصویر در Canvas و دریافت داده‌های بین‌مبدأ اهمیت دارد. برای دسترسی محدودشده به داده‌های تصویر، سرور مقصد باید هدرهای CORS مناسب را ارسال کند.

### ویژگی `referrerpolicy`
سیاست ارسال اطلاعات ارجاع‌دهنده را کنترل می‌کند.
```html
<img
    src="https://example.com/photo.jpg"
    alt="تصویر نمونه"
    referrerpolicy="no-referrer"
>
```
مقدار `no-referrer` مانع ارسال اطلاعات ارجاع‌دهنده برای آن درخواست می‌شود.

### Image Map با `usemap`
می‌توان قسمت‌های مختلف یک تصویر را به لینک‌های متفاوت متصل کرد.
```html
<img
    src="images/plan.png"
    alt="نقشه بخش‌های ساختمان"
    usemap="#building-map"
    width="600"
    height="400"
>

<map name="building-map">
    <area
        shape="rect"
        coords="20,20,200,150"
        href="office.html"
        alt="بخش اداری"
    >

    <area
        shape="rect"
        coords="220,20,400,150"
        href="garden.html"
        alt="باغ"
    >
</map>
```
در این مثال، مختصات نواحی برحسب پیکسل‌های تصویر اصلی تعریف شده‌اند. اگر تصویر با CSS تغییر اندازه پیدا کند، مدیریت مختصات و رفتار نواحی در اندازه‌های مختلف نیازمند توجه ویژه است.

## تفاوت تگ `<a>` و `<img>`
این دو تگ وظایف متفاوتی دارند.

| ویژگی | `<a>` | `<img>` |
|---|---|---|
| کاربرد اصلی | ایجاد لینک | نمایش تصویر |
| تگ پایانی | دارد | ندارد |
| ویژگی مهم | `href` | `src` |
| متن جایگزین | ویژگی استاندارد `alt` ندارد | از `alt` پشتیبانی می‌کند |
| امکان کلیک | برای پیمایش و فعال‌سازی مقصد طراحی شده | به‌تنهایی لینک نیست |
| کاربرد رایج | رفتن به صفحه یا مقصد دیگر | نمایش عکس، لوگو و نمودار |

مثال لینک:
```html
<a href="about.html">درباره ما</a>
```
مثال تصویر:

```html
<img src="logo.png" alt="لوگوی سایت">
```
مثال ترکیبی:
```html
<a href="index.html">
    <img src="logo.png" alt="صفحه اصلی">
</a>
```
در مثال ترکیبی، `<a>` مقصد کلیک را تعیین می‌کند و `<img>` محتوای تصویری قابل مشاهده را ارائه می‌دهد.
