# کنترل ابعاد عناصر در CSS با `width`، `height` و `box-sizing`

در CSS برای کنترل اندازه و ابعاد عناصر HTML از ویژگی‌هایی مانند `width`، `height` و `box-sizing` استفاده می‌کنیم.

این ویژگی‌ها مشخص می‌کنند:

- عرض یک عنصر چقدر باشد.
- ارتفاع یک عنصر چقدر باشد.
- فضای داخلی عنصر چگونه محاسبه شود.
- آیا `padding` و `border` به ابعاد نهایی عنصر اضافه شوند یا خیر.

برای طراحی صفحات وب واکنش‌گرا (Responsive) و ایجاد چیدمان‌های دقیق، شناخت این ویژگی‌ها ضروری است.

---

## ویژگی width

ویژگی `width` برای تعیین عرض یک عنصر در CSS استفاده می‌شود.

### ساختار کلی

```css
selector {
    width: value;
}
```

### مثال

```css
.box {
    width: 300px;
}
```

در این مثال عرض عنصر `.box` برابر با ۳۰۰ پیکسل خواهد بود.

### تعیین عرض با درصد

```css
.container {
    width: 80%;
}
```

در این حالت عرض عنصر برابر با ۸۰ درصد عرض فضای مرجع آن خواهد بود.

برای مثال اگر عرض فضای مرجع ۱۰۰۰ پیکسل باشد، عرض عنصر ۸۰۰ پیکسل خواهد شد.

### تعیین عرض خودکار

```css
.box {
    width: auto;
}
```

مقدار `auto` به مرورگر اجازه می‌دهد عرض عنصر را با توجه به نوع عنصر، فضای در دسترس و قوانین چیدمان محاسبه کند.

برای عناصر Block معمولی، عرض `auto` معمولاً باعث می‌شود عنصر فضای افقی در دسترس را پر کند.

### مقدارهای مهم width

| مقدار | توضیح |
|---|---|
| `auto` | محاسبه خودکار عرض |
| `100px` | عرض ثابت ۱۰۰ پیکسل |
| `50%` | عرض برابر با ۵۰ درصد فضای مرجع |
| `50vw` | عرض برابر با ۵۰ درصد عرض صفحه نمایش |
| `fit-content` | اندازه‌گیری متناسب با محتوا و فضای در دسترس |
| `max-content` | عرض موردنیاز برای نمایش محتوا بدون شکستن خطوط، در صورت امکان |
| `min-content` | کمترین عرض ذاتی محتوا با توجه به امکان شکستن آن |

## ویژگی height

ویژگی `height` برای تعیین ارتفاع یک عنصر استفاده می‌شود.

### ساختار کلی

```css
selector {
    height: value;
}
```

### مثال

```css
.box {
    height: 200px;
}
```

در این مثال ارتفاع عنصر برابر با ۲۰۰ پیکسل است.

### تعیین ارتفاع با درصد

```css
.container {
    height: 50%;
}
```

در این حالت ارتفاع عنصر به ارتفاع فضای مرجع آن وابسته است.

**نکته مهم:**

برای اینکه درصد ارتفاع به‌درستی محاسبه شود، معمولاً باید ارتفاع عنصر والد مشخص باشد.

مثال:

```css
.parent {
    height: 400px;
}

.child {
    height: 50%;
}
```

در این مثال ارتفاع عنصر فرزند برابر با ۲۰۰ پیکسل خواهد بود.

اگر ارتفاع والد مشخص نباشد، درصد ارتفاع در بسیاری از شرایط به‌صورت `auto` محاسبه می‌شود.

### ارتفاع خودکار

```css
.box {
    height: auto;
}
```

با استفاده از `auto` ارتفاع عنصر معمولاً بر اساس محتوای داخلی آن تعیین می‌شود.

برای مثال اگر محتوای عنصر بیشتر شود، ارتفاع آن نیز می‌تواند افزایش پیدا کند.

### مقدارهای مهم height

| مقدار | توضیح |
|---|---|
| `auto` | ارتفاع خودکار |
| `100px` | ارتفاع ثابت ۱۰۰ پیکسل |
| `50%` | ۵۰ درصد ارتفاع فضای مرجع |
| `50vh` | ۵۰ درصد ارتفاع صفحه نمایش |
| `fit-content` | ارتفاع متناسب با محتوا و فضای موجود |
| `max-content` | ارتفاع موردنیاز برای نمایش کامل محتوا |
| `min-content` | حداقل ارتفاع ذاتی محتوا |

## واحدهای اندازه‌گیری

برای تعیین مقدار `width` و `height` می‌توان از واحدهای مختلف CSS استفاده کرد.

### ۱. واحد px

واحد `px` یک واحد ثابت در CSS است.

```css
.box {
    width: 300px;
    height: 200px;
}
```

در این مثال عرض و ارتفاع عنصر به‌ترتیب ۳۰۰ و ۲۰۰ پیکسل CSS هستند.

### ۲. واحد %

واحد درصد نسبت به فضای مرجع محاسبه می‌شود.

```css
.parent {
    width: 800px;
}

.child {
    width: 50%;
}
```

عرض فرزند برابر با ۴۰۰ پیکسل خواهد بود.

### ۳. واحد vw

واحد `vw` نسبت به عرض viewport یا فضای قابل مشاهده مرورگر محاسبه می‌شود.

هر `1vw` برابر با یک درصد عرض viewport است.

```css
.box {
    width: 50vw;
}
```

اگر عرض viewport برابر با ۱۲۰۰ پیکسل باشد، عرض عنصر ۶۰۰ پیکسل خواهد بود.

### ۴. واحد vh

واحد `vh` نسبت به ارتفاع viewport محاسبه می‌شود.

هر `1vh` برابر با یک درصد ارتفاع viewport است.

```css
.box {
    height: 50vh;
}
```

اگر ارتفاع viewport برابر با ۸۰۰ پیکسل باشد، ارتفاع عنصر ۴۰۰ پیکسل خواهد بود.

### ۵. واحد rem

واحد `rem` نسبت به اندازه فونت عنصر ریشه یعنی `html` محاسبه می‌شود.

```css
html {
    font-size: 16px;
}

.box {
    width: 20rem;
}
```

در این مثال عرض عنصر برابر با ۳۲۰ پیکسل خواهد بود.

### ۶. واحد em

واحد `em` نسبت به اندازه فونت مرجع همان عنصر یا محیط ارث‌بری‌شده آن محاسبه می‌شود. در ویژگی‌های اندازه‌گذاری مانند `width` و `height`، مقدار `em` بر اساس `font-size` خود عنصر محاسبه می‌شود.

```css
.box {
    font-size: 20px;
    width: 10em;
}
```

عرض عنصر برابر با ۲۰۰ پیکسل خواهد بود.

### مقایسه واحدها

| واحد | مبنای محاسبه |
|---|---|
| `px` | پیکسل CSS |
| `%` | فضای مرجع وابسته به ویژگی |
| `vw` | عرض viewport |
| `vh` | ارتفاع viewport |
| `rem` | اندازه فونت عنصر ریشه |
| `em` | اندازه فونت مرجع عنصر |

## محدود کردن ابعاد با min و max

گاهی نمی‌خواهیم یک عنصر بیش از اندازه کوچک یا بزرگ شود.

برای کنترل این موضوع از ویژگی‌های زیر استفاده می‌کنیم:

- `min-width`
- `max-width`
- `min-height`
- `max-height`

### ویژگی min-width

حداقل عرض مجاز یک عنصر را مشخص می‌کند.

```css
.box {
    min-width: 200px;
}
```

عرض عنصر نباید از ۲۰۰ پیکسل کمتر شود.

### ویژگی max-width

حداکثر عرض مجاز عنصر را مشخص می‌کند.

```css
.box {
    max-width: 800px;
}
```

عرض عنصر از ۸۰۰ پیکسل بیشتر نمی‌شود.

### ویژگی min-height

حداقل ارتفاع عنصر را مشخص می‌کند.

```css
.box {
    min-height: 200px;
}
```

### ویژگی max-height

حداکثر ارتفاع عنصر را مشخص می‌کند.

```css
.box {
    max-height: 500px;
}
```

### ترکیب width و max-width

یکی از کاربردی‌ترین روش‌ها برای طراحی واکنش‌گرا:

```css
.container {
    width: 90%;
    max-width: 1200px;
    margin: 0 auto;
}
```

در این مثال:

- عرض کانتینر در صفحه‌های کوچک ۹۰ درصد فضای مرجع است.
- عرض آن حداکثر به ۱۲۰۰ پیکسل می‌رسد.
- با استفاده از `margin: 0 auto` در مرکز قرار می‌گیرد.

### ترکیب min-height و height

```css
.section {
    min-height: 300px;
    height: auto;
}
```

ارتفاع بخش حداقل ۳۰۰ پیکسل خواهد بود؛ اما اگر محتوا به فضای بیشتری نیاز داشته باشد، ارتفاع عنصر افزایش پیدا می‌کند.

## مدل جعبه‌ای یا Box Model

یکی از مهم‌ترین مفاهیم در CSS، مدل جعبه‌ای یا Box Model است.

مرورگر هر عنصر HTML را به شکل یک جعبه در نظر می‌گیرد.

این جعبه از چهار بخش تشکیل شده است:

<pre>
+--------------------------------------+
|                Margin                |
|   +------------------------------+   |
|   |           Border             |   |
|   |   +----------------------+   |   |
|   |   |       Padding        |   |   |
|   |   |   +--------------+   |   |   |
|   |   |   |   Content    |   |   |   |
|   |   |   +--------------+   |   |   |
|   |   +----------------------+   |   |
|   +------------------------------+   |
+--------------------------------------+
</pre>

### ۱. Content

محتوای اصلی عنصر است.

برای مثال:

- متن
- تصویر
- سایر عناصر HTML

ویژگی‌های `width` و `height` در مدل پیش‌فرض `content-box` ابعاد همین قسمت را مشخص می‌کنند.

### ۲. Padding

فاصله داخلی بین محتوا و Border است.

```css
.box {
    padding: 20px;
}
```

در این مثال از هر چهار طرف محتوا ۲۰ پیکسل فاصله داخلی ایجاد می‌شود.

### ۳. Border

حاشیه یا کادر اطراف عنصر است.

```css
.box {
    border: 5px solid black;
}
```

در این مثال یک حاشیه ۵ پیکسلی ایجاد می‌شود.

### ۴. Margin

فاصله خارجی بین عنصر و عناصر اطراف آن است.

```css
.box {
    margin: 20px;
}
```

در این مثال از هر چهار طرف عنصر ۲۰ پیکسل فاصله خارجی ایجاد می‌شود.

## ویژگی box-sizing

ویژگی `box-sizing` مشخص می‌کند مرورگر ابعاد نهایی عنصر را چگونه محاسبه کند.

این ویژگی دو مقدار اصلی و پرکاربرد دارد:

1. `content-box`
2. `border-box`

### ۱. مقدار content-box

این مقدار، مقدار پیش‌فرض `box-sizing` است.

```css
.box {
    width: 300px;
    height: 200px;
    padding: 20px;
    border: 5px solid black;
    box-sizing: content-box;
}
```

در این حالت:

- عرض محتوا: ۳۰۰ پیکسل
- Padding چپ و راست: مجموعاً ۴۰ پیکسل
- Border چپ و راست: مجموعاً ۱۰ پیکسل

بنابراین عرض نهایی عنصر:

```text
300 + 40 + 10 = 350px
```

ارتفاع نهایی نیز:

```text
200 + 40 + 10 = 250px
```

پس ابعاد واقعی جعبه برابر با ۳۵۰ در ۲۵۰ پیکسل خواهد بود.

### فرمول محاسبه در content-box

```text
عرض نهایی =
width + padding-left + padding-right + border-left + border-right
```

```text
ارتفاع نهایی =
height + padding-top + padding-bottom + border-top + border-bottom
```

نکته: `margin` در این محاسبه وارد نمی‌شود.

### ۲. مقدار border-box

در این حالت `width` و `height` ابعاد جعبه را با احتساب `padding` و `border` مشخص می‌کنند.

```css
.box {
    width: 300px;
    height: 200px;
    padding: 20px;
    border: 5px solid black;
    box-sizing: border-box;
}
```

در این مثال:

- عرض کل جعبه: ۳۰۰ پیکسل
- ارتفاع کل جعبه: ۲۰۰ پیکسل
- Padding و Border داخل همین ابعاد محاسبه می‌شوند.

بنابراین ابعاد نهایی عنصر تغییر نمی‌کند و برابر با ۳۰۰ در ۲۰۰ پیکسل باقی می‌ماند.

### فرمول محاسبه در border-box

```text
عرض محتوا =
width - padding-left - padding-right - border-left - border-right
```

```text
ارتفاع محتوا =
height - padding-top - padding-bottom - border-top - border-bottom
```

البته این فرمول‌ها زمانی کاربرد دارند که ابعاد مشخص‌شده به‌اندازه مجموع Padding و Border باشند.

## تفاوت content-box و border-box

فرض کنید دو عنصر با مشخصات یکسان داشته باشیم:

```css
.box {
    width: 300px;
    height: 200px;
    padding: 20px;
    border: 5px solid black;
}
```

اگر عنصر اول از `content-box` و عنصر دوم از `border-box` استفاده کند، نتیجه متفاوت خواهد بود.

| ویژگی | content-box | border-box |
|---|---:|---:|
| width | 300px | 300px |
| height | 200px | 200px |
| Padding | 20px | 20px |
| Border | 5px | 5px |
| عرض نهایی | 350px | 300px |
| ارتفاع نهایی | 250px | 200px |

### نتیجه

در `content-box`، با اضافه شدن Padding و Border ابعاد نهایی عنصر بزرگ‌تر می‌شود.

اما در `border-box`، Padding و Border در ابعاد تعیین‌شده محاسبه می‌شوند.

به همین دلیل استفاده از `border-box` در طراحی رابط کاربری بسیار رایج است.

## تنظیم box-sizing برای تمام عناصر

یکی از روش‌های استاندارد و پرکاربرد در CSS این است که `box-sizing: border-box` را برای تمام عناصر صفحه تنظیم کنیم.

### روش اول: انتخاب تمام عناصر

```css
* {
    box-sizing: border-box;
}
```

در این حالت تمام عناصر با مدل `border-box` محاسبه می‌شوند.

### روش دوم: روش پیشنهادی و قابل توسعه

```css
html {
    box-sizing: border-box;
}

*,
*::before,
*::after {
    box-sizing: inherit;
}
```

در این روش:

1. عنصر ریشه یعنی `html` دارای `box-sizing: border-box` است.
2. تمام عناصر از مقدار والد خود ارث‌بری می‌کنند.
3. شبه‌عناصر `::before` و `::after` نیز شامل این قانون می‌شوند.

این روش برای پروژه‌های بزرگ مناسب است و امکان تغییر مقدار `box-sizing` در بخش‌های مختلف پروژه را ساده‌تر می‌کند.

## نکات مهم و اشتباهات رایج

### ۱. اشتباه گرفتن width با عرض نهایی

در حالت `content-box`، مقدار `width` فقط عرض محتوا است و Padding و Border به آن اضافه می‌شوند.

### ۲. فراموش کردن تأثیر Padding

```css
.box {
    width: 400px;
    padding: 30px;
}
```

در حالت پیش‌فرض `content-box`، عرض نهایی ۴۶۰ پیکسل خواهد بود.

### ۳. تصور اینکه Margin داخل width محاسبه می‌شود

Margin هیچ‌وقت بخشی از عرض یا ارتفاع محاسبه‌شده توسط `box-sizing` نیست.

### ۴. استفاده نامناسب از height ثابت

```css
.box {
    height: 100px;
}
```

اگر محتوای عنصر از ارتفاع تعیین‌شده بیشتر باشد، ممکن است محتوا از جعبه خارج شود یا با توجه به ویژگی `overflow` بریده یا اسکرول‌پذیر شود.

برای بخش‌هایی که محتوای متغیر دارند، اغلب استفاده از `min-height` یا `height: auto` انتخاب مناسب‌تری است.

### ۵. فراموش کردن ارتفاع والد در درصدها

```css
.parent {
    height: auto;
}

.child {
    height: 50%;
}
```

در این مثال معمولاً نمی‌توان انتظار داشت ارتفاع فرزند نصف ارتفاع محتوای والد شود؛ زیرا ارتفاع والد به‌صورت صریح مشخص نشده است.

### ۶. تصور اینکه box-sizing روی Margin تأثیر دارد

ویژگی `box-sizing` فقط نحوه محاسبه Content، Padding و Border را مشخص می‌کند و Margin را شامل نمی‌شود.

### ۷. تفاوت عناصر Inline و Block

برای عناصر معمولی از نوع Inline، ویژگی‌های `width` و `height` عموماً اعمال نمی‌شوند.

برای مثال:

```css
span {
    display: inline;
    width: 200px;
    height: 100px;
}
```

در این حالت `width` و `height` مانند عناصر Block اعمال نمی‌شوند.

برای حل این موضوع می‌توان از `inline-block` استفاده کرد:

```css
span {
    display: inline-block;
    width: 200px;
    height: 100px;
}
```

## مثال کاربردی

در این مثال یک کارت طراحی می‌کنیم که ابعاد مشخصی داشته باشد و با استفاده از `box-sizing` از بزرگ‌تر شدن ناخواسته آن جلوگیری کنیم.

### HTML

```html
<div class="card">
    <h2>آموزش CSS</h2>
    <p>
        در این بخش با ویژگی‌های width، height
        و box-sizing آشنا می‌شویم.
    </p>
    <button>مشاهده بیشتر</button>
</div>
```

### CSS

```css
* {
    box-sizing: border-box;
}

body {
    margin: 0;
    padding: 30px;
    font-family: Arial, sans-serif;
}

.card {
    width: 100%;
    max-width: 350px;
    min-height: 200px;

    padding: 20px;
    border: 2px solid #333;
    margin: 0 auto;

    background-color: #f5f5f5;
    border-radius: 10px;
}

.card h2 {
    margin-top: 0;
}

.card button {
    padding: 10px 20px;
    border: none;
    background-color: #333;
    color: white;
    cursor: pointer;
}
```

### بررسی نتیجه

در این مثال:

- `width: 100%` باعث می‌شود کارت تمام عرض فضای در دسترس را اشغال کند.
- `max-width: 350px` حداکثر عرض کارت را محدود می‌کند.
- `min-height: 200px` حداقل ارتفاع کارت را مشخص می‌کند.
- `padding: 20px` فاصله داخلی ایجاد می‌کند.
- `border: 2px solid #333` کادر کارت را ایجاد می‌کند.
- `box-sizing: border-box` باعث می‌شود Padding و Border به عرض و ارتفاع تعیین‌شده اضافه نشوند.
- `margin: 0 auto` کارت را در مرکز قرار می‌دهد.

## جمع‌بندی

ویژگی‌های `width`، `height` و `box-sizing` از مهم‌ترین ابزارهای CSS برای کنترل ابعاد عناصر هستند.

| ویژگی | کاربرد |
|---|---|
| `width` | تعیین عرض عنصر |
| `height` | تعیین ارتفاع عنصر |
| `min-width` | تعیین حداقل عرض |
| `max-width` | تعیین حداکثر عرض |
| `min-height` | تعیین حداقل ارتفاع |
| `max-height` | تعیین حداکثر ارتفاع |
| `box-sizing` | تعیین نحوه محاسبه ابعاد جعبه |

### تفاوت اصلی دو مقدار box-sizing

- `content-box`: مقدار Width و Height فقط برای Content در نظر گرفته می‌شود.
- `border-box`: مقدار Width و Height شامل Content، Padding و Border است.

### پیشنهاد برای استفاده در پروژه‌های واقعی

بهتر است در ابتدای پروژه از الگوی زیر استفاده کنید:

```css
html {
    box-sizing: border-box;
}

*,
*::before,
*::after {
    box-sizing: inherit;
}
```

این کار باعث می‌شود محاسبه ابعاد عناصر قابل پیش‌بینی‌تر شود و هنگام طراحی Layout، ساخت کارت‌ها، فرم‌ها، دکمه‌ها و بخش‌های مختلف صفحه با مشکلات کمتری مواجه شوید.

**نکته نهایی:** در طراحی واکنش‌گرا، ترکیب `width`، `max-width`، `min-height` و `box-sizing: border-box` یکی از روش‌های کاربردی برای ساخت عناصر منعطف و قابل کنترل است.
