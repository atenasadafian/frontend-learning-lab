# راهنمای جامع ساخت جدول‌های اطلاعاتی ساختاریافته

یکی از قابلیت‌های HTML، نمایش اطلاعات در قالب جدول است. جدول‌ها برای نمایش داده‌هایی مناسب هستند که ارتباط منطقی بین سطرها و ستون‌های آن‌ها وجود دارد؛ مانند:

- اطلاعات کاربران
- فهرست محصولات
- گزارش‌های مالی
- نتایج آزمون‌ها
- مقایسه قیمت‌ها
- برنامه هفتگی
- آمار و گزارش‌های سازمانی

برای ساخت جدول‌های HTML، چهار تگ اصلی وجود دارد:

| تگ | کاربرد |
|---|---|
| `<table>` | ایجاد جدول |
| `<tr>` | ایجاد یک سطر |
| `<th>` | ایجاد سلول عنوان یا سرستون |
| `<td>` | ایجاد سلول داده |

استفاده صحیح از این تگ‌ها باعث می‌شود اطلاعات به‌صورت منظم، قابل‌فهم و قابل‌پردازش توسط مرورگرها و فناوری‌های کمکی نمایش داده شوند.

## جدول HTML 

جدول HTML ساختاری دوبعدی از اطلاعات است که داده‌ها را در قالب سطرها و ستون‌ها سازمان‌دهی می‌کند.

برای مثال، جدول زیر اطلاعات سه کاربر را نمایش می‌دهد:

| شناسه | نام | سن |
|---:|---|---:|
| ۱ | علی | ۲۵ |
| ۲ | سارا | ۲۸ |
| ۳ | رضا | ۳۲ |

در این جدول:

- سه ستون داریم: شناسه، نام و سن.
- یک سطر برای سرستون‌ها وجود دارد.
- سه سطر اطلاعاتی وجود دارد.
- هر سطر اطلاعاتی از سه سلول تشکیل شده است.

**نکته مهم:** از جدول برای نمایش داده‌های جدولی استفاده کنید، نه برای طراحی کلی صفحه، چیدمان منوها یا ایجاد فاصله بین عناصر. برای چیدمان صفحات، CSS Flexbox و CSS Grid مناسب‌تر هستند.

## ساختار اصلی جدول

ساختار ساده یک جدول در HTML به شکل زیر است:

```html
<table>
    <tr>
        <th>نام</th>
        <th>سن</th>
        <th>شهر</th>
    </tr>

    <tr>
        <td>علی</td>
        <td>25</td>
        <td>تهران</td>
    </tr>

    <tr>
        <td>سارا</td>
        <td>28</td>
        <td>شیراز</td>
    </tr>
</table>
```

### خروجی مورد انتظار

| نام | سن | شهر |
|---|---:|---|
| علی | ۲۵ | تهران |
| سارا | ۲۸ | شیراز |

ساختار تودرتوی جدول به این صورت است:

```text
table
 ├── tr
 │    ├── th
 │    ├── th
 │    └── th
 ├── tr
 │    ├── td
 │    ├── td
 │    └── td
 └── tr
      ├── td
      ├── td
      └── td
```

در این ساختار:

1. تگ `table` عنصر اصلی جدول است.
2. هر `tr` یک سطر را ایجاد می‌کند.
3. تگ‌های `th` عنوان ستون‌ها را مشخص می‌کنند.
4. تگ‌های `td` اطلاعات هر ستون را در سطر مربوطه قرار می‌دهند.

مرورگرها ممکن است برای جدول ساده، بدون CSS نیز ساختار سطرها و ستون‌ها را نمایش دهند؛ اما برای داشتن ظاهر مناسب باید از CSS استفاده کرد.

## معرفی تگ‌های اصلی

### تگ `<table>`

تگ `table` عنصر اصلی جدول را ایجاد می‌کند.

**نحوه استفاده:**

```html
<table>
    <!-- محتوای جدول -->
</table>
```

تمام سطرها و بخش‌های جدول درون این تگ قرار می‌گیرند.

مثال:

```html
<table>
    <tr>
        <td>محصول شماره ۱</td>
        <td>۱۵۰۰۰۰</td>
    </tr>
</table>
```

در این مثال، یک جدول با یک سطر و دو سلول ایجاد شده است.

### تگ `<tr>`

تگ `tr` مخفف **Table Row** است و برای ایجاد یک سطر در جدول به کار می‌رود.

**نحوه استفاده:**

```html
<tr>
    <td>داده اول</td>
    <td>داده دوم</td>
</tr>
```

هر سطر می‌تواند شامل سلول‌های عنوان (`th`) یا سلول‌های داده (`td`) باشد.

مثال:

```html
<table>
    <tr>
        <th>نام</th>
        <th>ایمیل</th>
    </tr>

    <tr>
        <td>مریم</td>
        <td>maryam@example.com</td>
    </tr>
</table>
```

در این مثال دو سطر داریم:

- سطر اول شامل عنوان ستون‌ها است.
- سطر دوم شامل اطلاعات کاربر است.

**نکته:** تعداد سلول‌های هر سطر لزوماً نباید یکسان باشد، زیرا ویژگی‌هایی مانند `colspan` و `rowspan` می‌توانند ساختار سلول‌ها را تغییر دهند؛ با این حال، برای جدول‌های معمولی بهتر است ساختار سطرها منظم باشد.

### تگ `<th>`

تگ `th` مخفف **Table Header** است و برای مشخص کردن سلول عنوان استفاده می‌شود.

این تگ معمولاً برای نام ستون‌ها یا عنوان یک ردیف به کار می‌رود.

مثال:

```html
<table>
    <tr>
        <th>نام محصول</th>
        <th>قیمت</th>
        <th>موجودی</th>
    </tr>
</table>
```

مرورگرها معمولاً متن داخل `th` را به‌صورت پررنگ و وسط‌چین نمایش می‌دهند؛ اما این ظاهر پیش‌فرض است و می‌توان آن را با CSS تغییر داد.

برای مشخص کردن ارتباط معنایی عنوان با سلول‌ها، از ویژگی `scope` استفاده می‌کنیم:

```html
<table>
    <tr>
        <th scope="col">نام</th>
        <th scope="col">سن</th>
        <th scope="col">شهر</th>
    </tr>

    <tr>
        <td>علی</td>
        <td>25</td>
        <td>تهران</td>
    </tr>
</table>
```

مقادیر متداول `scope` عبارت‌اند از:

| مقدار | کاربرد |
|---|---|
| `col` | عنوان مربوط به یک ستون |
| `row` | عنوان مربوط به یک سطر |
| `colgroup` | عنوان مربوط به گروهی از ستون‌ها |
| `rowgroup` | عنوان مربوط به گروهی از سطرها |

برای جدول‌های ساده، استفاده از `scope="col"` برای سرستون‌ها و `scope="row"` برای عنوان سطرها روش مناسبی است.

### تگ `<td>`

تگ `td` مخفف **Table Data** است و برای نمایش اطلاعات معمولی داخل سلول‌های جدول استفاده می‌شود.

مثال:

```html
<table>
    <tr>
        <th>نام</th>
        <th>شغل</th>
        <th>حقوق</th>
    </tr>

    <tr>
        <td>علی</td>
        <td>برنامه‌نویس</td>
        <td>30000000</td>
    </tr>
</table>
```

در این مثال، اطلاعات علی در سه سلول داده قرار گرفته است.

تفاوت اصلی `th` و `td` در معنای آن‌ها است:

- `th` یک سلول را به‌عنوان عنوان یا سرستون معرفی می‌کند.
- `td` یک سلول حاوی داده را مشخص می‌کند.

بنابراین، انتخاب این تگ‌ها نباید صرفاً بر اساس ظاهر آن‌ها انجام شود.

## ساخت اولین جدول

در این بخش یک جدول ساده برای نمایش اطلاعات دانشجویان ایجاد می‌کنیم.

### کد HTML

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>جدول اطلاعات دانشجویان</title>
</head>
<body>

    <h1>اطلاعات دانشجویان</h1>

    <table>
        <tr>
            <th scope="col">شماره دانشجویی</th>
            <th scope="col">نام</th>
            <th scope="col">رشته تحصیلی</th>
        </tr>

        <tr>
            <td>1001</td>
            <td>علی احمدی</td>
            <td>مهندسی کامپیوتر</td>
        </tr>

        <tr>
            <td>1002</td>
            <td>سارا محمدی</td>
            <td>مهندسی برق</td>
        </tr>

        <tr>
            <td>1003</td>
            <td>رضا کریمی</td>
            <td>مهندسی صنایع</td>
        </tr>
    </table>

</body>
</html>
```

### توضیح کد

- `lang="fa"` زبان اصلی صفحه را فارسی مشخص می‌کند.
- `dir="rtl"` جهت نوشتار صفحه را راست‌به‌چپ تعیین می‌کند.
- `meta charset="UTF-8"` امکان نمایش صحیح حروف فارسی را فراهم می‌کند.
- `meta viewport` برای نمایش مناسب صفحه در دستگاه‌های مختلف استفاده می‌شود.
- `h1` عنوان اصلی صفحه را نمایش می‌دهد.
- `table` جدول اطلاعات را ایجاد می‌کند.
- `th` عنوان ستون‌ها را مشخص می‌کند.
- `td` اطلاعات دانشجویان را نمایش می‌دهد.

در این مثال، ساختار جدول از HTML ساخته شده است و هنوز استایل سفارشی ندارد.

## بخش‌های معنایی جدول

HTML علاوه بر چهار تگ اصلی، تگ‌های دیگری برای سازمان‌دهی بهتر جدول دارد.

سه تگ مهم عبارت‌اند از:

- `<thead>`: بخش سرستون‌ها
- `<tbody>`: بخش اصلی داده‌ها
- `<tfoot>`: بخش پایانی یا جمع‌بندی جدول

مثال:

```html
<table>
    <thead>
        <tr>
            <th scope="col">محصول</th>
            <th scope="col">تعداد</th>
            <th scope="col">قیمت</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>کیبورد</td>
            <td>2</td>
            <td>1200000</td>
        </tr>

        <tr>
            <td>ماوس</td>
            <td>3</td>
            <td>600000</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <th scope="row" colspan="2">مجموع</th>
            <td>1800000</td>
        </tr>
    </tfoot>
</table>
```

### مزایای استفاده از این تگ‌ها

1. ساختار جدول خواناتر می‌شود.
2. بخش عنوان، داده‌ها و جمع‌بندی از یکدیگر جدا می‌شوند.
3. هدف هر بخش برای توسعه‌دهندگان روشن‌تر می‌شود.
4. مرورگرها و ابزارهای پردازش HTML می‌توانند ساختار معنایی را بهتر تشخیص دهند.
5. استایل‌دهی به بخش‌های مختلف ساده‌تر می‌شود.

استفاده از `thead`، `tbody` و `tfoot` برای همه جدول‌ها اجباری نیست، اما در جدول‌های پیچیده و اطلاعاتی توصیه می‌شود.

## عنوان و توضیحات جدول

### استفاده از `<caption>`

تگ `caption` عنوان خود جدول را مشخص می‌کند.

```html
<table>
    <caption>فهرست محصولات فروشگاه</caption>

    <thead>
        <tr>
            <th scope="col">نام محصول</th>
            <th scope="col">قیمت</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>مانیتور</td>
            <td>8500000</td>
        </tr>

        <tr>
            <td>کیبورد</td>
            <td>1200000</td>
        </tr>
    </tbody>
</table>
```

عنوان جدول باید توضیح دهد که جدول چه اطلاعاتی را نمایش می‌دهد.

### استفاده از `<caption>` در مقابل `<th>`

این دو تگ کاربرد یکسانی ندارند:

| تگ | کاربرد |
|---|---|
| `caption` | عنوان کلی جدول |
| `th` | عنوان یک سطر یا ستون |

برای مثال، عبارت «فهرست محصولات فروشگاه» عنوان کل جدول است؛ اما «نام محصول» عنوان یک ستون محسوب می‌شود.

### توضیحات تکمیلی

اگر جدول به توضیحات بیشتری نیاز دارد، می‌توان از یک پاراگراف در کنار جدول استفاده کرد:

```html
<p id="sales-description">
    این جدول فروش محصولات را در ماه جاری نشان می‌دهد.
</p>

<table aria-describedby="sales-description">
    <caption>گزارش فروش ماهانه</caption>

    <thead>
        <tr>
            <th scope="col">ماه</th>
            <th scope="col">مبلغ فروش</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>مهر</td>
            <td>50000000</td>
        </tr>
    </tbody>
</table>
```

ویژگی `aria-describedby` ارتباط جدول با توضیحات تکمیلی را برای فناوری‌های کمکی مشخص می‌کند.

## ادغام سلول‌ها

گاهی لازم است یک سلول چند ستون یا چند سطر را پوشش دهد. برای این کار از دو ویژگی `colspan` و `rowspan` استفاده می‌کنیم.

### ویژگی `colspan`

ویژگی `colspan` مشخص می‌کند که یک سلول چند ستون را اشغال کند.

مثال:

```html
<table>
    <tr>
        <th colspan="3">اطلاعات تماس</th>
    </tr>

    <tr>
        <td>نام</td>
        <td>تلفن</td>
        <td>ایمیل</td>
    </tr>

    <tr>
        <td>علی</td>
        <td>09120000000</td>
        <td>ali@example.com</td>
    </tr>
</table>
```

در این مثال، سلول «اطلاعات تماس» سه ستون را پوشش می‌دهد.

### ویژگی `rowspan`

ویژگی `rowspan` مشخص می‌کند که یک سلول چند سطر را اشغال کند.

مثال:

```html
<table>
    <tr>
        <th scope="col">نام گروه</th>
        <th scope="col">نام دانشجو</th>
    </tr>

    <tr>
        <td rowspan="2">گروه اول</td>
        <td>علی</td>
    </tr>

    <tr>
        <td>سارا</td>
    </tr>
</table>
```

در این مثال، سلول «گروه اول» دو سطر را پوشش می‌دهد.

### تفاوت `colspan` و `rowspan`

| ویژگی | جهت ادغام | مثال |
|---|---|---|
| `colspan` | افقی، در چند ستون | `colspan="3"` |
| `rowspan` | عمودی، در چند سطر | `rowspan="2"` |

**نکته:** هنگام استفاده از این ویژگی‌ها باید تعداد سلول‌ها و ساختار منطقی جدول را بررسی کرد تا ستون‌ها به‌درستی زیر یکدیگر قرار بگیرند.

## ۹. استایل‌دهی جدول با CSS

HTML ساختار اطلاعات را تعریف می‌کند؛ در مقابل، CSS ظاهر آن را کنترل می‌کند.

برای مثال، می‌توان رنگ پس‌زمینه، حاشیه‌ها، فاصله داخلی، اندازه متن و نحوه قرارگیری اطلاعات را تغییر داد.

### ۹.۱. یک استایل ساده

```html
<style>
    table {
        width: 100%;
        border-collapse: collapse;
    }

    th,
    td {
        border: 1px solid #cccccc;
        padding: 12px;
        text-align: right;
    }

    th {
        background-color: #eeeeee;
    }
</style>
```

### توضیح ویژگی‌ها

| ویژگی CSS | کاربرد |
|---|---|
| `width` | تعیین عرض جدول |
| `border` | ایجاد حاشیه |
| `border-collapse` | ادغام حاشیه‌های مجاور سلول‌ها |
| `padding` | ایجاد فاصله بین محتوا و حاشیه سلول |
| `text-align` | تعیین تراز افقی متن |
| `background-color` | تعیین رنگ پس‌زمینه |

### ۹.۲. ایجاد جدول با سطرهای راه‌راه

برای خوانایی بیشتر می‌توان رنگ سطرها را به‌صورت متناوب تغییر داد.

```css
tbody tr:nth-child(even) {
    background-color: #f2f2f2;
}

tbody tr:hover {
    background-color: #e6f0ff;
}
```

در این کد:

- `nth-child(even)` سطرهای زوج را انتخاب می‌کند.
- `:hover` زمانی فعال می‌شود که نشانگر ماوس روی سطر قرار بگیرد.

### ۹.۳. استایل‌دهی کامل‌تر

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>جدول محصولات</title>

    <style>
        body {
            font-family: Tahoma, Arial, sans-serif;
            margin: 24px;
            line-height: 1.8;
        }

        table {
            width: 100%;
            border-collapse: collapse;
            margin-top: 16px;
        }

        caption {
            font-size: 1.2rem;
            font-weight: bold;
            margin-bottom: 12px;
        }

        th,
        td {
            border: 1px solid #cccccc;
            padding: 12px;
            text-align: right;
        }

        thead th {
            background-color: #e8eef7;
        }

        tbody tr:nth-child(even) {
            background-color: #f7f7f7;
        }

        tbody tr:hover {
            background-color: #e8f2ff;
        }
    </style>
</head>

<body>
    <h1>فهرست محصولات</h1>

    <table>
        <caption>اطلاعات محصولات فروشگاه</caption>

        <thead>
            <tr>
                <th scope="col">کد محصول</th>
                <th scope="col">نام محصول</th>
                <th scope="col">قیمت (تومان)</th>
            </tr>
        </thead>

        <tbody>
            <tr>
                <td>101</td>
                <td>مانیتور</td>
                <td>8500000</td>
            </tr>

            <tr>
                <td>102</td>
                <td>کیبورد</td>
                <td>1200000</td>
            </tr>

            <tr>
                <td>103</td>
                <td>ماوس</td>
                <td>600000</td>
            </tr>
        </tbody>
    </table>
</body>
</html>
```

## ۱۰. دسترس‌پذیری و استانداردها

دسترس‌پذیری یا Accessibility به این معناست که افراد مختلف، از جمله افرادی که از صفحه‌خوان استفاده می‌کنند، بتوانند محتوای صفحه را درک کنند.

برای ساخت جدول‌های دسترس‌پذیر، نکات زیر مهم هستند.

### ۱۰.۱. استفاده صحیح از `th` و `td`

از `th` برای عنوان‌ها و از `td` برای داده‌های معمولی استفاده کنید.

```html
<table>
    <thead>
        <tr>
            <th scope="col">نام</th>
            <th scope="col">امتیاز</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>علی</td>
            <td>95</td>
        </tr>
    </tbody>
</table>
```

### ۱۰.۲. مشخص کردن جهت عنوان‌ها با `scope`

استفاده از `scope="col"` یا `scope="row"` به ابزارهای کمکی کمک می‌کند ارتباط بین عنوان و داده را بهتر تشخیص دهند.

### ۱۰.۳. افزودن عنوان معنادار

عنوان مناسب با `caption` مشخص می‌کند که جدول چه موضوعی دارد.

```html
<table>
    <caption>نتایج آزمون پایان‌ترم</caption>
    <!-- سطرها و سلول‌های جدول -->
</table>
```

### ۱۰.۴. استفاده از ساختار معنایی

در جدول‌های طولانی، بخش‌بندی با `thead`، `tbody` و در صورت نیاز `tfoot` می‌تواند ساختار را روشن‌تر کند.

### ۱۰.۵. جدول‌های پیچیده

در جدول‌هایی که چند سطح عنوان دارند یا عنوان‌ها چندین ستون را پوشش می‌دهند، ممکن است به شناسه‌های `id` و ویژگی `headers` نیاز باشد.

مثال ساده:

```html
<table>
    <caption>نمرات دانشجویان</caption>

    <thead>
        <tr>
            <th id="student-name" scope="col">نام دانشجو</th>
            <th id="student-score" scope="col">نمره</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td headers="student-name">سارا</td>
            <td headers="student-score">19</td>
        </tr>
    </tbody>
</table>
```

در این مثال، ویژگی `headers` سلول‌های داده را به عنوان‌های دارای شناسه مرتبط می‌کند. در جدول‌های ساده، معمولاً `scope` کافی است؛ اما در ساختارهای پیچیده، `headers` می‌تواند ارتباطات دقیق‌تری تعریف کند.

---

## ۱۱. جدول‌های واکنش‌گرا

جدول‌های عریض ممکن است در صفحه‌نمایش تلفن همراه از عرض صفحه بیشتر شوند. یکی از راهکارهای متداول، قرار دادن جدول درون یک عنصر با قابلیت پیمایش افقی است.

```html
<div class="table-wrapper">
    <table>
        <caption>گزارش فروش محصولات</caption>

        <thead>
            <tr>
                <th scope="col">کد</th>
                <th scope="col">نام محصول</th>
                <th scope="col">قیمت</th>
                <th scope="col">تعداد</th>
                <th scope="col">وضعیت</th>
            </tr>
        </thead>

        <tbody>
            <tr>
                <td>101</td>
                <td>مانیتور</td>
                <td>8500000</td>
                <td>12</td>
                <td>موجود</td>
            </tr>
        </tbody>
    </table>
</div>
```

CSS مربوطه:

```css
.table-wrapper {
    max-width: 100%;
    overflow-x: auto;
}

.table-wrapper table {
    width: 100%;
    border-collapse: collapse;
}

.table-wrapper th,
.table-wrapper td {
    border: 1px solid #cccccc;
    padding: 10px;
    white-space: nowrap;
}
```

ویژگی `overflow-x: auto` در صورت نیاز پیمایش افقی ایجاد می‌کند.

ویژگی `white-space: nowrap` مانع شکستن متن سلول به چند خط می‌شود؛ البته برای سلول‌هایی با متن طولانی باید با دقت استفاده شود.

**نکته:** واکنش‌گرایی جدول فقط به کوچک کردن عرض آن محدود نیست. در جدول‌های بسیار عریض، بهتر است بررسی شود که کدام اطلاعات ضروری هستند و آیا نمایش آن‌ها در قالبی جایگزین برای موبایل تجربه بهتری ایجاد می‌کند یا خیر.

## ۱۲. مثال کاربردی کامل

در این مثال یک جدول اطلاعاتی کامل برای مدیریت سفارش‌های فروشگاه طراحی می‌کنیم.

ویژگی‌های این مثال:

- ساختار معنایی با `thead` و `tbody`
- عنوان جدول با `caption`
- عنوان‌های استاندارد با `th`
- داده‌های معمولی با `td`
- استایل‌دهی با CSS
- نمایش مناسب در صفحه‌های کوچک
- پشتیبانی از نوشتار راست‌به‌چپ

### فایل `index.html`

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">

<head>

            margin-bottom: 20px;
        }

        .table-wrapper {
            width: 100%;
            overflow-x: auto;
        }

        table {
            width: 100%;
            min-width: 600px;
            border-collapse: collapse;
        }

        caption {
            text-align: right;
            font-size: 1.2rem;
            font-weight: bold;
            padding: 12px 0;
        }

        th,
        td {
            border: 1px solid #dddddd;
            padding: 12px;
            text-align: right;
        }

        thead th {
            background-color: #eeeeee;
        }

        tbody tr:nth-child(even) {
            background-color: #f8f8f8;
        }

        tbody tr:hover {
            background-color: #edf4ff;
        }
    </style>
</head>

<body>

    <h1>مدیریت سفارش‌ها</h1>

    <div class="table-wrapper">
        <table>
            <caption>فهرست سفارش‌های مشتریان</caption>

            <thead>
                <tr>
                    <th scope="col">شماره سفارش</th>
                    <th scope="col">نام مشتری</th>
                    <th scope="col">مبلغ سفارش</th>
                    <th scope="col">وضعیت</th>
                </tr>
            </thead>

            <tbody>
                <tr>
                    <td>5001</td>
                    <td>علی احمدی</td>
                    <td>2500000 تومان</td>
                    <td>پرداخت‌شده</td>
                </tr>

                <tr>
                    <td>5002</td>
                    <td>سارا محمدی</td>

                    <td>3200000 تومان</td>
```

### نحوه اجرا

۱. یک پوشه برای پروژه بسازید.

۲. فایلی با نام `index.html` ایجاد کنید.

۳. کد بالا را داخل فایل قرار دهید.

۴. فایل را در مرورگر باز کنید.

جدول به‌صورت محلی و بدون نیاز به نصب کتابخانه یا فریم‌ورک اجرا می‌شود.

## ۱۳. اشتباهات رایج

### اشتباه اول: استفاده از `td` به‌جای `th` برای عنوان ستون

روش نامناسب:

```html
<table>
    <tr>
        <td>نام</td>
        <td>سن</td>
    </tr>
</table>
```

روش بهتر:

```html
<table>
    <thead>
        <tr>
            <th scope="col">نام</th>
            <th scope="col">سن</th>
        </tr>
    </thead>
</table>
```

استفاده از `th` معنای عنوان ستون را مشخص می‌کند.

### اشتباه دوم: استفاده از جدول برای طراحی صفحه

جدول برای داده‌های ساختاریافته است، نه برای ایجاد ستون‌های اصلی صفحه، قرار دادن منوها یا تنظیم فاصله بین عناصر.

برای این موارد از Flexbox یا Grid استفاده کنید.

### اشتباه سوم: فراموش کردن ساختار سطرها

هر سلول باید در جایگاه مناسبی از ساختار جدول قرار بگیرد.

```html
<table>
    <tr>
        <td>علی</td>
        <td>25</td>
    </tr>
</table>
```

در این مثال، `td`ها داخل `tr` قرار گرفته‌اند؛ این ساختار صحیح است.

### اشتباه چهارم: ادغام نادرست سلول‌ها

مقدار `colspan` یا `rowspan` باید با ساختار واقعی جدول سازگار باشد. ادغام نامناسب ممکن است باعث شود اطلاعات در ستون‌های اشتباه قرار بگیرند.

### اشتباه پنجم: استفاده بیش از حد از CSS برای جبران ساختار نامناسب

تراز کردن داده‌ها با فاصله‌های دستی، استفاده از تعداد زیادی فاصله یا چیدمان سلول‌ها با موقعیت‌دهی غیرضروری، جایگزین ساختار درست HTML نیست.

ابتدا ساختار معنایی مناسب را بسازید و سپس با CSS ظاهر آن را تنظیم کنید.

### اشتباه ششم: نادیده گرفتن صفحه‌نمایش کوچک

جدول‌های بزرگ ممکن است در تلفن همراه به‌خوبی دیده نشوند. برای این موارد، پیمایش افقی یا طراحی یک نمایش جایگزین را در نظر بگیرید.

## ۱۴. بهترین روش‌ها

برای ساخت جدول‌های اطلاعاتی استاندارد، توصیه می‌شود موارد زیر را رعایت کنید:

1. **ساختار را از ظاهر جدا کنید.** HTML برای معنا و ساختار و CSS برای ظاهر استفاده می‌شود.
2. **از `th` برای عنوان‌ها استفاده کنید.** این کار به درک بهتر ارتباط بین داده‌ها و عنوان‌ها کمک می‌کند.
3. **عنوان جدول را مشخص کنید.** در صورت نیاز از `caption` استفاده کنید.
4. **جدول‌های بزرگ را بخش‌بندی کنید.** `thead`، `tbody` و `tfoot` ساختار را روشن‌تر می‌کنند.
5. **از `scope` استفاده کنید.** برای سرستون‌ها `scope="col"` و برای عنوان سطرها `scope="row"` مناسب است.
6. **از `colspan` و `rowspan` فقط در صورت نیاز استفاده کنید.** ادغام سلول‌ها باید ارتباط منطقی اطلاعات را حفظ کند.
7. **دسترس‌پذیری را رعایت کنید.** عنوان‌ها و ارتباط بین سلول‌ها باید برای کاربران صفحه‌خوان قابل تشخیص باشند.
8. **نمایش در موبایل را آزمایش کنید.** جدول‌های عریض ممکن است به پیمایش افقی نیاز داشته باشند.
9. **از جدول برای داده‌های جدولی استفاده کنید.** برای چیدمان عمومی صفحه از CSS Grid و Flexbox کمک بگیرید.
10. **HTML معتبر بنویسید.** برای بررسی ساختار می‌توانید از [اعتبارسنج HTML سرویس W3C](https://validator.w3.org/) استفاده کنید.

## ۱۵. جمع‌بندی

تگ‌های اصلی جدول در HTML، یعنی `table`، `tr`، `th` و `td`، برای ساختاردهی اطلاعات در سطرها و ستون‌ها استفاده می‌شوند.

خلاصه کاربرد هر تگ:

| تگ | توضیح |
|---|---|
| `<table>` | ایجاد ساختار کلی جدول |
| `<tr>` | ایجاد یک سطر |
| `<th>` | تعریف سلول عنوان |
| `<td>` | تعریف سلول داده |
| `<thead>` | گروه‌بندی سرستون‌ها |
| `<tbody>` | گروه‌بندی داده‌های اصلی |
| `<tfoot>` | گروه‌بندی اطلاعات پایانی |
| `<caption>` | تعیین عنوان جدول |

برای ساخت یک جدول استاندارد، ابتدا ساختار صحیح HTML را ایجاد کنید، سپس عنوان‌های ستون‌ها و داده‌ها را مشخص کنید و در نهایت با CSS ظاهر جدول را بهبود دهید.

**اصل کلیدی:** یک جدول خوب فقط جدولی با ظاهر زیبا نیست؛ بلکه باید ساختار معنایی روشن، اطلاعات منظم، دسترس‌پذیری مناسب و نمایش قابل‌قبول در اندازه‌های مختلف صفحه داشته باشد.
